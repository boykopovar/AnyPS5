# libScePigletv2VSH technical debt

### Build

- [libScePigletv2VSH](../../../core/libs/prx/libScePigletv2VSH/CMakeLists.txt) links libc's import library a second time, before glslang, and libstdc++ before the import library's trailing copy. The import library lists 12 `std::__cxx11::basic_string` members that the patched `libc.prx` does not export, so a library whose static archives use them fails to load with error 127 when they bind to `libc.prx`, while `__cxa_throw` and `_Unwind_*` bound to libstdc++ throw through libgcc's SEH unwinder, which finds no unwind data for AnyPS5's frames and cannot deliver the exception. A library that links glslang or another C++ archive needs the same order until the import library stops listing those members.

### Unknown function info

- [scePigletSetConfigurationVSH](../../../core/libs/prx/libScePigletv2VSH/Export.cpp) (libScePigletv2VSH) - returns true for a configuration whose first word, its size, is 0x88, as in the OpenOrbis piglet sample, and false otherwise. The other fields, which the sample fills with flags 0xe8, memory sizes and the window size, are ignored; their meaning is unknown.
- [eglCreateWindowSurface](../../../core/libs/prx/libScePigletv2VSH/src/Egl.cpp) (libScePigletv2VSH) - the native window is taken as the 32-bit words `{uniqueId, width, height, reserved}` the sample fills, and only the width and height are used. Each surface opens its own VideoOut port for the system user on the main bus and registers two linear R8G8B8A8 buffers; how the console library presents is unknown.

### Functional

- [libScePigletv2VSH](../../../core/libs/prx/libScePigletv2VSH/Export.cpp) (libScePigletv2VSH) - implements on Vulkan the 13 EGL 1.4 and 33 OpenGL ES 2.0 functions the OpenOrbis piglet sample imports, enough for its textured quads; the other functions of the console library are absent. `glShaderBinary` accepts only AnyPS5's own GLSL ES source from [libScePrecompiledShaders](../../../core/libs/prx/libScePrecompiledShaders/Export.cpp), compiled with glslang as GLSL ES 3.10 under relaxed Vulkan rules, and throws on a PS4 shader binary. The only config is RGBA8 without depth, stencil or multisampling, and making a context current on another surface while it records a frame throws. Cube maps, mipmap levels other than 0, texel types other than `GL_UNSIGNED_BYTE`, attribute types other than `GL_FLOAT` and `GL_UNSIGNED_BYTE`, `GL_LINE_LOOP`, polygon offset, sample coverage, shared contexts and single-buffered surfaces throw. A texture whose minifying filter needs mipmaps samples as incomplete (0, 0, 0, 1). `GL_EXTENSIONS` reports `GL_OES_texture_npot` and no size or wrap restriction is enforced for non-power-of-two textures. Clip-space depth follows OpenGL ES's [-w, w] only where the device has `VK_EXT_depth_clip_control`; elsewhere primitives with negative depth are clipped. `eglSwapInterval` without a current context succeeds and sets the interval of the next surface, which the sample relies on; intervals above 1 are clamped to 1. `eglSwapBuffers` renders to an image, copies it to host memory and into the next VideoOut buffer once no flip is pending, and flips on vblank for interval 1 and on hsync for interval 0. Checked on Windows with the sample (59.94 frames per second) and `guest_piglet`; Linux and macOS builds are unverified.
