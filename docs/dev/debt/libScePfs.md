### Unknown function info

- [scePfsGetBlockTableReadCommand, scePfsGetHeaderReadCommand, scePfsGetPreadBlockRange, scePfsGetSingleBlockReadCommand, scePfsGetUncompressedSize, scePfsValidate](../../../core/libs/prx/libScePfs/Export.cpp) (libScePfs) - implemented from the bundled decrypted `libScePfs.prx` of Stellar Blade (PPSA13197, `unwrapped/libScePfs.prx.elf`, export VAs `0xef0`/`0xf20`/`0xd80`/`0xfb0`/`0x2f0`/`0xd0`). PFSC magic `0x43534650`; version u16 `+4`; total `+0x18`; v2 tag `+0x28` == 2, u64 block boundaries at `+0x30` masked 48-bit; v3 16-byte index records `+0x48`, types 3 (block table) and 7 (data region) keyed on the low byte, entries masked 44-bit; errors `0x8a780001`-`0x8a780005`. Deviation: v3 `scePfsGetSingleBlockReadCommand` with no type-3 record and `blockIndex >= 0` null-derefs on console; host returns `0x8a780003`.
  - names/NIDs verified from pinned [ps5rs stubs](https://github.com/claimore22/ps5rs/tree/5f252a658ff470bcb2b6cd15205fd8ca64ae4477/data/stubs/by_library) (`libScePfs.txt`); NID match confirmed via `tools/nid_names.py` `compute_nid`.
  - revision note (PPSA02101's decrypted module, older revision): `scePfsGetHeaderReadCommand`, `scePfsGetBlockTableReadCommand`, `scePfsGetPreadBlockRange`, `scePfsGetUncompressedSize` and `scePfsValidate` match instruction for instruction; that revision's `scePfsGetSingleBlockReadCommand` has no `blockIndex` bounds checks and its v3 path indexes the caller's table without the type-3 lookup. The newer revision is followed.
  - `scePfsGetPreadBlockRange` range and index math is hardened beyond the firmware's wrapping `offset + size` add: a request whose end wraps u64 or whose block index does not fit u32 returns `0x8a780005`; a zero `end` skips firmware's read before the v3 table and reports the same `(first, last)` it would with a zero word there.
  - `scePfsValidate` v3 keeps the block count from `words[1] >> 0x14` unsigned; firmware treats it as signed minus one clamped to zero, so a count of `0x80000001` or higher walks the table where firmware returns immediately (malformed headers only).
- [scePfsPread, scePfsPreadDecompressBlock](../../../core/libs/prx/libScePfs/Export.cpp) (libScePfs) - `scePfsPread` (VA `0x330`) decodes as `(dst, size, offset, header, workBuffer)`; its argument checks before the reads are implemented from the bundled decrypted `libScePfs.prx` of Stellar Blade (PPSA13197, `unwrapped/libScePfs.prx.elf`), read from disassembly, not measured on a console: null `dst` returns `0x8a780001`, a zero `size` returns `0` before any header access, an offset above 48 bits or a null header or work buffer returns `0x8a780001`, a header without the PFSC magic returns `0x8a780002`, and a range past the total at `+0x18` returns `0x8a780005`. Past them the worker loop and command marshalling are not ported, so a request passing every check throws through `NotImplemented_nid_no_patch`. `scePfsPreadDecompressBlock` (VA `0x1180`) drives an internal range-decoder codec (`0xf0a20` block, calls `0x6380`, `0xaa0`); signature and codec semantics unverified.
