# libSceScreenShot technical debt

### Silent stubs

- [sceScreenShotEnableNotification and sceScreenShotDisableNotification](../../../core/libs/prx/libSceScreenShot/Export.cpp) (libSceScreenShot) - return 0 without effect: on the console they ask the system software to show or hide the capture notification, which this project does not display
- [sceScreenShotSetOverlayImage and sceScreenShotSetOverlayImageWithOrigin](../../../core/libs/prx/libSceScreenShot/Export.cpp) (libSceScreenShot) - check the arguments and the file as the PS5 module does, then return 0 without keeping the image, since this project takes no screenshots to overlay
- [sceScreenShotIsDisabled and sceScreenShotIsVshScreenCaptureDisabled](../../../core/libs/prx/libSceScreenShot/Export.cpp) (libSceScreenShot) - report one process-wide flag set by sceScreenShotDisable and cleared by sceScreenShotEnable; on the console the system software answers, and what the id selects is unknown. A null output pointer or an id of -1 returns 0x80BE0001, matching firmware 13.42 disassembly.

### Unknown function info

- [sceScreenShotGetDrcParam and sceScreenShotSetDrcParam](../../../core/libs/prx/libSceScreenShot/Export.cpp) (libSceScreenShot) - member function signatures are recovered from the aerolib symbol database demangled names (`_ZN13sceScreenShot9IpcClient11SetDrcParamEjj` and `_ZN13sceScreenShot9IpcClient11GetDrcParamEiPjS1_`). The exported function prototypes are assumed from these internal `IpcClient` member names; this correspondence is unverified because members do not always match exports (for example, `SetOverlayImage` takes three integers in the client while the export takes a file path). Parameter semantics, valid identifiers, return values and console behavior remain unmeasured, so both continue to throw `NotImplemented_nid_no_patch`.
- [sceScreenShotCapture and sceScreenShotGetAppInfo](../../../core/libs/prx/libSceScreenShot/Export.cpp) (libSceScreenShot) - validate arguments matching firmware 13.42 disassembly (capture rejects a type of 2 or above or a null output, and getAppInfo rejects an id of -1 or a null output, returning 0x80BE0001) before calling an unimplemented service and throwing `NotImplemented_nid_no_patch`.
- [sceScreenShotSetParam](../../../core/libs/prx/libSceScreenShot/Export.cpp) (libSceScreenShot) - names and NIDs are present in the [PS5 3.20 export inventory](https://github.com/DNNDHH/PS5-3.20_Libs/blob/b2a77c09cd71c01f34c790cfbe98c751a13262ad/libSceScreenShot.c), but no credible prototypes were found. They are declared without parameters solely to resolve known imports; this is not an ABI claim and callers must not call them until signatures are verified.
