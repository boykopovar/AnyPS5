# libSceGifParser technical debt

### Callable exports

- [Callable exports](../../../core/libs/prx/libSceGifParser/Export.cpp) - Seven 3.20 callable NIDs are import-resolution declarations only. One NID also appears in the 13.60-labelled inventory; other NIDs differ across versions. Their signatures and behavior are unverified; parameterless `int` declarations are placeholders, not verified ABI contracts. Every entry except `gtaHM-0DRuA` throws through `NotImplemented_nid_no_patch`. Data exports require separate layout and ownership analysis.
- [Firmware 13.42 exports](../../../core/libs/prx/libSceGifParser/Export.cpp) (libSceGifParser) - the 13.42 `libSceGifParser.sprx` exports seven function NIDs; `gtaHM-0DRuA` is the only one also in the 3.20 set above, and its decoder exports `T8p1TeFElWo`, `SZeQGmAx+N0` and `DTWP8QPsnTM` are not declared. Read from disassembly, not measured on a console: `qiEL-fPgaAA` and `-ZzjSDCInl4` return `0x809D4054`; `WvV54DtSzmQ` copies the caller's 0x58-byte configuration into both of the module's copies and returns 0; `gtaHM-0DRuA` clears the first copy and returns 0. The configuration is eleven function pointers that the module's helpers jump through without a null check; nothing reads it here until the decoder is implemented. A null or unreadable configuration, which the module reads through, throws.
