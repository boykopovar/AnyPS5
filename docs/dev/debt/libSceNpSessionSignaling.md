- [sceNpSessionSignalingInitialize, sceNpSessionSignalingCreateContext and sceNpSessionSignalingCreateContext2](../../../core/libs/prx/libSceNpSessionSignaling/Export.cpp) - the initialization layout is 40 bytes; both context layouts are 56 bytes with callback and user-data pairs. The second context variant adds a group identifier to its connection callback. Pool allocation, callback delivery and underlying NP account validation are not implemented; priority and affinity settings do not affect host scheduling.

- [sceNpSessionSignalingGetConnectionStatus, sceNpSessionSignalingActivateSession and sceNpSessionSignalingActivateUser](../../../core/libs/prx/libSceNpSessionSignaling/Export.cpp) - initialization, context lookup and output validation follow the system library. Connections never activate in the offline runtime; activation returns unavailable and a connection query on a valid context returns connection-not-found without writing outputs. SDK-dependent peer-address validation and local-network discovery remain incomplete.

- [sceNpSessionSignalingCreateJoinActivate, sceNpSessionSignalingJoinActivate, sceNpSessionSignalingManualUdpAbortConnection, sceNpSessionSignalingManualUdpCreateJoin, sceNpSessionSignalingManualUdpEstablishConnection and sceNpSessionSignalingManualUdpJoin](../../../core/libs/prx/libSceNpSessionSignaling/Export.cpp) (libSceNpSessionSignaling) - names and NIDs are present in the [PS5 3.20 export inventory](https://github.com/DNNDHH/PS5-3.20_Libs/blob/b2a77c09cd71c01f34c790cfbe98c751a13262ad/libSceNpSessionSignaling.c) and the [13.60 inventory](https://github.com/xdCloudy/PS5-13.60-Function-Stub-Library/blob/bfec40deb4c47a17d7603ee2bc79aa6862c0c56b/data/firmware-13.60/libscenpsessionsignaling-58c8806476.jsonl), but no credible prototypes were found. The parameterless declarations are import-resolution placeholders, not an ABI claim, and they still throw through `NotImplemented_nid_no_patch`.

- [sceNpSessionSignalingInitializeWithPort, sceNpSessionSignalingSetCustomProperty and sceNpSessionSignalingRegisterInternalCallback](../../../core/libs/prx/libSceNpSessionSignaling/Export.cpp) - signatures from the 11.00 wrappers. Initialize (`0xab80`) passes port 0x217b and reserved 0 to the initializer at vtable slot 0x10; InitializeWithPort (`0xab40`) forwards `(param, port, reserved)` there too, but the initializer's validation is unmeasured; the host opens no socket and accepts both. SetCustomProperty (`0xb3c0`) checks init, null property and context, then calls slot 0x78 with the opaque pointer and copies the returned dword to the optional previous output; GetCustomProperty (`0xb470`) calls slot 0x80 and copies its dword to the optional output. This establishes the 32-bit previous/output exchange, not the internal four-byte load, so the host models one 32-bit value. RegisterInternalCallback stores both pointers without invoking them; the callback signature is unknown.

- [sceNpSessionSignalingGetMemoryInfo and sceNpSessionSignalingGetConnectionStatistics](../../../core/libs/prx/libSceNpSessionSignaling/Export.cpp) (libSceNpSessionSignaling) - the wrapper checks initialization (0x80553301) and a null output (0x80553303) before delegating. The host stores the pool size from initialization and reports zero used and peak sizes because it allocates no signaling pool, and reports all connection statistics as zero because no connection ever activates. The console's actual usage and statistics values were not measured.

- [sceNpSessionSignalingGetCustomProperty and sceNpSessionSignalingSetCustomProperty](../../../core/libs/prx/libSceNpSessionSignaling/Export.cpp) (libSceNpSessionSignaling) - the host keeps one 32-bit custom property per context. Get allows a null output and returns the current value; Set rejects a null property pointer, returns the previous value through the optional output and stores the new value. Reusing a destroyed context slot clears the property and both callback pointers, so a new context starts from the same state as a fresh slot. The input width is inferred from the wrapper's opaque pointer and the 32-bit previous/getter exchange described above, not measured on a console.

- [sceNpSessionSignalingRegisterInternalCallback](../../../core/libs/prx/libSceNpSessionSignaling/Export.cpp) (libSceNpSessionSignaling) - stores the callback and user-data pointers in the context and never invokes them. Null pointers are accepted, as the wrapper does not check them, and the call returns 0 after forwarding to the internal object regardless of its result. The callback signature is unknown.
