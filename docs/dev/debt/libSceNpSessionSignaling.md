- [sceNpSessionSignalingCreateJoinActivate and sceNpSessionSignalingJoinActivate](../../../core/libs/prx/libSceNpSessionSignaling/Export.cpp) (libSceNpSessionSignaling) - the signatures come from the supplied firmware 11.00 module, read from disassembly, not measured on a console: CreateJoinActivate takes a session id, a group-id output and an optional connection-id output; JoinActivate adds a parameter block whose first byte must be nonzero, as the module checks. The session-id format, the parameter block beyond its first byte and the service error codes are not established.

- [sceNpSessionSignalingInitializeWithPort, sceNpSessionSignalingSetCustomProperty and sceNpSessionSignalingRegisterInternalCallback](../../../core/libs/prx/libSceNpSessionSignaling/Export.cpp) - Initialize (`0xab80`) and InitializeWithPort (`0xab40`) reach manager vtable slot 0x10 (`0x1c7c0`): it rejects a null parameter, a second initialization and a failed pool, uses the low 16 bits of the port and accepts any reserved value; the host opens no socket and ignores both. SetCustomProperty (`0xb3c0`) checks init, null property and context, then calls slot 0x78 (`0x114c0` -> `0x14420`), which applies `strnlen` to the property pointer and exchanges a dword; the four-byte load/store is unverified, so the host refuses a valid request with `NotImplemented_nid_no_patch`. GetCustomProperty (`0xb470`) calls slot 0x80 (`0x11500` -> `0x14630`) and returns the fresh-context zero. RegisterInternalCallback stores both pointers without invoking them; the callback signature is unknown.
