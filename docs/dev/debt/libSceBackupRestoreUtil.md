# libSceBackupRestoreUtil technical debt

### Unknown function info

- [sceBackupRestoreUtilCalcRequiredSize, sceBackupRestoreUtilGetRestoreFailedTitles](../../../core/libs/prx/libSceBackupRestoreUtil/Export.cpp) have unknown signatures and behaviour. The parameterless `int` declarations are import-resolution placeholders, not confirmed ABI signatures, and throw through `NotImplemented_nid_no_patch`. Only the names and NIDs are established by the [13.60 export inventory](https://github.com/xdCloudy/PS5-13.60-Function-Stub-Library/blob/bfec40deb4c47a17d7603ee2bc79aa6862c0c56b/data/firmware-13.60/libscebackuprestoreutil-78effa9f1f.jsonl).
- [sceBackupRestoreUtilCancelBackupData, sceBackupRestoreUtilCancelRestoreData, sceBackupRestoreUtilDeleteBackupData, sceBackupRestoreUtilGetRequiredSize, sceBackupRestoreUtilGetTitles, sceBackupRestoreUtilInitialize and sceBackupRestoreUtilTerminate](../../../core/libs/prx/libSceBackupRestoreUtil/Export.cpp) (libSceBackupRestoreUtil) - names and NIDs are present in the [PS5 3.20 export inventory](https://github.com/DNNDHH/PS5-3.20_Libs/blob/b2a77c09cd71c01f34c790cfbe98c751a13262ad/libSceBackupRestoreUtil.c), but no credible prototypes were found. The declarations have no parameters solely to resolve known imports; this is not an ABI claim and callers must not call them until signatures are verified
- [The uninitialized answers](../../../core/libs/prx/libSceBackupRestoreUtil/Export.cpp) (libSceBackupRestoreUtil) - 12 backup, restore, progress, information and cancel exports return `0x81300000`, only the 32-bit result being claimed, because `sceBackupRestoreUtilInitialize` throws and the library is never initialized here. In firmware 13.42's `libSceBackupRestoreUtil.sprx` (SHA-256 `7bd336b468f2ace0b5e9959535ff79543a3b68bc6e0d5738c2b00445a1e71aec`), read from disassembly and not run on a console, each loads the pointer at `0xc018` first and returns `0x81300000` when it is null. It lies beyond its segment's file data, so it starts null; `sceBackupRestoreUtilInitialize` passes its address on at `0xb5c` and `sceBackupRestoreUtilTerminate` clears it. Names, signatures and the error's name are unverified.
