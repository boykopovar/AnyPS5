- [Thick SW_4KB_S_X volumes](../../../core/libs/prx/libSceAgcDriver/Graphics/src/TextureTiling.cpp) have not been measured on console hardware. Other thick swizzle modes outside the supported families throw. DCC and CMASK fast clears of mipmapped volumes also throw because their metadata layouts have not been established. The supported layout follows [AMD PAL c5e80007](https://github.com/GPUOpen-Drivers/pal/blob/c5e800072a32f68b6ccc4422936d96167c6e0728/src/core/imported/addrlib/src/gfx10/gfx10addrlib.cpp), using the GFX10 non-RB+ 16-pipe `GFX10_SW_4K_S3_X_PATINFO` equations for 1, 2, 4, 8 and 16-byte elements, including packed mip tails.

- [Native multisample color publication](../../../core/libs/prx/libSceAgcDriver/Graphics/src/MultisampleTarget.cpp) does not provide automatic shader-buffer publication, cached draw-recipe routing, general metadata or depth publication. Concurrent unsynchronized guest writes during commit, console equivalence and large-title costs remain unverified. Explicit calls and the guest-memory read guard commit uncompressed single-layer R_X snapshots through writable registered mappings and write tracking before retiring the native owner and guards. Committed reads without the ordinary flush hook still run this guard. Pending writes, overlapping owners, unsupported metadata and recursive publication in recorder completions throw; snapshot readback restrictions remain.
