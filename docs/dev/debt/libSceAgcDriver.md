- [Thick SW_4KB_S_X volumes](../../../core/libs/prx/libSceAgcDriver/Graphics/src/TextureTiling.cpp) have not been measured on console hardware. Other thick swizzle modes outside the supported families throw. DCC and CMASK fast clears of mipmapped volumes also throw because their metadata layouts have not been established. The supported layout follows [AMD PAL c5e80007](https://github.com/GPUOpen-Drivers/pal/blob/c5e800072a32f68b6ccc4422936d96167c6e0728/src/core/imported/addrlib/src/gfx10/gfx10addrlib.cpp), using the GFX10 non-RB+ 16-pipe `GFX10_SW_4K_S3_X_PATINFO` equations for 1, 2, 4, 8 and 16-byte elements, including packed mip tails.

- [Native multisample color publication](../../../core/libs/prx/libSceAgcDriver/Graphics/src/MultisampleTarget.cpp) does not model PM4 draw-key/variant selection, fixed-function vertex/index consumers, dynamic BDA, general metadata/depth publication or arbitrary recorder reuse. Console equivalence, concurrent unsynchronized guest writes during commit and large-title costs remain unverified. Explicit calls, CPU reads and logical read-only shader buffers commit uncompressed single-layer R_X snapshots through writable registered mappings and write tracking before retiring native ownership and guards. Device draws cover immutable-variant recipe replay and moved read-only fragment inputs. All writable bindings are checked before any publication; unsupported metadata, conflicting owners, pending writes, another active recorder on the same device and completion recursion throw.
