# libSceFios2 technical debt

### Silent stubs

- [sceFiosDLLInitialize, sceFiosDLLTerminate, sceFiosInitialize, sceFiosTerminate, sceFiosIsInitialized, sceFiosIsIdle, sceFiosCancelAllOps and sceFiosCloseAllFiles](../../../core/libs/prx/libSceFios2/Export.cpp) (libSceFios2) - AnyPS5 runs no FIOS2 worker pool, cache or overlay filesystem. Module entry points and initialize/terminate succeed without host setup; `sceFiosIsInitialized` reports whether initialize ran without terminate, and `sceFiosIsIdle` reports the same because no asynchronous operations are queued. Cancel-all and close-all succeed with nothing to cancel or close. Signatures are still the parameterless import placeholders in Export.cpp; console behaviour is unmeasured. Retail packages such as CUSA02636 bundle `libSceFios2.prx` for import resolution

- [sceFiosSuspend, sceFiosResume, sceFiosGetSuspendCount, sceFiosIsSuspended and sceFiosShutdownAndCancelOps](../../../core/libs/prx/libSceFios2/Export.cpp) (libSceFios2) - with no worker queue, suspend depth is tracked in a host counter only: each suspend increments it, each resume decrements it without going below zero, shutdown-and-cancel clears it, and terminate clears it with initialize state. Nothing is paused because there is no FIOS2 backend. Console suspend semantics and error codes are unmeasured; signatures remain parameterless import placeholders
