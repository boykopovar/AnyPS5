# libSceJobManager technical debt

### Functional

- [sce::Job::JobManager](../../../core/libs/prx/libSceJobManager/Export.cpp) submits commands as work becomes runnable rather than encoding ahead with the rewind protocol recovered from PPSA06888's module (offsets 0x2210 and 0x2650). Commands are recycled after a completed wait. Command capacity is a separate bound from the dispatch count: the native size query measures one register and a 31-character marker, then its exhaustion callback at 0x29d0 traps instead of growing storage. The fallback throws. Original-module execution with the host AGC builders accepts two dispatches with 255 registers and 65,535-character markers, then traps on a third. Console timing equivalence remains unverified.
- [JobManager state](../../../core/libs/prx/libSceJobManager/Export.cpp) keeps scheduling state and nodes on the host heap; only the header, compute commands and completion labels occupy the caller's block. Blocks smaller than 0x2d8 bytes throw. Worker spin and persistent-thread settings do not affect scheduling. Factory priorities above one, use after sequence destruction and shutdown from the manager's own worker throw. New API calls concurrent with shutdown are unverified; shutdown with outstanding compute-sequence work throws.
- [JobManager initialization and profiling](../../../core/libs/prx/libSceJobManager/Export.cpp) omit `_sceUlobjmgrRegisterObject`, `_sceUlobjmgrUnregisterObject` and the `sceRazorCpuJobManager*` calls. Initialization returns zero instead of the registration import's result (`BG26hBGiNlw`). Kernel resource-creation failures throw after cleanup; the original does not check every thread or attribute creation result. Vtable order has been checked, but no calling title or PS5 timing equivalence has been tested.
- [JobManager node exhaustion](../../../core/libs/prx/libSceJobManager/Export.cpp) lets Wait retire work without allocating a pool node. The original Wait allocates a node and spins until another sequence releases one; exhaustion without such a release stalls. Failed sequence opens consume their factory slot in both implementations.
