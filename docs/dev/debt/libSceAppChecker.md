# libSceAppChecker technical debt

### Unknown function info

- [sceAppCheckerAbort, sceAppCheckerExecute and sceAppCheckerExecuteEx](../../../core/libs/prx/libSceAppChecker/Export.cpp) (libSceAppChecker) - names and NIDs are present in the [aerolib symbol database](https://github.com/zecoxao/sce_symbols/blob/master/aerolib.csv) and are attributed to this module by `sceAppChecker` symbol prefix; the library is absent from the PS5 3.20 export inventory and the [13.60 inventory](https://github.com/xdCloudy/PS5-13.60-Function-Stub-Library/tree/bfec40deb4c47a17d7603ee2bc79aa6862c0c56b/data/firmware-13.60), so the pairing is not firmware-verified and no credible prototypes were found. In a firmware 13.42 dump no module defines or imports the three NIDs; the name appears only in `libSceSysmodule.sprx` and in `SceShellCore.elf`, which lists `libSceAppChecker.prx`, a file that dump lacks. The declarations have no parameters solely to resolve imports; this is not an ABI claim and callers must not call them until signatures are verified
