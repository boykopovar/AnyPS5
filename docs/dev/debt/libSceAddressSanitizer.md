# libSceAddressSanitizer technical debt

### Functional

- [__asan_malloc, __asan_calloc, __asan_realloc, __asan_reallocalign, __asan_memalign, __asan_aligned_alloc, __asan_posix_memalign, __asan_free, __asan_malloc_usable_size, __asan_memcpy, __asan_memmove, __asan_memset](../../../core/libs/prx/libSceAddressSanitizer/Allocator.cpp) (libSceAddressSanitizer) forward to the guest libc entry points in [`prx/libc/src/FileAndHeap.cpp`](../../../core/libs/prx/libc/src/FileAndHeap.cpp), so the module and the title share one heap and either can free the other's pointer. Nothing is added around the allocation, so `__asan_get_allocated_begin` answers the pointer and `__sanitizer_get_allocated_size` answers libc's usable size, not the requested size.
- [__asan_report_error, the __asan_report_load, __asan_report_store and __asan_report_exp families, __asan_report_present, __asan_get_report_*](../../../core/libs/prx/libSceAddressSanitizer/Report.cpp) (libSceAddressSanitizer) record the address, type, size and expected value of the last report and pass a description to the callback set by `__asan_set_error_report_callback`, then return instead of ending the title as a console runtime does, because this module raises no report of its own.

### Silent stubs

- [__asan_load1, __asan_load2, __asan_load4, __asan_load8, __asan_load16, __asan_loadN, __asan_store1, __asan_store2, __asan_store4, __asan_store8, __asan_store16, __asan_storeN and their _noabort and exp forms](../../../core/libs/prx/libSceAddressSanitizer/Shadow.cpp) (libSceAddressSanitizer) report nothing: there is no shadow byte to read, so an access past the end of an allocation is not detected and an exp form's expected value is ignored. Closes when: shadow memory exists.
- [__asan_address_is_poisoned, __asan_region_is_poisoned, __asan_poison_memory_region, __asan_unpoison_memory_region, __asan_poison_stack_memory, __asan_unpoison_stack_memory, __asan_alloca_poison, __asan_allocas_unpoison, __asan_poison_intra_object_redzone, __asan_unpoison_intra_object_redzone, __asan_set_shadow_00 to __asan_set_shadow_07 and __asan_set_shadow_f1, _f2, _f3, _f5, _f8](../../../core/libs/prx/libSceAddressSanitizer/Shadow.cpp) (libSceAddressSanitizer) record no poison: the predicate answers 0 for every address, the region lookup answers null, the rest do nothing. Allocations carry no redzone, so heap-buffer-overflow, use-after-free, double-free and container-overflow go unreported. Closes when: shadow memory exists.
- [__asan_stack_malloc_0 to __asan_stack_malloc_10, __asan_stack_malloc_always_0 to _10, __asan_stack_free_0 to __asan_stack_free_10, __asan_get_current_fake_stack, __asan_addr_is_in_fake_stack](../../../core/libs/prx/libSceAddressSanitizer/Shadow.cpp) (libSceAddressSanitizer) answer null and do nothing: there is no fake stack, so instrumented code keeps locals on its own stack and stack-buffer-overflow and use-after-return go unreported. Closes when: a fake stack exists.
- [the __ubsan_handle_* family without the _abort suffix](../../../core/libs/prx/libSceAddressSanitizer/Ubsan.cpp) (libSceAddressSanitizer) print no diagnostic and let execution continue, where a UBSan build names the source location and the check that failed. The `_abort` forms, which the compiler expects not to return, call `abort()`. Closes when: the diagnostic and the options string are reproduced.
- [__asan_describe_address, __sanitizer_symbolize_pc, __sanitizer_symbolize_global, __sanitizer_print_stack_trace, __sanitizer_cov_dump, __sanitizer_dump_coverage, __sanitizer_dump_trace_pc_guard_coverage, __sanitizer_annotate_contiguous_container](../../../core/libs/prx/libSceAddressSanitizer/Control.cpp) (libSceAddressSanitizer) return without effect: there is no symbolizer to name an address with and no coverage buffer to dump, and the contiguous-container annotation is not tracked. Closes when: a symbolizer and a coverage buffer exist.
- [__asan_init, __asan_init_v5, __asan_handle_no_return, __asan_before_dynamic_init, __asan_after_dynamic_init, __asan_register_globals, __asan_unregister_globals, __asan_register_elf_globals, __asan_unregister_elf_globals, __asan_register_image_globals, __asan_unregister_image_globals, __asan_version_mismatch_check_v6, _v7, _v8, __sanitizer_malloc_hook, __sanitizer_free_hook, __sanitizer_purge_allocator, __sanitizer_sandbox_on_notify](../../../core/libs/prx/libSceAddressSanitizer/Control.cpp) (libSceAddressSanitizer) keep only the state the runtime reports: initialization is recorded once and the global, elf and image flags make a repeated registration a no-op. Nothing is poisoned, purged or reported.

### Unknown function info

- [__asan_current_error_report, __asan_current_error_report_size, __ubsan_current_error_report, __ubsan_current_error_report_size, __ubsan_get_current_report_data](../../../core/libs/prx/libSceAddressSanitizer/Export.cpp) (libSceAddressSanitizer) throw: no published prototype, because the UBSan report buffer is internal to compiler-rt. Closes when: a compiler-rt header for the version the titles were built with, or a firmware module, establishes the parameter list and the returned buffer.
- [__asan_get_alloc_stack, __asan_get_free_stack, __asan_destroy_fake_stack, __asan_update_allocation_context](../../../core/libs/prx/libSceAddressSanitizer/Export.cpp) (libSceAddressSanitizer) throw: the first two are deprecated in compiler-rt with parameter lists that differ between versions, the third has no fake stack to destroy, and the fourth is internal with no published parameter list. Closes when: a fake stack and allocation stacks are recorded and the prototypes are established.
- [__asan_get_shadow_mapping](../../../core/libs/prx/libSceAddressSanitizer/Export.cpp) (libSceAddressSanitizer) throws: the compiler-rt scale and offset would invite a caller to read a shadow this module never maps, and a zero mapping would answer the memory itself, so neither is the truth. Closes when: shadow memory is reserved and its range is decided.
- [__sanitizer_annotate_double_ended_contiguous_container, __sanitizer_verify_double_ended_contiguous_container, __sanitizer_double_ended_contiguous_container_find_bad_address](../../../core/libs/prx/libSceAddressSanitizer/Export.cpp) (libSceAddressSanitizer) throw: the double-ended container interface is newer than the single-ended one the rest of this module follows and its declaration is not in the headers used here. Closes when: a compiler-rt header establishes it.
- [__sanitizer_get_current_allocated_bytes, __sanitizer_get_free_bytes, __sanitizer_get_heap_size, __sanitizer_get_unmapped_bytes](../../../core/libs/prx/libSceAddressSanitizer/Export.cpp) (libSceAddressSanitizer) throw: the guest heap is libc's and exposes none of these counters, so zero would be a false answer rather than an empty one. Closes when: libc exports its allocator statistics or this module keeps its own accounting.
- [__asan_option_detect_stack_use_after_return, __ubsan_vptr_type_cache](../../../core/libs/prx/libSceAddressSanitizer/Export.cpp) (libSceAddressSanitizer) throw: both are data objects in the real runtime, read directly by instrumented code, and both are declared as parameterless functions here, so a guest load of the symbol would read code bytes rather than the intended value. Closes when: the export inventory can carry a data export with a known size and ownership.
