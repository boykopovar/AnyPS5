- [All 90 exports](../../../core/libs/prx/libSceDataTransfer/Export.cpp) (libSceDataTransfer) - the library orchestrates console-to-console migration: the `Request*PS4` and `Request*PS5` calls drive a transfer from a source console, the `Target*` calls serve the receiving one, and the `EventIs*`/progress calls report that session's state, over a private LAN protocol whose activation, SSO-ticket, reboot-handshake and eth0/IPv6-readiness steps no public source documents. Argument counts, output shapes and result codes are still unrecovered — the readable 13.42 module is unanalysed beyond one export — and a host has no peer console to run the other endpoint against. Nothing can be implemented honestly before that module is analysed or a console is measured; unknown: every signature and the whole session state machine.
