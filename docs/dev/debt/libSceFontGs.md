# libSceFontGs technical debt

### Unknown function info

- [sceFontSelectGraphicsGnm](../../../core/libs/prx/libSceFontGs/Export.cpp) (libSceFontGs) - throws for index 0 and returns `nullptr` for other indices. The PS4 10.71 body (offset 0x4090) returns a static backend table for index 0; its entries are not mapped, and the host `libSceFont` graphics device does not consume it.

### Not console-verified

- [sceFontGraphicsGnmSurfaceInit](../../../core/libs/prx/libSceFontGs/Export.cpp) (libSceFontGs) - transliterated from the PS4 10.71 `libSceFontGs.sprx` body (offset 0x41e0) and its call tree: the DataFormat builder and channel getter (0x21970, 0x21c40), the Gnm `Texture::init` path (0x21f80, 0x21a60, 0x223e0), the surface tiling computation (0x25e90 with 0x25ce0, 0x25e00, 0x27390, 0x27420, 0x274d0) and the base-address setters (0x202f0, 0x22d40, 0x23060). The GPU mode comes from `sceKernelIsNeoMode`, as on the PS4. The expected bytes in `GuestFontGsGnm.cpp` come from running the 10.71 machine code off-console, and the port matched it byte for byte on about 55 million base and Neo configurations. On a PS4 Pro with firmware 10.71 in base mode, the console's own `sceFontGraphicsGnmSurfaceInit` produced the same return code and all 0x100 bytes for the six test configurations; Neo mode was not measured on the console. Only the paths SurfaceInit can reach are ported: the texture description it builds always has one fragment, one mip level, depth 1, pitch 0 and no flags, so the PS4 helpers 0x22550 and 0x22910 and the fragment, mip, pitch and block-compressed branches of the tiling computation are left out. The tiling branch for a macro tile larger than 1 KiB (0x266bc) throws through `NotImplemented_nid_no_patch`; no tile mode and element size SurfaceInit accepts reaches it.
- [sceFontGraphicsGnmDrawupFillTextureImage, sceFontGraphicsGnmDrawupFillTexturePattern, sceFontGraphicsSequenceGetGnmCommandsForChain and sceFontGraphicsSequenceGetGnmCommandsForSubmit](../../../core/libs/prx/libSceFontGs/Export.cpp) (libSceFontGs) - transliterated from the PS4 10.71 `libSceFontGs.sprx` bodies (offsets 0x40a0, 0x4150, 0x4580 and 0x4640; the names hash to `UsBLoyXsQZs`, `uksHKVEsxu4`, `NtbMKwRg6qg` and `DI4LrTUrD04`). They match the `libSceFontGs.native` AGC bridges except for the surface tag 0x48 and that the two sequence getters pass every error to `sceFontGraphicsReportError`. The sequence getters were matched by single PS4 runs on prepared sequences without a GPU submission; the drawup bridges and the PS5 exports with these NIDs were not checked on a console.
