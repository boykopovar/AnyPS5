# libSceJson2 technical debt

SDK 5/6 below refer to the application compatibility SDK queried by `sceKernelGetCompiledSdkVersion` (process-parameter offset `0x10`). The PS5 SDK field at `0x14` and the console firmware version are distinct.

Reference-backed exact-bit tests cover signed underflow, subnormals, normal boundaries, large finite values and overflow across special-float modes. These results intentionally retain the reference rounding, which differs from standard correctly rounded conversion. Formatting still uses locale-independent `to_chars` with 17 significant digits for modern settings; broader formatting equivalence remains unverified.
