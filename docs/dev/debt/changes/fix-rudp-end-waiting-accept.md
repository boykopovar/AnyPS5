# libSceRudp

## change [sceRudpPollDestroy and sceRudpEnd]

- [sceRudpPollDestroy and sceRudpEnd](../../../core/libs/prx/libSceRudp/Export.cpp) (libSceRudp) - unmeasured: a call on a poll while `sceRudpPollDestroy` drains it, which here already answers as for a destroyed poll (`0x8077001F`); real-kernel wake and timeout races are untested too. `sceRudpInit` waits for a draining `sceRudpEnd` ([13.42 disassembly](https://github.com/boykopovar/AnyPS5/issues/13682#issuecomment-6906135610)). The rest follows the [detailed firmware 13.42 report](https://github.com/boykopovar/AnyPS5/pull/10954#issuecomment-6399054346), which ran the module under an emulator with imports stubbed, not on a console: `sceRudpPollDestroy` woke both waiters of a poll with `0x80770014` and returned 0 only after both had left the wait, and `sceRudpEnd` did the same with one waiter. Here `sceRudpEnd` treats every waiter of every poll that way (not run). A later wait on the destroyed id returns `0x8077001F`, and after `sceRudpEnd` waits and cancels return `0x80770001`.

## change [sceRudpAccept]

- [sceRudpAccept](../../../core/libs/prx/libSceRudp/Export.cpp) (libSceRudp) - the success path never ran, since no peer connects: of its arguments the same [13.42 run](https://github.com/boykopovar/AnyPS5/issues/13682#issuecomment-6537745577), under an emulator with imports stubbed and not on a console, ran only `ctxId` and a null `newCtxId`; the types and positions of `handler`, `handlerArg`, `address`, `addressLength` and `vport` come from disassembly. After initialization it checks a negative id or a null `newCtxId` (`0x80770004`), an unknown id (`0x80770003`) and a context that is not listening (`0x80770011`). It then returns `0x80770016` while option 7 is set (the default), and otherwise waits until `sceRudpTerminate` ends the context and returns `0x80770014`, as the run did. `sceRudpEnd` wakes a waiting accept, which returns `0x80770014`, and returns only after it has left ([disassembly](https://github.com/boykopovar/AnyPS5/issues/13682#issuecomment-6906135610), not run).
