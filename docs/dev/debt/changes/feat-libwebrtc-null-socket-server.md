- [rtc::NullSocketServer constructor layout and vtable](../../../core/libs/prx/libwebrtc/src/NullSocketServer.cpp) (libwebrtc) - unchecked on the console: 40 bytes (vptr 0, null `network_binder_` 8, `rtc::Event` 8-byte guest mutex 16 and `CLOCK_MONOTONIC` cond 24, false bools 32 and 33) and a local vtable D1, D0 (unsized guest delete), `CreateSocket`, `SetMessageQueue`, `Wait`, `WakeUp`, read from [socket_server.h](https://webrtc.googlesource.com/src/+/8d78f5de6c27b2c793039989ea381f1428fb0100/rtc_base/socket_server.h), null_socket_server.h and event.h, the same at M127. The vtable, typeinfo and name NIDs (`Lb5K8k9Rr-g`, `ta9QdMAbOms`, `sT25c8f3uls`) are not among the 31 data exports, so typeinfo is null. `TimeDelta` is taken as one `int64_t` of microseconds in a register. Closes when: compared with the console.
- [rtc::NullSocketServer Wait, WakeUp and CreateSocket](../../../core/libs/prx/libwebrtc/src/NullSocketServer.cpp) (libwebrtc) - assume a build without `RTC_DCHECK_IS_ON`: `CreateSocket` returns null, and negative or infinite durations other than `PlusInfinity` reach `GetTimespec` unchecked. Otherwise the POSIX path of [null_socket_server.cc](https://webrtc.googlesource.com/src/+/8d78f5de6c27b2c793039989ea381f1428fb0100/rtc_base/null_socket_server.cc) and [event.cc](https://webrtc.googlesource.com/src/+/8d78f5de6c27b2c793039989ea381f1428fb0100/rtc_base/event.cc), the same at M127, with their notices: `Wait` returns true and never warns. `ScopedYieldPolicy::YieldExecution` is skipped, as no named or implemented export installs a policy. Non-zero guest pthread or clock returns, bar the cond wait's, throw; upstream aborts or ignores them. A null object throws, and an unwritable one in the constructor and destructors. Closes when: the build flags are known and compared with the console.
