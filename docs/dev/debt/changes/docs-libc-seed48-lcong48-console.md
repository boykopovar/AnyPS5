# libc

## change [seed48 and lcong48]

- [seed48 and lcong48](../../../core/libs/prx/libc/src/Random.cpp) (libSceLibcInternal, implemented in libc) follow the console's `libSceLibcInternal.sprx` (SDK 4.5x build of `J03950001`, 0x6F460 and 0x6F420): the multiplier and addend are shared by the whole `rand48` family, including `erand48`, `nrand48` and `jrand48` on a caller's seed; `lcong48` sets them with the seed, and `srand48` and `seed48` restore 0x5DEECE66D and 0xB. Unlike FreeBSD, `seed48` returns a static copy of the new seed rather than the previous one. A PS5 payload process (firmware 11.60) measured the console's `libSceLibcInternal` in agreement: `seed48` returned one static object holding the new seed each time, `lcong48` with multiplier 3 and addend 5 changed the next `lrand48` values, `srand48` after it restored the standard pair, and five `lrand48` values after each match this library's formula; a null argument and a title process are unmeasured.
