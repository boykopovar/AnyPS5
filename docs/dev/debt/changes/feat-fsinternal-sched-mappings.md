With a non-negative result, `ToPriority` returns its low byte and `ToSlot` returns `(result >> 16) & 0xff` when that field is 1 or 2. A negative result, or a slot field other than 1 or 2, reaches a module-internal helper with code `0x16`; the host throws through `NotImplemented_nid_no_patch` instead. Read from disassembly, not measured on a console.
