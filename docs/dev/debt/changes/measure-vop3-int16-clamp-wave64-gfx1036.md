# shader

## change [VOP3 16-bit integer binary clamp]

- [VOP3 16-bit integer binary clamp](../../../core/shader/recompiler/RdnaDecoder/src/RdnaVectorOpDecoder.cpp) (`v_mul_lo_u16`, `v_lshrrev_b16`, `v_ashrrev_i16`, `v_max_u16`, `v_max_i16`, `v_min_u16`, `v_min_i16`, `v_lshlrev_b16`) (shader recompiler) - the decoder accepts the VOP3 clamp modifier bit on non-packed 16-bit integer multiply, shifts and min/max without effect; measured on RDNA2 (gfx1036, AMD Windows driver 31.0.22044.1) in wave32 over 64 input rows, the bit changes none of the eight 32-bit results: `v_mul_lo_u16` keeps the low 16 bits of an overflowing product instead of saturating, while `v_add_nc_u16` with clamp saturates on the same part; in wave64 the test's 32 rows repeated over 64 lanes give the same results and match `Expected`, and RDNA2 ISA Table 88 is cited only as an encoding reference pointer. Checked by [Vop3Integer16Clamp](../../../core/libs/prx/libSceAgcDriver/tests/execution/Vop3Integer16Clamp.cpp); console comparison on gfx1013 remains unmeasured.
