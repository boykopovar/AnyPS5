# libkernel_sys

## change [scePthreadBarrier*, scePthreadBarrierattr*, scePthreadGetcpuclockid, scePthreadGetconcurrency and sceKernelMsync]

- [scePthreadBarrier*, scePthreadBarrierattr*, scePthreadGetcpuclockid, scePthreadGetconcurrency and sceKernelMsync](../../../core/libs/prx/libkernel_sys/Export.Discovery.cpp) (libkernel_sys) call libkernel's `pthread_barrier*`, `pthread_getcpuclockid`, `pthread_getconcurrency` and `msync` and wrap POSIX errors as `0x80020000 | errno`; signatures follow the [Orbital type database](https://github.com/AlexAltea/orbital/blob/master/tools/ida/db_types.json). The barrier name limit is firmware-dependent: 11.60 refused a 40-character `scePthreadBarrierInit` name with `ENAMETOOLONG`, a PS5 Pro payload process (13.60) accepted 31, 32, 39 and 40; count 0 answers `EINVAL`; titles were not measured. `scePthreadGetcpuclockid` answers plain `CLOCK_THREAD_CPUTIME_ID` (14) for any live thread on 13.60; AnyPS5 returns its registry's bit-31 id instead - not aligned. `scePthreadGetconcurrency`: 0 for level 0, `0x80020000 | level` otherwise (11.60; 0 re-confirmed on 13.60); titles may differ.
