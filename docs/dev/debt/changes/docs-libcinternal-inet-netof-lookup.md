A null text throws std::invalid_argument. On a PS5 (firmware 11.60, payload process; a title process may differ) `dlsym` found none of the four names or of their `__` forms bare or with the suffixes `_40` to `_90` in libSceLibcInternal.sprx, libkernel.sprx or RTLD_DEFAULT, while the control names `snprintf_s` and `inet_ntoa_r` were found bare in libSceLibcInternal.sprx (libc.sprx could not be opened). The NIDs named in this entry are the hashes of these eight names. That is a lookup result only: no function was called, so the console's results are not measured, and a title process was not looked at.
