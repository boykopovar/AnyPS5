## change jnf and ynf](../../../core/libs/prx/libc/src/Math.cpp)

- [acoshl, asinhl, atanhl, hypotl, log1pl, log2l, lgammal and tgammal](../../../core/libs/prx/libc/src/Math.cpp) (libc) return the host C library's results, not those of the console's own code, so the last bits can differ. `tgammaf` delegates to the host's double `tgamma` as FreeBSD 11 does ([`s_tgammaf.c`](https://github.com/freebsd/freebsd-src/blob/stable/11/lib/msun/src/s_tgammaf.c)), except above 171.63 (`x / 0`) and below -190 (a signed zero without underflow), where it follows msun's `b_tgamma.c` as the bundled `libc.prx` does, then restores the sign of a zero result for negative non-integer inputs from the parity of `floor(-x)`; nine title-bundled `libc.prx` builds return that sign for underflowing inputs, where Windows UCRT can return the opposite sign ([#9707](https://github.com/boykopovar/AnyPS5/issues/9707)). As in the console's `libSceLibcInternal.sprx` (SDK 4.5x build of `J03950001`, 0x56410), `lgammal` does not store the sign in `signgam`; `hypotl` returns infinity for an infinite argument even when the other is a NaN, as C11 F.10.4.3 requires. [hypot3, hypot3f and hypot3l](../../../core/libs/prx/libc/src/Math.cpp) follow that module (0x51D30, 0x520D0, 0x52420): the first NaN of x, y and z is returned unchanged, any infinity gives positive infinity, a zero argument gives the two-argument hypot of the other two, and otherwise the largest magnitude is combined with the hypot of the other two

## add Functional

- [jnf and ynf](../../../core/libs/prx/libc/src/Jnf.cpp) (libc) follow FreeBSD msun's [`e_jnf.c` at release/10.0.0](https://github.com/freebsd/freebsd-src/blob/release/10.0.0/lib/msun/src/e_jnf.c), calling this libc's msun `j0f`, `j1f`, `y0f`, `y1f` and `logf`. Console provenance, FMA and nonzero exceptions are unverified. `ynf(+-0)` preserves negative infinity without changing errno or exception flags. Finite negative arguments return a positive quiet NaN without errno or invalid, as `y0f`/`y1f` do; NaNs propagate first and negative infinity gives an invalid NaN. Order arithmetic wraps explicitly at 32 bits: `INT_MIN` skips recurrence, giving `j1f(abs(x))` or `y1f(x)` for finite nonzero x. Large orders can take billions of steps or fail to terminate, as upstream does. Closes when: the console float functions are measured or disassembled.
