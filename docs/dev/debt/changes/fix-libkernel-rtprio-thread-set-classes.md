- [rtprio_thread, pthread_setconcurrency, pthread_getconcurrency](../../../core/libs/prx/libkernel/Pthread/Posix/Thread.cpp) (libkernel) - an accepted `RTP_SET` throws: idle 960, type 11 or a caller-credential-dependent normal set 615 to 895, real-time 256 to 767 or credential-dependent 896 to 959. The rest return `EINVAL` (the firmware 13.60 kernel's `rtp_to_pri`, kernel-13.60 @ 0xffffffff9e890790, normal type 3 gated @ 0xffffffff9e8906af). Function 2 returns `ESRCH` as a PS5 payload measured, though 13.60 gives an uncredentialed caller `EINVAL` (@ 0xffffffff9e890596). `RTP_LOOKUP` reports the policy's type (10 or 2) and priority, 3 with 0 without real-time attributes (unmeasured); function 5 `EINVAL`. A missing thread gives `ESRCH` before a null `rtprio` gives `EFAULT`. `pthread_setconcurrency` stores 0 or more and returns `EINVAL` below 0, as libthr does.
