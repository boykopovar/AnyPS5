# libkernel

## change [Map hints inside a reservation](../../../core/libs/prx/libkernel/DirectMemory/DirectMemory.cpp) (libkernel)

- [Map hints inside a reservation](../../../core/libs/prx/libkernel/DirectMemory/DirectMemory.cpp) (libkernel) - `sceKernelMapDirectMemory` and the flexible, anonymous and file-backed maps place a mapping without `MAP_FIXED` at its hint address when the whole range lies in a range still reserved by `sceKernelReserveVirtualRange`, as if `MAP_FIXED` were set. A hint is first rounded up to the requested alignment, as FreeBSD 11.4 `vm_map_find` searches upward from it; `MAP_ALIGNED_SUPER` aligns to 2 MiB only maps of 2 MiB or more, as [`pmap_align_superpage`](https://github.com/freebsd/freebsd-src/blob/8c639945a44588f6cfdddfb057bb5aad88735da0/sys/amd64/amd64/pmap.c#L7649) does for offset 0; file offsets are not matched to it. Taken from PPSA01474, which maps its heaps by hint inside a 64 GiB reservation and uses the hint addresses; not measured on the console. Hints outside a reservation, or over a range that is partly mapped, stay hints

## add Silent stubs

- [Unmodelled mmap flags](../../../core/libs/prx/libkernel/DirectMemory/PosixMemory.cpp) (libkernel) - fail with `EOPNOTSUPP`, which no source gives: any bit mmap does not model, for example 0x4, 0x8, 0x20, 0x40, 0x100, 0x8000, `MAP_STACK`, `MAP_GUARD` and `MAP_32BIT`, `MAP_EXCL` or neither `MAP_SHARED` nor `MAP_PRIVATE` on a file map, and `MAP_NO_OVERWRITE` or `MAP_NO_COALESCE` on an anonymous map. FreeBSD 11.4 [`kern_mmap_fpcheck`](https://github.com/freebsd/freebsd-src/blob/8c639945a44588f6cfdddfb057bb5aad88735da0/sys/vm/vm_mmap.c#L226-L299) drops 0x20 and 0x40 and goes on with the call, returns `EINVAL` for the other bits outside its mask, accepts `MAP_STACK`, `MAP_GUARD`, `MAP_32BIT` and `MAP_EXCL | MAP_FIXED`, and checks the descriptor (`EBADF`) before `EINVAL` for a file map of neither kind; the console's answer is not measured

## add Unknown function info

- [mmap flags](../../../core/libs/prx/libkernel/DirectMemory/PosixMemory.cpp) (libkernel) - unmeasured on a console; they follow FreeBSD 11.4 [`kern_mmap`](https://github.com/freebsd/freebsd-src/blob/8c639945a44588f6cfdddfb057bb5aad88735da0/sys/vm/vm_mmap.c#L226-L299) and [`vm_mmap_object`](https://github.com/freebsd/freebsd-src/blob/8c639945a44588f6cfdddfb057bb5aad88735da0/sys/vm/vm_mmap.c#L1555-L1576). `MAP_SHARED | MAP_ANON` maps private zero-filled memory (shared only across `fork`), uncharged to the flexible budget like the private map, with the `MAP_FIXED` and `MAP_EXCL` handling of the fixed anonymous mmap. `MAP_ALIGNED(n)` other than `MAP_ALIGNED_SUPER` is `EINVAL` for n below 14 (16 KiB pages, inferred) or from 64; without `MAP_FIXED` the map is placed 2^n aligned, `ENOMEM` when none fits, as for every n from 47. `MAP_HASSEMAPHORE`, `MAP_NOSYNC`, `MAP_NOCORE` and `MAP_PREFAULT_READ` are accepted; that `sceKernelMapFlexibleMemory` refuses them (measured) says nothing of mmap
