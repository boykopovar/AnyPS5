# libSceIcu

## change [ICU collator exports]

- [ICU collator exports](../../../core/libs/prx/libSceIcu/Collator.cpp) are not compared with a console. `ucol_open`, `ucol_close`, `ucol_getAttribute`, `ucol_setAttribute`, `ucol_getStrength`, `ucol_setStrength`, `ucol_strcoll` and `ucol_strcollUTF8` call ICU 78.1 ([ucol.cpp](https://github.com/unicode-org/icu/blob/049e0d6a420629ac7db77256987d083a563287b5/icu4c/source/i18n/ucol.cpp)) over the root data and every locale tailoring built from `3rdparty/icu`. A handle `ucol_open` did not return or already closed, unreadable guest memory, a null `UErrorCode` and a locale ID without a terminator in 4096 bytes throw. `ucol_getReorderCodes` and `ucol_getTailoredSet` implement only ICU 68.2's early returns ([ucol.cpp](https://github.com/unicode-org/icu/blob/84e1f26ea77152936e70d53178a816dbfbf69989/icu4c/source/i18n/ucol.cpp) 372-382, 602-612). Closes when: compared with the console for the same locales.

## change [recovered inventory exports]

- The 134 [recovered inventory exports](../../../core/libs/prx/libSceIcu/RecoveredInventory.cpp) have unverified parameters, return types, callback ABIs and behavior. The 44 left in that file throw through `NotImplemented_nid_no_patch` as parameterless `int` placeholders; the `ubidi` and `ucsdet` ones are in [Bidi.cpp](../../../core/libs/prx/libSceIcu/Bidi.cpp) and [CharsetDetection.cpp](../../../core/libs/prx/libSceIcu/CharsetDetection.cpp). The [13.60 inventory](https://github.com/xdCloudy/PS5-13.60-Function-Stub-Library/blob/226383a7fa4b1275d6cebf61eb1c1e7ca7b58bcb/data/firmware-13.60/libsceicu-9790ee85e3.jsonl) establishes only name/NID bindings. The [module map](https://github.com/boykopovar/ps5-nid-map/blob/cc1d586fddab576a520f226da6b2632b031e6d09/data/Modules/libSceIcu.inc) assigns all 134 NIDs to logical `libSceIcu` in `libSceIcu.sprx`. Recovered `ucfpos`, `uset` and `uiter` groups are excluded. Console ABI, behavior and title compatibility remain unverified.
