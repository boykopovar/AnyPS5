## add Unknown function info

- [sceFsInitMountPprPkgOpt](../../../core/libs/prx/libSceFsInternalForVsh/Export.cpp) (libSceFsInternalForVsh) - what the fields at 0x58 to 0x77 mean is unknown; it sets them to 0x30, 0, -1 and 0, as firmware 13.60 (`0x43f80`) does. It also zeroes 0x00 to 0x57 and 0x80 to 0x8f, sets the lvd block size at 0x78 to 0x10000 and leaves 0x7c to 0x7f. The option is 0x90 bytes; `sceFsMountPprPkg` reads the image path at 0x00, the second mount path at 0x08, the budget id at 0x10, the image offset at 0x18, the superblock offsets at 0x20 and 0x30, the type at 0x38, the first mount path at 0x80 and the second image at 0x88. Read from disassembly, not measured on a console.

## add Functional

- [sceFsMountPprPkg and sceFsUmountPprPkg](../../../core/libs/prx/libSceFsInternalForVsh/Export.cpp) (libSceFsInternalForVsh) - throw where firmware 13.60 reaches the kernel. The mount attaches the image file from its offset through `/dev/lvdctl` (ioctl `0xc0286d00`), then calls `nmount` with `fstype` `ppr_pfs`, the 0x90-byte option as `ppkg_opt` and `sblock_offset` = superblock offset - image offset; the unmount calls `statfs`, `unmount` and `sceFsLvdDetach`. The host has no lvd or PFS layer. The checks before that return what the module returns: `0x80020016` for a null option, output, image or mount path, and `0x16` for a type outside 0x101 to 0x10d or equal to 0x107, 0x108 or 0x10b. Read from disassembly, not measured on a console. Closes when: package images can be mounted on the host.
