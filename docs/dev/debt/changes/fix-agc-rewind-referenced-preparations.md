# libSceAgcDriver

## change [Registration preparation at submit]

- [Registration preparation at submit](../../../core/libs/prx/libSceAgcDriver/Execution/src/Driver/Queues/Submission.cpp) (libSceAgcDriver) - `Driver::Submit` waits only for pool-held preparations of programs it binds (`*_PGM_LO/HI` by `SET_SH_REG` or `SET_SH_REG_INDIRECT`), including when the submission ends in a REWIND (the pre-REWIND commands are scanned the same way; the released REWIND tail waits again for the programs it binds when the queue worker copies it). It waits for all queued ones if a pair is half written, a draw (dispatch) has no graphics (compute) pair written before it, a list has an invalid register, or a predicated or `COND_EXEC`-guarded write sets a program register. Not covered: a program re-registered at an address an earlier submission bound, used without rebinding while this one writes another graphics pair; its first draw waits in the queue worker, unbounded (74 s for the largest shader seen). Longest submit wait on Ghost of Yōtei, cold: 3.2 s, 7 s total over 900 s (RTX 4090). Goat Simulator 3 (PPSA04159)'s 10 s margin and how often titles write half a pair are not measured.
