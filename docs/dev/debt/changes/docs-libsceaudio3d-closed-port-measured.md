# libSceAudio3d

## change [sceAudio3dObjectReserve](../../../core/libs/prx/libSceAudio3d/Export.cpp) (libSceAudio3d) - returning `0x80EA0004`
- [sceAudio3dObjectReserve](../../../core/libs/prx/libSceAudio3d/Export.cpp) (libSceAudio3d) - returning `0x80EA0004` (`AUDIO3D_ERROR_INVALID_PARAMETER`) when the `object_id` output pointer is unwritable via `GuestCopyOut_nid_no_patch` is a host-safety fallback preserving caller errno; console hardware fault behavior on unmapped memory is unmeasured. A PS5 (firmware 11.60, payload process; a title process may differ) returned `0x80EA0002` (`AUDIO3D_ERROR_INVALID_PORT`) before `sceAudio3dInitialize` for the ports 0 and -1 with valid output buffers, which stayed unchanged, and for the port 0 with null output pointers and with the unmapped address 0x10, in every case without a fault; the answer for the port comes first, so the pointer question of this entry is not reached and stays unmeasured.
