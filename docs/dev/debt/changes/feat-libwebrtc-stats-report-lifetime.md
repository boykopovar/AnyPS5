# libwebrtc

## add Public source implementations

- [webrtc::RTCStatsReport::begin, end and ConstIterator destructor](../../../core/libs/prx/libwebrtc/src/RtcStatsReport.cpp) (libwebrtc) - nothing is checked on the console. Adapted from [rtc_stats_report.cc](https://webrtc.googlesource.com/src/+/8d78f5de6c27b2c793039989ea381f1428fb0100/stats/rtc_stats_report.cc), [ref_counted_base.h](https://webrtc.googlesource.com/src/+/8d78f5de6c27b2c793039989ea381f1428fb0100/api/ref_counted_base.h) and [ref_counter.h](https://webrtc.googlesource.com/src/+/8d78f5de6c27b2c793039989ea381f1428fb0100/rtc_base/ref_counter.h), the same at M127, with their WebRTC notices and BSD licence at the top of the file. `begin` and `end` return the iterator through the hidden result pointer and add a reference to the non-virtual count at 0; the destructor of an iterator with a report drops that reference. Dropping the last one deletes the report as `~RTCStatsReport` does: the `stats_` nodes in post-order, each `RTCStats` through its deleting destructor, vtable slot 1, then the id string, the node and the report through guest `operator delete`. A moved-from iterator releases nothing. Null results or reports, a null begin node, a count at or below 0, and at the last reference a malformed tree, string or stats vtable throw before anything changes. Closes when: compared with the console.
