# libwebrtc

## add Public source implementations

- [webrtc::RTCStatsReport::begin, end and ConstIterator destructor](../../../core/libs/prx/libwebrtc/src/RtcStatsReport.cpp) (libwebrtc) - unchecked on the console. Null results, reports, a null begin node, a count at or below 0 on release, and at the last release a malformed tree, string or stats vtable throw before anything changes. As upstream, `begin` and `end` add a reference without checking it; the caller must hold one. Adapted from [rtc_stats_report.cc](https://webrtc.googlesource.com/src/+/8d78f5de6c27b2c793039989ea381f1428fb0100/stats/rtc_stats_report.cc), [ref_counted_base.h](https://webrtc.googlesource.com/src/+/8d78f5de6c27b2c793039989ea381f1428fb0100/api/ref_counted_base.h) and [ref_counter.h](https://webrtc.googlesource.com/src/+/8d78f5de6c27b2c793039989ea381f1428fb0100/rtc_base/ref_counter.h) at M127. The last release deletes the `stats_` nodes in post-order, each `RTCStats` through vtable slot 1, then ids, nodes and the report. Closes when: compared with the console.
