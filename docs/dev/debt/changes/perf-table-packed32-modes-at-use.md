# shader

## add Functional

- [Image-table images list the 10_11_11 and 2_10_10_10 UInt and UNorm modes](../../../core/shader/recompiler/Optimization/src/ResourceMaterializer.cpp) only after a captured table column held one of those formats (37, 41, 44, 48). The trigger is per table column: any program whose snapshot includes a flagged column is prepared again with the modes, even if it never selects that record, and a memoised column carries its flag to every program that reads it. The preparation is done twice and not kept across runs; a normalized array view is scanned by its raw words; the bindless heap path of #20519 never reads the records and so never triggers. The older packed modes and direct images stay eager, and `APS5_EAGER_UNSIGNED_PACKED32_MODES` restores the eager lists. Closes when: the modes are chosen per table and format, or one sample operation serves all conversion modes.
- [The packed 32-bit unsigned retry flag](../../../core/shader/recompiler/Optimization/src/ResourceMaterializer.cpp) is one per program: after one retry every table image of that program lists the packed modes, not only the image that reads the flagged column. An image whose table operation is unsupported lists no runtime modes and is left out of the trigger. Closes when: the modes are chosen per image.
- [A table column that holds only the UNORM codes (37, 44) on an image that is not sRGB-decode compatible](../../../core/shader/recompiler/Optimization/src/ResourceMaterializer.cpp) still triggers one preparation retry although the flagged mode list adds no usable mode for that image. Closes when: the trigger checks the modes the flag would add.
- [A memoised table column keeps its packed 32-bit unsigned flag](../../../core/shader/recompiler/Optimization/src/ResourceMaterializer.cpp) as computed under the GCN guest shader setting of the capture that sealed it, and the column key does not include that setting. The flag is right only while the setting stays fixed for the whole process, which holds for the emulator and the shader replay tool; a test that switches it must not reuse a table address. Closes when: the column key includes the setting, or the flag is computed per read.
