# libSceAjm.native

## add Functional

- [AJM job buffers](../../../core/libs/prx/libSceAjm.native/src/Ajm.cpp) (libSceAjm.native) - what the console's AJM does with an inaccessible buffer is not measured. Jobs read inputs through `GuestCopyIn_nid_no_patch` and write PCM output and sideband through `GuestCopyOut_nid_no_patch`, keeping errno. A single-buffer input is read through one copy of up to 16 KiB from where the job reads, never past the stated size; when that copy fails, the job reads only the pieces each codec parses (its lengths or headers, then its packets, superframes or frames), so a stated size past the readable data still decodes. A multi-buffer input is joined first. PCM output and sideband are written once, at the end of the job. An Opus packet that runs into unreadable memory ends the job with `AJM_RESULT_INVALID_DATA` and nothing consumed (Super Meat Boy 3D's FMOD submits such jobs). Any other unreadable input, or an unwritable output or sideband, throws `std::runtime_error` from `sceAjmBatchStart`.
