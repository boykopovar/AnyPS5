# libSceMetadataReaderWriter

## add Functional

- [Metadata::getFieldCount, ParserInterface copies and Value::operator=](../../../core/libs/prx/libSceMetadataReaderWriter/Export.cpp) - read from the 11.00 and 13.40 module bodies. `getFieldCount` reads the field-container pointer at object+0x28, answers 0 when null and otherwise returns the 32-bit count at container+4. The two `ParserInterface` copy constructors copy the interface; 13.40 copies 0x38 bytes and 11.00 0x30, so the implementation follows 13.40. `Value::operator=` copies the 4-byte type and the qword at +8, then the qword at +0x10 when the type is 0..3, and returns the destination; a type above 3 leaves +0x10 and the padding at +4 unchanged, as both modules do; the 13.40 log is not reproduced. Checked guest copies preserve `errno`; a null or unreadable pointer throws `invalid_argument`, where the console faults. The layouts and `getFieldCount`'s result type are inferred, not measured on a console.
