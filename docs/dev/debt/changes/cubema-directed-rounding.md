# shader

## change [output modifier]

- The [output modifier](../../../core/shader/recompiler/Translation/src/TranslationContext/OperandAccess.cpp) (`mul:2`, `mul:4`, `div:2`) follows the shader's float mode as measured on RDNA2 (gfx1035): the hardware applies it only with IEEE mode off and output denormals of the result's precision flushed (bit 1 of the `FLOAT_MODE` denormal field clear), and ignores it otherwise. On f32 results it is applied as the hardware does with f32 denormals flushed; a shader without a known float mode is translated with IEEE mode off and f32 denormals flushed, the mode titles use. On f16 and f64 results it is applied with f16/f64 denormals flushed and ignored otherwise; f16 and f64 output scaling is established on hardware (f16 on RADV NAVI24 and RX 9070 XT; both on gfx1031, including +0 for a zero or denormal result as on f32), while the ordering against the `FP16_OVFL` clamp remains unmeasured. `v_cubeid_f32`, `v_cubesc_f32`, `v_cubetc_f32` and `v_cubema_f32`, measured on RDNA2 (gfx1036) with `DX10_CLAMP`=1, apply it whenever IEEE mode is off, in all four f32 denormal modes (`v_mul_f32_e64` in the same measurement follows the rule above), with the same bit-level result as the f32 path, and ignore it with IEEE mode on; clamp is applied after it. Only round to nearest even is modelled for the scaling: in the other round modes (measured with IEEE mode off) gfx1036 rounds an overflow of the `mul:2` and `mul:4` scaling as the mode says (to the largest finite value when rounding toward zero), where the translation gives infinity; RDNA1 (gfx1010, RX 5700 XT, AMD Windows driver 32.0.21045.5002) does the same on `v_cubema_f32 mul:2`. `v_cubema_f32`'s own result, twice the major axis value with denormal inputs flushed in every f32 denormal mode, is rounded in the `FLOAT_MODE` f32 round mode, declared or set by `s_round_mode`: an overflow gives the largest finite value of its sign when the mode rounds toward zero for that sign, and a zero result takes the sign of the major axis value when rounding toward negative infinity and is +0 otherwise. Measured on gfx1010 over 2788 inputs in all four round modes and f32 denormal modes at IEEE 0 and 1, and over 16728 rows with `s_round_mode`: no mismatch; the PS5's gfx1013 is not measured.
