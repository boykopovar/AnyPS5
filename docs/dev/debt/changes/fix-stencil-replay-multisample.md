# libSceAgcDriver

## change [Stencil reference export replay]

- [Stencil reference export replay](../../../core/libs/prx/libSceAgcDriver/Graphics/src/Draw.cpp) on devices without `VK_EXT_shader_stencil_export` replays the low eight bits of the values proved from constant, select and phi exports, with an export proved on every kept path. An export the prover cannot bound replays all 256 eight-bit values, one pass per value per triangle (logged once per process). It records instances, then their triangles, then the reference classes of each triangle. One pipeline filters fragments at shader termination against a dynamic push value before late stencil and depth tests. The [Vulkan stencil-reference replacement rule](https://docs.vulkan.org/refpages/latest/refpages/source/FragStencilRefEXT.html) discards bits above the attachment's stencil width; supported stencil attachments have eight bits. Numeric subgroup observations throw except bounded own-lane mask plumbing, group control with kept-lane and derivative-helper coverage proved, and first-lane reads of values built only from user data, the shader base, descriptors, constant and scalar memory reads and `IsRuntimeUniformOp`'s operations or float compares and reciprocals on them, which every lane of a wave holds alike. WQM inputs must exclude helper contributions (a ballot of the active lanes, as in an EXEC copy, covers whole quads and is accepted), since [non-quad subgroup operations may treat helpers as inactive](https://docs.vulkan.org/glslext/latest/glslext/khr/GL_KHR_shader_subgroup.html). Readonly guarded SRT reads may report internal host faults, and read-only BDA reads may report faults; these draws wait and check faults before publishing results, and loops throw. Indirect draws, restart, strips, fans, tessellation, mesh, early tests, ordered pixel execution, guest shader memory writes, other fault-producing memory access, clocks, primitive ID inputs, attachment feedback and pipeline face/channel splits throw. Multisampled targets replay like single-sample ones (a killed fragment writes none of its samples, per-sample shading compares per invocation, sample reordering wraps the whole render pass); not measured on console hardware. A sampled depth surface counts as feedback only when its range overlaps a bound depth or stencil plane. An exhausted stage push range throws. Equivalence to console ordering has not been measured on console hardware.
