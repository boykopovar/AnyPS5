# libSceZlib

## change [`sceZlibInflate`]

- [`sceZlibInflate`](../../../core/libs/prx/libSceZlib/Export.cpp) copies compressed input through checked guest reads and publishes decoded bytes and the request ID through checked guest writes. An unreadable source, a destination that cannot receive the produced bytes or an unwritable request ID returns `0x81120016` without queuing a request. This is a host-safety fallback; the console's response to inaccessible non-null buffers is unmeasured. Input is supplied to zlib in 16 KiB chunks so a very large declared source does not require a matching host allocation. Checked copies preserve host errno. The entire request ID range is checked before writing decoded bytes; a concurrent mapping change can still make the final ID write fail after the destination changes. A destination address that is not a multiple of 2 KiB returns `0x81120016`; the console's response to an unaligned destination is unmeasured. Validation order for multiple invalid arguments is not console-measured.
