- [Versioned std::__sce_v2::filesystem primitives](../../../../core/libs/prx/libc/src/VersionedFilesystem.cpp) (libc) - `_Open_dir` now reports a failed first `readdir_r` through its `error` reference and closes the handle, where it used to report 0 and return a null handle, so `directory_iterator` became an end iterator with no error. The console loops over `sceKernelGetdents` itself and maps its errors, as the `libc.prx` bundled with PPSA28416 shows; the exact code the console writes for a failed first read has not been measured, so the `readdir_r` status is passed through unchanged. Null arguments are not handled here: the export takes references, and the guest never passes null.
