# libSceVrTracker

## add Functional

- [sceVrTrackerGetTime and sceVrTrackerGpuWait once initialized](../../../core/libs/prx/libSceVrTracker/Export.cpp) (libSceVrTracker) - not measured on a PS5: the answers once `sceVrTrackerInit` has succeeded follow [shadPS4](https://github.com/shadps4-emu/shadPS4/blob/8d50471b7dc141dd700b51276b8edd1f293bce26/src/core/libraries/vr_tracker/vr_tracker.cpp#L222-L255), a PS4 implementation. `sceVrTrackerGetTime` returns `ARGUMENT_INVALID` (`0x81260806`) for a null pointer and otherwise writes `sceKernelGetProcessTime` (L227-L230); the PS5 module's clock is unverified. `sceVrTrackerGpuWait` returns `ARGUMENT_INVALID` for a null parameter or a `size` other than 32 and otherwise `NOT_EXECUTE_GPU_SUBMIT` (`0x81260815`) (L249-L254), reading only `size`. shadPS4 marks it a stub that never submits; here too no submission can precede the wait, as `sceVrTrackerGpuSubmit` throws once initialized, and the answer after a submission is unknown. Closes when: measured on a PS5
- [sceVrTrackerGpuSubmit once initialized](../../../core/libs/prx/libSceVrTracker/Export.cpp) (libSceVrTracker) - throws for every argument once `sceVrTrackerInit` has succeeded. [shadPS4](https://github.com/shadps4-emu/shadPS4/blob/8d50471b7dc141dd700b51276b8edd1f293bce26/src/core/libraries/vr_tracker/vr_tracker.cpp#L234-L242) returns `ARGUMENT_INVALID` there without reading the parameter, a stub that relies on its camera never returning frame data, so it settles neither the argument checks of the 552-byte and 648-byte parameters nor the submission. Closes when: measured on a PS5
- [sceVrTrackerGetTime and sceVrTrackerGpuWait guest pointers](../../../core/libs/prx/libSceVrTracker/Export.cpp) (libSceVrTracker) - returning `ArgumentInvalid` (`0x81260806`) for an unwritable time pointer or an unreadable wait parameter `size` via `GuestCopyOut_nid_no_patch` and `GuestCopyIn_nid_no_patch` while preserving errno is a host-safety fallback with console behavior unmeasured.
