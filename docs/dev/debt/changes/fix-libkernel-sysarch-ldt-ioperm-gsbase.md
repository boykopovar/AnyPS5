# libkernel

## change XFPUSTATE operations 11 and 132 throw for a non-null argument

- [sysarch](../../../core/libs/prx/libkernel/System/src/Process.cpp) (libkernel) - copying out XFPUSTATE state (operations 11 and 132) throws, as do the unmeasured lengths 513 to 1023 (PS5 firmware 12.70: 132 accepted lengths 0, 64, 128, 256 and 512, gave EINVAL for 1024 to 8192 and EFAULT for null arguments and addresses; 11 gave EFAULT for a null argument). Lengths from 1024 give EINVAL, 0 returns 0, a null address EFAULT. LDT operations 0 and 1 fail with EINVAL unread: the 13.60 kernel refuses any operation below 2 (kernel-13.60 @ 0xffffffff9e86b062). 3, 4 and 10 follow FreeBSD 11.4 with no I/O permission map; 4 fails with `EPERM`, as `priv_check(PRIV_IO)` does in a jail (not measured). Numbers absent from its switch give EINVAL, confirmed on the console for 2, 5, 6, 12, 127, 133, 134, 1000 and -1 with null arguments; other absent numbers follow FreeBSD's [default case](https://github.com/freebsd/freebsd-src/blob/release/11.0.0/sys/amd64/amd64/sys_machdep.c#L324-L325), unmeasured.
