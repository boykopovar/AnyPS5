# libSceNet

## add Unknown function info

- [sceNetGetSystemMemInfo, sceNetGetAppMemInfo, sceNetGetIfListOnce, sceNetGetRouteInfo, sceNetGetArpInfo, sceNetAllocateAllRouteInfo, sceNetAllocateAllRouteInfo6, sceNetGetIfListEx](../../../core/libs/prx/libSceNet/Export.cpp) (libSceNet) - the records these exports read or write are not defined: `NetSystemMemoryInfo`, `NetAppMemoryInfo`, `NetInterfaceStatistics`, `NetRouteInfo` and `NetArpInfo` are forward-declared only in [Net.hpp](../../../core/libs/prx/libSceNet/include/Net.hpp), with no field size, offset or record stride, so implementing any of them would invent the ABI. `sceNetGetIfListEx` writes the defined `NetInterfaceInfo`, but the meaning of its `flags` is unknown. The memory exports are absent from the PS4 firmware 10.71 and 11.00 modules, so there is no PS4 writer to port; the route, ARP and interface-once exports pass their PS4 10.71 argument checks and then read `__sys_netcontrol` or a PF_ROUTE sysctl, records the host cannot supply. All throw. Closing this needs a PS5 `libSceNet.sprx` disassembly of each writer to recover the struct layout and the record count and stride, plus a payload probe of the written fields; a host data source alone cannot close it because the byte layout and the kernel records are what is missing.
