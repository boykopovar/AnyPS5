# libSceXml

## add Functional

- [Writable `Document` lifecycle and conversion](../../../core/libs/prx/libSceXml/src/Document.cpp) ([WritableTree](../../../core/libs/prx/libSceXml/src/WritableTree.cpp)) (libSceXml) - `initialize` and `setWritable` back a mutable DOM tree behind a 72-byte block from the initializer's allocator; not measured on a PS5. `initialize` returns `0x80850001` on allocation failure, `0x80850002` without an initializer and `0x00850003` if already running; node and string storage lives on the host heap rather than `MemAllocator`, so allocation counts differ. `setWritable` returns `docRoot` (`NodeId`, type 0) via the hidden result pointer and detaches the writable generation from its `DocumentBuilder`, invalidating prior read-only `NodeId`s. Closes when: measured on a PS5.
- [Writable `Document` tree and attribute mutations](../../../core/libs/prx/libSceXml/src/WritableTree.cpp) (libSceXml) - `createElement`, `createTextNode`, `addElementChild`, `insertNode`, `removeChild`, `recurseDelete`, `setText`, `setAttribute`, `setAttrValue`, `setAttributeList`, `removeAttribute` and `removeAttributes` follow Sony `bXCe` and Vita `libSceXml` conventions; not measured on a PS5. Return ABI (`NodeId` sret vs `int`), `removeChild(child, parent)` order, `insertNode` inserting after `refChild` (first if null), `recurseDelete` ignoring attached nodes, `setAttrValue` no-oping when absent, `setText` on elements, 128-attribute limits and `0x80850202`/`0x8085020a` codes are unverified on PS5. `importNode` and `importParent` still throw because candidate references conflict. Closes when: measured on a PS5.
