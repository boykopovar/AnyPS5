# libSceLibreSsl

## add Unknown function info

- [EC_KEY_get0_private_key, EC_KEY_set_private_key](../../../core/libs/prx/libSceLibreSsl/src/Ec.cpp) - not checked on the console. A copy over 8388607 words or a failed allocation gives 0 but queues no error. A stored key that is negative or has a zero top word within the order's word count throws in `EC_KEY_check_key`, `ECDSA_sign` and `ECDH_compute_key`; one that is zero or at least the order also throws in the last two. LibreSSL computes with both. Copying, freeing, reuse by `EC_KEY_generate_key` and its `BN_rand_range` word count follow LibreSSL 2.5.4's [libcrypto](https://github.com/libressl/openbsd/tree/2e2c612066aa993717528a0249c15c51128d61cb/src/lib/libcrypto) `ec/ec_key.c`, `bn/bn_lib.c` and `bn/bn_rand.c`, with no group or range check on setting. A null `EC_KEY`, a negative word count or capacity, null words, self-assignment or shared words throw. Alias guards also reject cases where LibreSSL flags prevent frees

## change [EC_GROUP_new_by_curve_name, EC_GROUP_free, EC_GROUP_get_degree, EC_KEY_new, EC_KEY_new_by_curve_name, EC_KEY_free, EC_KEY_set_group, EC_KEY_get0_group, ECDSA_size]

- [EC_GROUP_new_by_curve_name, EC_GROUP_free, EC_GROUP_get_degree, EC_KEY_new, EC_KEY_new_by_curve_name, EC_KEY_free, EC_KEY_set_group, EC_KEY_get0_group, ECDSA_size](../../../core/libs/prx/libSceLibreSsl/src/Ec.cpp) (libSceLibreSsl) - not checked on the console. They follow LibreSSL 2.5.4's [ec](https://github.com/libressl/openbsd/tree/2e2c612066aa993717528a0249c15c51128d61cb/src/lib/libcrypto/ec) and [ecs_lib.c](https://github.com/libressl/openbsd/blob/2e2c612066aa993717528a0249c15c51128d61cb/src/lib/libcrypto/ecdsa/ecs_lib.c) over mbedtls, which has 11 of LibreSSL's 90 curves (NIDs 409, 415, 711 to 716, 928, 932, 934). The other 79 throw; other NIDs return null without queuing `EC_R_UNKNOWN_GROUP`. Keys use libSceLibreSsl3's EC layout and `EC_KEY_new`'s defaults. `EC_KEY_set_group` to another curve throws on a key that has a public key. Setting a key's own group keeps it, where LibreSSL frees it first. Null groups and keys throw where LibreSSL dereferences them
