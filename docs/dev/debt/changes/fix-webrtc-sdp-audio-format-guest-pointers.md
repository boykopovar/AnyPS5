# libwebrtc

## change [webrtc::AudioEncoder::EncodedInfo constructor, copy constructor, copy assignment and destructor]

- [webrtc::AudioEncoder::EncodedInfo constructor, copy constructor, copy assignment and destructor](../../../core/libs/prx/libwebrtc/src/AudioEncoderEncodedInfo.cpp) (libwebrtc) - the layout and allocation follow firmware 13.42's module code read in #18830, not run on a console: a 0x68-byte leaf whose first 0x18 bytes are upstream's [EncodedInfoLeaf](https://webrtc.googlesource.com/src/+/8d78f5de6c27b2c793039989ea381f1428fb0100/api/audio_codecs/audio_encoder.h), then unnamed bytes 0x18-0x63 that the constructor leaves alone and a byte at 0x64 it clears; `redundant` is three pointers at 0x68 to 0x68-byte leaves. Storage is guest `malloc`/`free`; 4096 bytes or more take 0x27 extra bytes, a 32-byte-aligned start and the raw pointer at -8. Not modelled: the module's mspace pointer, unread. Assignment was not read: it copies the leaf and reuses capacity that fits, else allocates the source count. A null, unreadable or unwritable object, unreadable source leaves or out-of-order `redundant` pointers throw `std::invalid_argument` without changing the target. Closes when: the unnamed fields and assignment are read.
