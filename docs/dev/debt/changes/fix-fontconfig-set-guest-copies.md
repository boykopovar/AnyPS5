# libfontconfig

## change [Font sets and object sets]

- [Font sets and object sets](../../../core/libs/prx/libfontconfig/Sets.cpp) come from disassembly of firmware 13.42 `libfontconfig.sprx` (SHA-256 `74d7414445f8687c1d22a92fa3c994d2e5fa304e6699dc84dcc5459af7da8472`), not the stock desktop layout; the console version, opaque layouts and allocation-failure behavior are unverified. Sets and element pointers are read through `GuestCopyIn_nid_no_patch` and written through `GuestCopyOut_nid_no_patch`, so an unmapped or unwritable set reports through `NotImplemented_nid_no_patch` with errno kept instead of faulting, and null destroy or null add return where the firmware would touch pointers. A destroy that cannot read a later element has destroyed the earlier ones; an add that cannot write the set back leaves the caller's record and array as they were, releases the duplicate and frees any buffer it grew. Capacity is stored in bytes, grows by sixteen pointers, stops at 1024 entries, and every insertion duplicates the caller's pattern.
