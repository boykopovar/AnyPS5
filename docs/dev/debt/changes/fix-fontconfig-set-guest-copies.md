# libfontconfig

## change [Font sets and object sets]

- [Font sets and object sets](../../../core/libs/prx/libfontconfig/Sets.cpp) are based on disassembly of firmware 13.42 `libfontconfig.sprx` (SHA-256 `74d7414445f8687c1d22a92fa3c994d2e5fa304e6699dc84dcc5459af7da8472`), not the stock desktop Fontconfig layout. Font-set capacity is stored in bytes, grows by sixteen pointers, and stops at 1024 entries; each insertion duplicates the caller's pattern. Object sets allocate their pointer arrays inline and preserve the original argument order with duplicated names. Host safety returns on null destroy and null add, where the firmware accesses pointers without such checks. `FcFontSetAdd`, `FcFontSetDestroy` and `FcObjectSetDestroy` read the caller's set and each element pointer through `GuestCopyIn_nid_no_patch` and write through `GuestCopyOut_nid_no_patch`, so an unmapped or unwritable set reports through `NotImplemented_nid_no_patch` with errno kept instead of faulting the host; a destroy that cannot read a later element has destroyed the earlier ones, and an add that cannot write the set back has written the slot whose duplicate it then releases. `FcObjectSetBuild` still reads its name arguments through `CopyObject`. Console runtime behavior beyond disassembly is not verified.
