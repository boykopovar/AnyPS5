# libSceIcu

## change [UTF-8 and UTF-16 conversions]

- [UTF-8 and UTF-16 conversions](../../../core/libs/prx/libSceIcu/UtfConversions.cpp) - the four non-lenient conversions follow ICU 78.1 [ustrtrns.cpp](https://github.com/unicode-org/icu/blob/049e0d6a420629ac7db77256987d083a563287b5/icu4c/source/common/ustrtrns.cpp), whose text for them differs from ICU 68.2 only in pointer and type spellings: strict and substitution handling, the bytes a malformed sequence swallows, the substitution count and destination length stores that precede termination, and error preservation. The source is read through `GuestCopyIn` in page-sized chunks and every output through `GuestCopyOut`; an unreadable source or a refused output write throws `std::invalid_argument` before any output changes, a null error pointer and a result above `INT32_MAX` still throw. `u_strFromUTF8Lenient` keeps its direct reads until #22460 rewrites it. PS5 equivalence is unverified: console behavior and the reads it faults on are unmeasured. Closes when: compared with the console.
