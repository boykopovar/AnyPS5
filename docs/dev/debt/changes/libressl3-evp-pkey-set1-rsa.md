# libSceLibreSsl3

## change [EVP_PKEY_new, EVP_PKEY_free, EVP_PKEY_set1_RSA, EVP_PKEY_copy_parameters]

- [EVP_PKEY_new, EVP_PKEY_free, EVP_PKEY_set1_RSA, EVP_PKEY_copy_parameters](../../../core/libs/prx/libSceLibreSsl3/src/PkeyLifecycle.cpp) - not checked on a console. Native allocation and release follow the 32-byte [LibreSSL 4.0.0 layout and p_lib.c](https://github.com/libressl/openbsd/tree/ce488b78e0bd994780569df718596b9776ff681a/src/lib/libcrypto/evp). Allocation failure queues `ERR_R_MALLOC_FAILURE` in the libSceLibreSsl queue without file or line and returns null. `EVP_PKEY_free` releases `EVP_PKEY_EC` payloads through `EC_KEY_free`; final release of any other nonnull method or payload throws and restores the reference instead of calling the method. `EVP_PKEY_set1_RSA` releases an existing payload through its method callback, or through the native RSA or EC destructor for methodless objects created by the available wrappers, installs the native RSA method, and retains a nonnull RSA key. A null RSA returns zero after selecting the RSA type. A null PKEY and reference-count overflow throw instead of reproducing undefined behaviour; overflow occurs after the new pointer is assigned. `EVP_PKEY_copy_parameters` copies `EC_GROUP` for `EVP_PKEY_EC` keys through `EC_KEY_set_group`; non-EC copies throw locally. Objects from the two modules must not be mixed. Closes when: compared with the console.
