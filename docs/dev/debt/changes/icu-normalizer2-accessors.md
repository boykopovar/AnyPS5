# libSceIcu

## add Functional

- [Normalizer2 accessors](../../../core/libs/prx/libSceIcu/Normalizer2Accessors.cpp) are unverified on a console. The `Normalizer2` NFC, NFD and NFKC_Casefold getters, the `Normalizer2Factory` instance, no-op, NFKC and NFKC_Casefold getters and `getImpl`, the `Normalizer2` base `composePair`, `getCombiningClass` and `isNormalizedUTF8`, and the `Normalizer2Impl` `composePair`, `getDecomposition`, `getRawDecomposition`, `hasDecompBoundaryBefore`, `norm16HasDecompBoundaryBefore` and `ensureCanonIterData` call ICU 78.1 with its compiled-in data (Unicode 17; the console's ICU 68 has Unicode 13). The objects they return are host ICU 78.1 objects, so title code that reads their members inline with the ICU 68 layout instead of calling an export gets wrong values. `Normalizer2Factory::getImpl` on a normalizer without normalization data, such as the no-op or a filtered normalizer, is undefined in ICU and throws here. The status, length and decomposition buffer are read and written through `GuestCopyIn_nid_no_patch` and `GuestCopyOut_nid_no_patch`; ICU reads the `isNormalizedUTF8` text directly, as it does for the `unorm2_*` exports. A null or inaccessible status, length or buffer, or a null `this`, throws where the console would fault or, for the base `composePair` and `getCombiningClass`, ignore it. Closes when: compared with the console.
