## change [Unaligned 32-bit buffer atomics](../../../core/shader/recompiler/SpirvBackend/src/SpirvRuntimeBuffer.cpp)

- [Unaligned 32-bit buffer atomics](../../../core/shader/recompiler/SpirvBackend/src/SpirvRuntimeBuffer.cpp) act on the containing dword per [RDNA2 ISA](https://gpuopen.com/download/rdna2-shader-instruction-set-architecture.pdf) §8.1.7 alignment mode DWORD (`SH_MEM_CONFIG.alignment_mode`): on PS5 13.40 (measured 2026-10-19 by a gfx1013 kernel in a retail title), `buffer_atomic_add` of 1 at byte offset 0x0D incremented the 0x0C dword and left neighbours unchanged. Unaligned 64-bit buffer atomics (off an 8-byte boundary) still record an unaligned BDA fault, as DWORD aligns only to 4 bytes, which host 64-bit atomics cannot address. When an unaligned V# base puts the containing dword before the first aligned bound dword, the atomic is OOB and returns 0 without writing. Covered by [BufferAtomicUnaligned.cpp](../../../core/libs/prx/libSceAgcDriver/tests/execution/BufferAtomicUnaligned.cpp).

## change [FORCE_DEGAMMA on RGBA8_UINT](../../../core/shader/recompiler/Optimization/src/ResourceMaterializer.cpp)

- [FORCE_DEGAMMA on RGBA8_UINT](../../../core/shader/recompiler/Optimization/src/ResourceMaterializer.cpp) materializes a direct image sampled only by plain biased pixel accesses as RGBA8_SRGB (both metadata and image view must become float sRGB; ignoring the bit or keeping a UINT heap is wrong) when every paired sampler sets FORCE_DEGAMMA. Accepted: 1 slice, mip 0, normalized point sampling, uniform FORCE_DEGAMMA; other accesses, mixed sampler states, indirect descriptors, and other int formats stay refused. Measured on RDNA2 gfx1036 (Win11 driver 32.0.21036.18, wave32, IEEE off, DX10 clamp on, denorms preserved, RNE, FP16 overflow off): `image_sample_b` DIM 2D on 16x16x1 RGBA8_UINT 3D T# returns int channels without the bit, vs RGBA8_UNORM-like float decoded values with it (incl. point min/max reduction and title sampler). Wave64 matches wave32 for 2D descriptors; 1-slice 3D, other filters, and PS5 gfx1013 unmeasured.

## change The scalar aperture sources [src_shared_base, src_shared_limit, src_private_base, src_private_limit]

- The scalar aperture sources [src_shared_base, src_shared_limit, src_private_base, src_private_limit](../../../core/shader/recompiler/RdnaDecoder/src/RdnaInstructionDecoder.cpp) (codes 235–238) read as 64-bit flat apertures: base = `SharedApertureHigh`/`PrivateApertureHigh` over 0, limit = same high dword over 0xffffffff, matching PS5 13.40 (measured 2026-10-19 by a gfx1013 kernel in a retail title: 0x80000000_00000000 / 0x80000000_FFFFFFFF shared, 0x70000000_00000000 / 0x70000000_FFFFFFFF private). A 64-bit read (`s_mov_b64`, 64-bit VALU source, wave64 lane mask) gets the full value and a 32-bit read gets the low dword, per LLVM `SIRegisterInfo.td`/`getSegmentAperture` and gfx1030/gfx1035 readouts ([#1190](https://github.com/boykopovar/AnyPS5/pull/1190), [#3803](https://github.com/boykopovar/AnyPS5/issues/3803)). The 32-bit read and wave address mode (assumed 64-bit, PTR32 clear) were not measured on console.

## change [Flag structurization](../../../core/shader/recompiler/ControlFlow/src/Structurizer.cpp)

- [Flag structurization](../../../core/shader/recompiler/ControlFlow/src/Structurizer.cpp) rebuilds graphs refused by all attempts (incl. irreducible/non-terminating) with one reach flag per block and one again flag per loop (`structurizeWithFlags`): each block keeps one guarded copy and each SCC becomes a loop whose single latch repeats while a back edge set its flag (~8x input blocks, 1 route var/block, trailing unreachable Return). Only unconditional top-level blocks stay unguarded, letting resource planning see skip paths and extra descriptor candidates. Attempts still run first; shared merge splitting aborts past 16x initial blocks (min 64; passing attempts grew <=10.6x on <=128-block random graphs). Single-block/round splitting hits its 4 rounds/block limit (>10 s on 9/2,000 <=128-block random graphs, max 63 s). `APS5_FORCE_STRUCTURIZER_FALLBACK=1` forces this for tests.

## change [Hull lane masks](../../../core/shader/recompiler/Optimization/src/TessellationLowering.cpp)

- [Hull lane masks](../../../core/shader/recompiler/Optimization/src/TessellationLowering.cpp) throw (`the hull program uses a lane mask other than its own lane's bit`) if reading non-self lane bits (1 invocation = 1 output control point of 1 patch). Own bit of `s_wqm_b64` over `ballot(p)` reads as p only if [QuadHelperProof](../../../core/shader/recompiler/Optimization/src/QuadHelperProof.cpp) proves quad-helper lanes (p false, neighbour p true) give identical outcome, else throws `reads its own bit of a whole-quad lane mask`. PPSA26344 02.002.000's 8 hull programs (3 OCP, NUM_PATCHES 85 -> quad spans 2 patches) lower this way (matches CPU wave model, not HW). A ballot==0 feeding only a branch whose predicate a loop phi carries reads own predicate (`v_readfirstlane_b32`/`v_cmpx_eq` waterfall runs once per invocation; loop scalar holds own pick vs console's last lane). Closes when: measured on a PS5.
