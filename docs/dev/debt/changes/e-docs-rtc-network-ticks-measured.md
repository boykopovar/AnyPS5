# libSceRtc
## change [sceRtcGetCurrentRawNetworkTick]
- [sceRtcGetCurrentRawNetworkTick](../../../core/libs/prx/libSceRtc/Export.cpp) (libSceRtc) - the console reads clock 0x13 and returns its time plus the Unix epoch in ticks, or `0x80B50001` when the clock is unsupported (errno 5). The raw network clock is not modelled; this returns the host clock. Read from the disassembly of libSceRtc.sprx on firmware 13.60. A PS5 (firmware 11.60, payload process, no network setup by the probe; a title process may differ) returned `0x80B50001` from it in the last of 5 calls (the probe logs the return code of the last call only). The output tick of `sceRtcGetCurrentNetworkTick` stayed constant over the five rounds and, judged from its difference to the current tick, is 0; the raw, ad and debug ticks equalled it in every round. A null pointer returned `0x80B50002`; the successful path was not measured.
## change [sceRtcGetCurrentAdNetworkTick, sceRtcGetCurrentDebugNetworkTick]
- [sceRtcGetCurrentAdNetworkTick, sceRtcGetCurrentDebugNetworkTick](../../../core/libs/prx/libSceRtc/Export.cpp) (libSceRtc) - the console reads clocks 0x12 and 0x11 and falls back to network clock 0x10 when either clock is unsupported. These getters use their process-local clock when it was set, otherwise they follow the process-local network clock. The firmware's unsupported-clock result is not modelled. Read from the disassembly of libSceRtc.sprx on firmware 13.60. A PS5 (firmware 11.60, payload process, no network setup by the probe; a title process may differ) returned `0x80B50001` from both getters in the last of 5 calls (the probe logs the return code of the last call only), as `sceRtcGetCurrentNetworkTick` did. That network tick stayed constant over the five rounds and, judged from its difference to the current tick, is 0; the ad and debug ticks equalled it in every round. A null pointer returned `0x80B50002` from both getters. The results do not show whether their own clocks 0x12 and 0x11 or the fall back to clock 0x10 produced the unsupported result; the successful path was not measured.
