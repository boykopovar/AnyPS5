# shader

## change [2D accesses through a 1D T#]
- [2D accesses through a 1D T#](../../../core/shader/recompiler/Optimization/src/ResourceMaterializer.cpp) have no PS5 measurement. Storage, packed/BY access, explicit-LOD comparison, bias, offsets, gradients and unsupported array forms throw. On gfx1036, #2237 and the [hardware oracle](../HW_ORACLE.md) measured mip-less loads and LZ/L/implicit compute samples ignoring v; implicit LOD follows u derivatives. On gfx1010, wave32/wave64 native R32_FLOAT/R16_UNORM C/C_LZ comparisons also ignore v: u steps 1/4/16 select mips 0/2/4, while v steps up to 64 do not change LOD. Emulated color comparisons through this pair throw. Gfx1036 2D-array L/LZ samples ignore v and slice; array loads return zero outside slice 0 and remain unsupported. Outside pixel/compute stages, implicit sampling still uses LOD zero and is unverified.

## change [3D image accesses bound to a 1D T#]
- [3D image accesses bound to a 1D T#](../../../core/shader/recompiler/Optimization/src/ResourceMaterializer.cpp) have no PS5 measurement. Only LZ, implicit sampling and mip-less loads are implemented. On gfx1010, the [hardware oracle](../HW_ORACLE.md) measured wave32/wave64 R8G8B8A8_UNORM accesses: LZ samples use u alone, including wrap/clamp/border addressing with HEIGHT/DEPTH 0 or 3. Mip-less loads use x when z is zero, ignore y, and return zero for nonzero z or out-of-range x. Implicit compute samples use u derivatives alone: steps 1/4/16 select mips 0/2/4; v/r steps do not affect LOD. Other stages still use LOD zero for implicit sampling. Explicit LOD, gradients, bias, offsets, comparison, gathers, queries and mip-bearing loads through this pair throw.

## add Functional
- [Compute implicit texture sampling](../../../core/shader/recompiler/SpirvBackend/src/SpirvImageEmitter.cpp) has no PS5 comparison; non-affine quads and masked neighbors are unmeasured on guest hardware, and the host can use different mip rounding. Inputs follow [LLVM whole-quad mode](https://llvm.org/doxygen/SIWholeQuadMode_8cpp_source.html), [RDNA2 ISA 12.16](https://gpuopen.com/download/rdna2-shader-instruction-set-architecture.pdf#page=226) and the recorded gfx1036/gfx1010 measurements. Compute uses the advertised NV derivative extension when available, otherwise KHR. Missing derivative support, incomplete quads, partial groups, table-based derivatives and multi-level emulation throw. Zero-bias minimum-LOD samples use spatial gradients. Wave64 keeps two guest lanes per invocation on subgroup32; derivative programs cannot use the spanned-wave lowering.
