# libSceNpCppWebApi

## add Functional

- [String, Vector and IntrusivePtr ownership across the arena](../../../core/libs/prx/libSceNpCppWebApi/Export.cpp) (libSceNpCppWebApi) - `String::copyFrom` releases the previous buffer through the allocator stored in the string and allocates the replacement through the string's context, inheriting the source context only when the destination had none; an empty source still adopts the context after the old buffer is released. `String::setContext` migrates a populated buffer to the new context before publishing it. `Vector::reserve` and `Vector::grow` reallocate elements through the body's context, falling back to the host allocator only for a null context; a body that already owns host storage keeps a null context when one is adopted from a source. `Vector<String>::copyFrom` resets existing elements with their own context and allocates the copied strings through the destination body. A tagged vector body released through a deleter-less string-vector `IntrusivePtr` is destroyed with the vector cleanup instead of the `String` destructor. Layouts and allocator choices are from the module and disassembly; console behavior for a context changed on a populated string or a body that inherits a context after allocating is unverified.
