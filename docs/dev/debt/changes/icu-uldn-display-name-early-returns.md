# libSceIcu

## change [recovered inventory exports]

- The 134 [recovered inventory exports](../../../core/libs/prx/libSceIcu/RecoveredInventory.cpp) have unverified parameters, return types, callback ABIs and behavior. The 43 left in that file throw through `NotImplemented_nid_no_patch` as parameterless `int` placeholders; the `ubidi` and `ucsdet` ones are in [Bidi.cpp](../../../core/libs/prx/libSceIcu/Bidi.cpp) and [CharsetDetection.cpp](../../../core/libs/prx/libSceIcu/CharsetDetection.cpp). The [13.60 inventory](https://github.com/xdCloudy/PS5-13.60-Function-Stub-Library/blob/226383a7fa4b1275d6cebf61eb1c1e7ca7b58bcb/data/firmware-13.60/libsceicu-9790ee85e3.jsonl) establishes only name/NID bindings. The [module map](https://github.com/boykopovar/ps5-nid-map/blob/cc1d586fddab576a520f226da6b2632b031e6d09/data/Modules/libSceIcu.inc) assigns all 134 NIDs to logical `libSceIcu` in `libSceIcu.sprx`. Recovered `ucfpos`, `uset` and `uiter` groups are excluded. Console ABI, behavior and title compatibility remain unverified.

## change [ICU locale display names exports]

- [ICU locale display names exports](../../../core/libs/prx/libSceIcu/LocaleDisplayNames.cpp) implement only the early returns of ICU 68.2 ([locdspnm.cpp](https://github.com/unicode-org/icu/blob/84e1f26ea77152936e70d53178a816dbfbf69989/icu4c/source/common/locdspnm.cpp): `uldn_close` 938-941, `uldn_keyValueDisplayName` 1090-1108, `uldn_localeDisplayName` 969-989, `uldn_openForContext` 924-935, `uldn_regionDisplayName` 1036-1052, `uldn_scriptDisplayName` 1009-1025). Non-null handles, valid calls, a null `UErrorCode` and every path that needs `ULocaleDisplayNames` objects and display name data throw `NotImplemented_nid_no_patch`. A failing `UErrorCode` (above zero) returns early with the status untouched; `uldn_close` ignores a null handle, and the display name exports set `U_ILLEGAL_ARGUMENT_ERROR` for a null handle or name, a null result with a positive capacity or a negative capacity. Unverified on a console. Closes when: those are implemented and compared with the console.
