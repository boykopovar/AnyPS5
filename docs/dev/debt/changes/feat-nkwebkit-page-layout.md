# libSceNKWebKit

## add Functional

- [WKPage layout, pagination, and scrollbar controls](../../../core/libs/prx/libSceNKWebKit/src/PageLayout.cpp) (libSceNKWebKit) - `WKPageAreScrollbarAnimationsSuppressed`, `WKPageFixedLayoutSize`, `WKPageGetGapBetweenPages`, `WKPageGetPageLength`, `WKPageGetPaginationBehavesLikeColumns`, `WKPageGetPaginationMode`, `WKPageGetScrollPinningBehavior`, `WKPageHasHorizontalScrollbar`, `WKPageHasVerticalScrollbar`, `WKPageSetFixedLayoutSize`, `WKPageSetGapBetweenPages`, `WKPageSetPageLength`, `WKPageSetPaginationBehavesLikeColumns`, `WKPageSetPaginationLineGridEnabled`, `WKPageSetPaginationMode`, `WKPageSetScrollPinningBehavior`, `WKPageSetSuppressScrollbarAnimations`, `WKPageSetUseFixedLayout`, `WKPageUseFixedLayout` and `WKPageWillHandleHorizontalScrollEvents` configure and query layout, pagination and scrollbar properties on the page in host memory. Upstream WebProcess IPC and rendering pipeline integrations are unmodeled.
