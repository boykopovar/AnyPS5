# libSceNKWebKit

## change [JSC::ProtoCallFrame argument accessors]

- [JSC::ProtoCallFrame argument accessors](../../../core/libs/prx/libSceNKWebKit/src/ProtoCallFrame.cpp) (libSceNKWebKit) - not compared with a console module: `argumentCount`, `argument`, `setArgument`, `clearCurrentVPC` and the copy assignment follow the pinned [PS5 ProtoCallFrame.h](https://github.com/neonmodder123/PS5-WebKit-11.x/blob/80f77e94c63ee7202eec3d4b5b1a021dd89011ba/Source/JavaScriptCore/interpreter/ProtoCallFrame.h#L35-L88) and the little-endian payload and tag of [JSCJSValue.h](https://github.com/neonmodder123/PS5-WebKit-11.x/blob/80f77e94c63ee7202eec3d4b5b1a021dd89011ba/Source/JavaScriptCore/runtime/JSCJSValue.h#L91-L110). The field setters measured offsets 0 to 32 and 48 of the 56-byte frame; `args` at offset 40 comes from that source only. As in release WebKit, indices are not bounds-checked and the count subtraction wraps. A null or unreadable frame or `args` array, or an unwritable destination, throws through `NotImplementedAt_nid_no_patch` where the console would fault. Assignment copies the members and leaves bytes 36 to 39 unchanged. Closes when: compared with a console module.
