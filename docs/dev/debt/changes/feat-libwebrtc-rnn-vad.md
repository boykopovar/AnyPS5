## add Public source implementations

- [webrtc::rnn_vad::RnnVad constructor, destructor and ComputeVadProbability](../../../core/libs/prx/libwebrtc/src/RnnVad.cpp) (libwebrtc) - layout, allocator and rounding are unchecked on the console. Adapted from M134 [rnn_vad](https://webrtc.googlesource.com/src/+/8d78f5de6c27b2c793039989ea381f1428fb0100/modules/audio_processing/agc2/rnn_vad) `rnn`, `rnn_fc`, `rnn_gru` and `vector_math`, identical at M127, and [rnnoise](https://chromium.googlesource.com/chromium/src/third_party/+/d212a71416ad7c6ceca04d6d27dfdd84fd00c04c/rnnoise/src) weights and activations, with their notices. The 536-byte object follows the headers; vectors are begin, end and capacity over host `new[]`, `FunctionView`s hold host functions. SSE2 and AVX2 dot products run portably in intrinsic order, AVX2 fused; other fused multiply-adds on the console would change last bits. Null, unreadable or unconstructed objects or inputs throw. Closes when: compared with the console.
- [rtc::Thread::IsQuitting and rtc::Thread::Restart](../../../core/libs/prx/libwebrtc/Export.cpp) (libwebrtc) - firmware 13.60 `libwebrtc.sprx` (SHA-256 `d59d0caf6967329b39201a2a0bd6df7b994516f21701b9801908db6735ae5314`) implements `IsQuitting` as a 32-bit read at `this + 0x64` and `Restart` as a 32-bit zero store at the same offset; the export NIDs match both mangled names. The host uses guest-copy helpers and throws on null or unreadable state. Thread construction, scheduling and the `Quit` wakeup remain unsupported. Not measured on a console.
- [rtc::Thread::socketserver](../../../core/libs/prx/libwebrtc/Export.cpp) (libwebrtc) - firmware 13.60 `libwebrtc.sprx` (SHA-256 `d59d0caf6967329b39201a2a0bd6df7b994516f21701b9801908db6735ae5314`) returns the socket server pointer stored at `this + 0x68`; the export NID matches the mangled name. The host uses guest-copy helpers and throws on null or unreadable state. The returned socket server's virtual methods remain unsupported. Not measured on a console.
