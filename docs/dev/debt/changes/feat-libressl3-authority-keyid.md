# libSceLibreSsl3

## change [`X509V3_EXT_d2i`]

- [`X509V3_EXT_d2i`](../../../core/libs/prx/libSceLibreSsl3/src/X509V3ExtD2i.cpp) (libSceLibreSsl3) - console ABI and allocator are unverified. The prototype and NID dispatch follow LibreSSL 4.0.0 `x509_lib.c`, `v3_lib.c` and `ext_dat.h`. Bit string, octet string, integer, enumerated, IA5, time, object, OCSP nonce, authority key identifier (90, into the 24-byte `AUTHORITY_KEYID`) and general names (85, 86) decode; otherName and ediPartyName elements, constructed strings and indefinite lengths throw. Standard methods 89, 103, 177, 290, 291, 367, 368, 371, 398, 401, 666, 747, 770, 771, 857, 1018 and 1021 throw `NotImplemented_nid_no_patch`. Malformed values return null with LibreSSL 4.0.0's reason queue for the tested vectors; directoryName content errors keep our name decoder's shorter nesting and directoryName allocation queues are unverified. Null extensions or values throw where upstream dereferences them; negative lengths return null. Closes when: compared with the console.
