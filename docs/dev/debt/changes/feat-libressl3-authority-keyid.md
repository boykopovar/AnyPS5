# libSceLibreSsl3

## change [`X509V3_EXT_d2i`]

- [`X509V3_EXT_d2i`](../../../core/libs/prx/libSceLibreSsl3/src/X509V3ExtD2i.cpp) (libSceLibreSsl3) - console ABI and allocator equivalence are unverified. The `void* (X509_EXTENSION*)` prototype and NID dispatch follow LibreSSL 4.0.0 `x509_lib.c`, `v3_lib.c` and `ext_dat.h`. BIT STRING, OCTET STRING, INTEGER, ENUMERATED, IA5STRING, GENERALIZEDTIME and OBJECT methods decode into the existing 24-byte `ASN1_STRING`/40-byte `ASN1_OBJECT` layouts; the OCSP nonce decoder copies its input unchanged. The authority key identifier (90) decodes `keyid` and `serial` into the 24-byte `AUTHORITY_KEYID`; an `issuer`, a constructed `keyid` or an indefinite length throws. Standard methods 84-87, 89, 103, 126, 143, 177, 290, 291, 367-369, 371, 398, 401, 663, 666, 747, 770, 771 and 857 throw `NotImplemented_nid_no_patch`; their decoded structures are not modelled and dynamic `X509V3_EXT_add` methods do not exist. Malformed values return null with ASN1 reason codes; queue parity is unverified. Null extensions or values and positive-length null data throw where upstream dereferences them; negative lengths return null. Closes when: compared with the console.
