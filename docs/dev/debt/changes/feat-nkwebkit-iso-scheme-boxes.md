# libSceNKWebKit

## add Functional

- [ISO schi, sinf and pssh boxes](../../../core/libs/prx/libSceNKWebKit/src/IsoSchemeBoxes.cpp) (libSceNKWebKit) - not compared with a console module. Vectors resized before a failed length check hold zeros where WTF leaves the bytes uninitialized, and `peekSystemID` can return them. The rest follows the pinned 11.x box sources such as [ISOProtectionSystemSpecificHeaderBox.cpp](https://github.com/neonmodder123/PS5-WebKit-11.x/blob/80f77e94c63ee7202eec3d4b5b1a021dd89011ba/Source/WebCore/platform/graphics/iso/ISOProtectionSystemSpecificHeaderBox.cpp): `schi` leaves the caller's offset, the key ID count check multiplies in 32 bits, and owned boxes are deleted through their vtables. A null argument throws. Closes when: compared with a console module.
