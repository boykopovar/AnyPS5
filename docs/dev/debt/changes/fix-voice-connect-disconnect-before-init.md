# libSceVoice

## change [sceVoiceInit, sceVoiceStart, sceVoiceCreatePort, sceVoiceGetPortInfo]

- [sceVoiceInit, sceVoiceStart, sceVoiceCreatePort, sceVoiceGetPortInfo](../../../core/libs/prx/libSceVoice/Export.cpp) (libSceVoice) - a second `sceVoiceInit` returns 0x804E0802, and Start, CreatePort and GetPortInfo return 0x804E0801 before checking any argument while the library is not initialized, as [prosper](https://github.com/mattias800/prosper/blob/ed42e499888d5a86792c3e1b2df3aebd8ca1a681/prosper/src/hle/audio/hle_audio.cpp#L4697-L4713) reads them from the shipped module. `ConnectIPortToOPort`, `DisconnectIPortFromOPort` and the other port and lifecycle calls return 0x804E0801 while the library is not initialized, unverified unless an entry says otherwise. Whether `sceVoiceInit` checks a null param before its state is unknown; it checks the state first, and that `sceVoiceEnd` returns the library to the not-initialized state is assumed. Closes when: the other entry points are read from the module or measured on a PS5

## change [sceVoiceDisconnectIPortFromOPort]

- [sceVoiceDisconnectIPortFromOPort](../../../core/libs/prx/libSceVoice/Export.cpp) (libSceVoice) - returns 0 for a connected pair and 0x804E0807 for a pair that is not connected (a second disconnect, a pair never connected, the two ports swapped) or whose second port was deleted, as [obSCEne's run](https://github.com/project-oops/obSCEne/blob/de5efc406319ade18df00654025494804405a7fb/reports/hardware/report-20261018-gt14-census.log#L2922-L2951) measured in its own title (PPSA90000) on a PS5 with system software 12.40, in an initialized library that had not started. A first port that is deleted or unknown and a second port id above 127 in an initialized library were not probed and still throw. Before `sceVoiceInit`, a payload process on a PS5 (firmware 11.60, two runs; a title process may differ) returned 0x804E0801 for it with five port pairs, among them a second port above 127, and for `sceVoiceConnectIPortToOPort(0, 1)`; the prototypes were assumed.
