# libScePad

## change [scePadGetTriggerEffectState]
- [scePadGetTriggerEffectState](../../../core/libs/prx/libScePad/Export.cpp) (libScePad) - returning PAD_ERROR_INVALID_ARG for an unwritable output pointer via GuestCopyOut_nid_no_patch with caller errno preserved is a host-safety fallback; whether the console faults or returns an argument error on unmapped memory is unmeasured. A PS5 (firmware 11.60, payload process; a title process may differ) answered `0x80920005` without `scePadInit` or `scePadOpen` for the handles 0, -1 and 0x1234 with a valid buffer, a null pointer and the unmapped address 0x10, left the buffer unchanged and did not fault; the answer comes before the pointer is read, so the pointer question stays unmeasured, and AnyPS5 answers the same `PAD_ERROR_NOT_INITIALIZED` first in that state.
