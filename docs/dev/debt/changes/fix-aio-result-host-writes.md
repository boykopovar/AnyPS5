Checked guest copies return `SCE_KERNEL_ERROR_EFAULT` for inaccessible outputs here. A failed state copy can leave poll/wait requests reported or delete requests removed; cancel changes nothing. Submit checks id output before I/O. An inaccessible later completion record may leave earlier I/O and completions done, but releases unpublished ids.
