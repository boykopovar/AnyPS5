# libSceSystemLogger

## change [sceSystemLoggerSetLogData]
- [sceSystemLoggerSetLogData](../../../core/libs/prx/libSceSystemLogger/Export.cpp) (libSceSystemLogger) - the guest `tag` string and the entries array are read through libc's checked copies (`CopyGuestString_nid_no_patch`, `GuestCopyIn_nid_no_patch`) before anything is dereferenced, so a non-null unwritten or unmapped address returns `0x81080002` with `errno` preserved instead of faulting the host process; this is a host-safety fallback. A PS5 (firmware 11.60, payload process; a title process may differ) returned 0 without a fault, without a call of `sceSystemLoggerInitialize`, in six calls whose first argument was null, a valid string or the unmapped address 0x10, whose second argument was 0 or 0x10 and whose third and fourth arguments were 0. Which of the second and third arguments is the count and which the entries pointer was not measured, and the probe passes no valid entries pointer, so what the console does for a valid tag with entries or with a count above 0 is unmeasured.
