# libkernel

## change [hw.realmem]

- [hw.realmem](../../../core/libs/prx/libkernel/System/src/SystemConfiguration.cpp) (libkernel) - `sysctl` {`CTL_HW`, 12} and `sysctlbyname` report the same 8-byte value as `hw.physmem` (the `_SC_PHYS_PAGES` pages of 16 KiB), read-only with `EPERM` for a write and `ENOMEM` for a short buffer, as FreeBSD's [`sysctl_hw_realmem`](https://github.com/freebsd/freebsd-src/blob/8c639945a44588f6cfdddfb057bb5aad88735da0/sys/kern/kern_mib.c#L191-L204) does. FreeBSD reports there the memory the firmware describes, which is at least `hw.physmem`. A payload process on a PS5 (firmware 12.70) gets -1 with `ENOENT` for `hw.physmem` and `hw.realmem` (a read, a size query and a null length) and for {`CTL_HW`, 5} and {`CTL_HW`, 12} (a read and a size query); a PS5 Pro payload process (13.60) reproduced every `ENOENT` and added the write answer: -1 with `EPERM` for an 8-byte new value on both nodes, so the kernel reaches the permission check where the read lookup fails; `hw.usermem64` ({`CTL_HW`, 13}) reads `ENOENT` too. What a title process gets was not measured. Dolphin reads it as the machine's memory size in [`MemPhysical`](https://github.com/dolphin-emu/dolphin/blob/8d2ad1a662472955497e5bb79d7b9ec6999e1f0d/Source/Core/Common/MemoryUtil.cpp#L253-L273) (RetroArch PPSA99169's `dolphin_libretro` core)

## change [vm.overcommit]

- [vm.overcommit](../../../core/libs/prx/libkernel/System/src/SystemConfiguration.cpp) (libkernel) - `sysctlbyname` returns -1 with `ENOENT` without changing the caller buffer or length for reads, size queries, a null length and writes. A payload process on a PS5 (firmware 12.70) measured the read, size-query and null-length cases; a PS5 Pro payload process (13.60) reproduced them and measured the write as `ENOENT` too. `sysctlnametomib` also returns `ENOENT`. A title process was not measured. Firmware 10.01 kernel data contains a read-write node holding 0, so the missing name appears to be process/namespace visibility rather than absence from the kernel. PS5MC (PPSA99420) probes the name in mimalloc's overcommit detection.
