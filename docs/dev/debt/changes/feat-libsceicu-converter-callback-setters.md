# libSceIcu

## add Functional

- [`ucnv_setFromUCallBack` and `ucnv_setToUCallBack`](../../../core/libs/prx/libSceIcu/ConverterCallbacks.cpp) forward to ICU 78.1 with host-side callback adapters. They translate the four ICU-provided callback functions, preserve guest callback/context pairs for replacements, and report null-converter errors through the status argument. The host converters used by these exports require no `icudt` data. Registry entries are per converter and direction; resetting a direction to the default empties that direction's entry and keeps the allocation, and no entry is released before `ucnv_close` exists to retire a converter. A host callback the library did not install is reported as a null action with its context. Guest ABI validation and a conversion through a guest callback on the library's default converter are asserted in the callback test; invalid guest outputs, `ucnv_close` cleanup of the registry (that export still throws), and behavior on a PS5 console have not been measured.
