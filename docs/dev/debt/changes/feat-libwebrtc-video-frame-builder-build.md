# libwebrtc

## add Public source implementations

- [webrtc::VideoFrame::Builder::build](../../../core/libs/prx/libwebrtc/src/VideoFrameBuilder.cpp) (libwebrtc) - not compared with the console. A builder holding packet infos throws through `NotImplemented_nid_no_patch` first, as copying `RtpPacketInfos` references a guest object whose layout is not modelled. A builder without a frame buffer throws `std::invalid_argument` where the firmware's `RTC_CHECK` aborts; a null builder or result throws. Unset optionals copy only their flag and an engaged colour space is copied as its 68 bytes (assumed guest `std::optional` copies). Otherwise, as in [video_frame.cc](https://webrtc.googlesource.com/src/+/8d78f5de6c27b2c793039989ea381f1428fb0100/api/video/video_frame.cc), it copies every builder field into the 216-byte `VideoFrame` behind the returned hidden result pointer, calls the buffer's virtual `AddRef` and leaves `processing_time_` unset. Closes when: compared with the console and packet infos are copied.
