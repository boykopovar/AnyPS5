# libSceLibreSsl3

## add Functional

- [X509_CRL entries with certificateIssuer](../../../core/libs/prx/libSceLibreSsl3/src/X509Crl.cpp) (libSceLibreSsl3) - not compared with the console. Each revoked entry gets the directoryName issuers of its `certificateIssuer` extension (or nearest earlier one), `reason` (`CRL_REASON_NONE` when absent), `EXFLAG_INVALID` on malformed, repeated or OOM `certificateIssuer`/`crlReason` leaving remaining entries untouched, and `EXFLAG_CRITICAL` on other critical entry extensions, matching LibreSSL 4.0.0 [`crl_set_issuers`](https://github.com/libressl/openbsd/blob/ce488b78e0bd994780569df718596b9776ff681a/src/lib/libcrypto/asn1/x_crl.c#L190-L253) and [`crl_revoked_issuer_match`](https://github.com/libressl/openbsd/blob/ce488b78e0bd994780569df718596b9776ff681a/src/lib/libcrypto/asn1/x_crl.c#L553-L577). Non-directoryName GeneralName forms throw; `idp_flags` (`indirectCRL`) is not decoded; same-serial entries scan in CRL order. Closes when: compared with the console.
