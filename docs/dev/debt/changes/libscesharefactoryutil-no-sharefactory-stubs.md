# libSceShareFactoryUtil

## change [sceShareFactoryUtilBackToGameFromShareFactory, sceShareFactoryUtilGetLaunchStatus, sceShareFactoryUtilGetLaunchStatusOfShareFactory, sceShareFactoryUtilInitialize, sceShareFactoryUtilLaunchShareFactory and sceShareFactoryUtilTerminate]

- [sceShareFactoryUtilLaunchShareFactory](../../../core/libs/prx/libSceShareFactoryUtil/Export.cpp) (libSceShareFactoryUtil) - its name and NID are in the [PS5 3.20 export inventory](https://github.com/DNNDHH/PS5-3.20_Libs/blob/b2a77c09cd71c01f34c790cfbe98c751a13262ad/libSceShareFactoryUtil.c), but no credible prototype was found and no host sharefactory app exists to launch. It is declared without parameters solely to resolve known imports; this is not an ABI claim and callers must not call it until the signature is verified. The other five exports return 0: `sceShareFactoryUtilInitialize` and `sceShareFactoryUtilTerminate` are no-ops because no host state is kept, `sceShareFactoryUtilGetLaunchStatus` and `sceShareFactoryUtilGetLaunchStatusOfShareFactory` report the retail default "not launched" state because the host has no sharefactory app, and `sceShareFactoryUtilBackToGameFromShareFactory` is a no-op because nothing has been launched. This is a cross-source baseline, not a PS5 10.6 console measurement.
