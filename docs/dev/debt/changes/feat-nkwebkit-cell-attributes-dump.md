# libSceNKWebKit

## add Functional

- [JSC::CellAttributes::dump](../../../core/libs/prx/libSceNKWebKit/src/JscCellAttributesDump.cpp) (libSceNKWebKit) - not compared with a console module. The body follows [CellAttributes.cpp](https://github.com/WebKit/WebKit/blob/73a35b43be7ae44c084885bd3fa4b403e59723c8/Source/JavaScriptCore/heap/CellAttributes.cpp#L33-L36) with the enum names from [DestructionMode.cpp](https://github.com/WebKit/WebKit/blob/73a35b43be7ae44c084885bd3fa4b403e59723c8/Source/JavaScriptCore/heap/DestructionMode.cpp#L35-L47) and [HeapCell.cpp](https://github.com/WebKit/WebKit/blob/73a35b43be7ae44c084885bd3fa4b403e59723c8/Source/JavaScriptCore/heap/HeapCell.cpp#L51-L65); the [11.x fork](https://github.com/neonmodder123/PS5-WebKit-11.x/blob/80f77e94c63ee7202eec3d4b5b1a021dd89011ba/Source/JavaScriptCore/heap/CellAttributes.cpp#L33-L36) keeps all three and both `int8_t` enums unchanged. The struct is the two bytes `destruction` then `cellKind`. `print` calls virtual `begin` (slot 4) and sends `%s` `{`, the mode, `, `, the kind and `}` to the returned stream's `vprintf` (slot 2), then calls `end` (slot 5) on the original stream; each enum name is itself a nested `print`, so it is bracketed by `begin` and `end` on the begun stream. A mode or kind outside the enum throws where upstream's `RELEASE_ASSERT_NOT_REACHED` crashes, after the text already sent and without calling `end`. A null attributes pointer, stream, vtable or virtual throws. Closes when: compared with a console module.
