# shader

## change [`v_cvt_f32_f64` f32 result]

- The [`v_cvt_f32_f64` f32 result](../../../core/shader/recompiler/Translation/src/Float64Instructions.cpp) follows the `FLOAT_MODE` f32 round mode as measured on RDNA2 (gfx1031) only; the PS5's gfx1013 is not measured. Rounding 1 to 3 rounds the f64 value up, down or toward zero: an overflow gives infinity on the side the mode rounds toward and the largest finite f32 on the other, a value below the smallest f32 denormal gives that denormal on the side the mode rounds toward when f32 denormal results are kept, and an f64 denormal source counts as zero when bit 0 of the f64 denormal field is clear. Measured with [tools/hw-oracle](../HW_ORACLE.md) over 104 f64 inputs in all sixteen f32 round and denormal modes, the four f64 denormal fields and IEEE 0 and 1, with no mismatches. An output modifier that overflows the converted value still gives infinity in these modes, where gfx1031 rounds the overflow as the mode says. Its flush to a zero of the source's sign, when bit 1 of the f32 denormal field is clear and the source rounded to 24 bits with an unbounded exponent in the round mode is below 2^-126, is measured on gfx1031 only.
