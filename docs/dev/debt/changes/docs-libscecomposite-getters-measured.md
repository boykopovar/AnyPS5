## change [sceCompositorGetDummySize and `NMGq0MJ2iGo`]
- [sceCompositorGetDummySize and `NMGq0MJ2iGo`](../../../core/libs/prx/libSceComposite/Export.cpp) - their signatures, what the dummy size measures and the name of `NMGq0MJ2iGo` are unknown; they keep the no-parameter declarations. In firmware 13.42 libSceComposite.sprx and libSceCompositeExt.sprx, `sceCompositorGetDummySize` returns `0x400` and `NMGq0MJ2iGo` returns 0 without reading an argument or any library state, and so do these. A PS5 (firmware 11.60, payload process; a title process may differ) returned `0x400` from `sceCompositorGetDummySize()` called without arguments, which agrees; `NMGq0MJ2iGo` was not called and stays unmeasured.
