# libkernel

## change [sceKernelGetAppCategoryType]

- [sceKernelGetAppCategoryType](../../../core/libs/prx/libkernel/SysExports.cpp) (libkernel; also exported by libkernel_sys through the shared compilation unit) - `(int pid, uint32_t* category)` returns `EINVAL` (0x80020016) for a null `category` before it looks at the pid. Pid 0 and the current process return the `applicationCategoryType` field of the title's `param.json`, and 0; a PS5 Pro payload process (13.60) answered `0xffffffff` where a 13.590.001 session reported 0, so the answer for a process without category data is not firmware-stable. Other pids, negative or unused, return `ESRCH` (0x80020003) with `errno` 3 without writing the output: measured on a PS5 Pro (-1, `INT_MIN` and an unused pid all answered ESRCH); the console answered values for its own other live processes, which AnyPS5 does not have, so every non-self pid here is an unused one. A real title's stored value is unmeasured, and the offset-0x50 field of the `sceKernelGetAppInfo` record is a fixed `0xffffffff` marker here, not category data. GoY (PPSA26344) and Marvel's Wolverine call it from bundled `libSceAgc` and skip a RegMgr GPU-transcoding check (key `0x34ae6c7a451600db`) only when it is `0x10000` (Ghidra, not console-measured).
