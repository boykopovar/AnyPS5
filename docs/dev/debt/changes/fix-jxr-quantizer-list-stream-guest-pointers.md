# libSceJxr

## change [allocateQuantizer]

- [allocateQuantizer](../../../core/libs/prx/libSceJxr/src/Quantizer.cpp) - not measured on a PS5: ABI/layout are inferred; an in-range null table throws before allocation instead of faulting, and a table that cannot be written through `GuestCopyOut_nid_no_patch` throws after the allocation is freed again. Pinned jxrlib [strcodec.c](https://github.com/4creators/jxrlib/blob/f7521879862b9085318e814c6157490dd9dbbdb4/image/sys/strcodec.c#L839-L853) rejects counts above 16 before table access, allocates `cQP * sizeof(CWMIQuantizer) * cChannel`, stores slot 0 even on allocation failure, leaves later slots unchanged on failure, and aliases later channels by `cQP`; return is 0 or -1. Its 20-byte quantizer layout follows [strcodec.h](https://github.com/4creators/jxrlib/blob/f7521879862b9085318e814c6157490dd9dbbdb4/image/sys/strcodec.h#L191-L201). Zero counts pass through guest `malloc(0)`.

## change [PKAlloc]

- [PKAlloc](../../../core/libs/prx/libSceJxr/src/Allocation.cpp): console behavior and ABI remain unverified. The implementation follows pinned jxrlib [JXRGlue.c](https://github.com/4creators/jxrlib/blob/f7521879862b9085318e814c6157490dd9dbbdb4/jxrgluelib/JXRGlue.c#L46-L50), using guest `calloc(1, cb)` so allocations match the guest heap released by `PKFree`. It stores the allocation, including null on failure, and returns `WMP_errSuccess` (0) or `WMP_errOutOfMemory` (-101) as a 64-bit `ERR`. A null `ppv` throws instead of the upstream null dereference, and one that cannot be written through `GuestCopyOut_nid_no_patch` throws after the allocation is freed again; zero size follows guest `calloc`.

## change [remapQP, formatQuantizer, getACPredMode and InitZigzagScan]

- [remapQP, formatQuantizer, getACPredMode and InitZigzagScan](../../../core/libs/prx/libSceJxr/src/Quantizer.cpp) call jxrlib's [strPredQuant.c](https://github.com/4creators/jxrlib/blob/f7521879862b9085318e814c6157490dd9dbbdb4/image/sys/strPredQuant.c#L79-L192), [strcodec.c](https://github.com/4creators/jxrlib/blob/f7521879862b9085318e814c6157490dd9dbbdb4/image/sys/strcodec.c#L861-L874) and [image.c](https://github.com/4creators/jxrlib/blob/f7521879862b9085318e814c6157490dd9dbbdb4/image/sys/image.c#L173-L183), built from `3rdparty/jxrlib`, on the caller's 20-byte quantizer, 1,160-byte macroblock and 704-byte coding context without `WMP_OPT_QT`. These prototypes and layouts are inferred from the export names. `formatQuantizer` copies the quantizer table in through `GuestCopyIn_nid_no_patch` and passes jxrlib the host copy. A null quantizer, quantizer table, used channel or macroblock, an unreadable quantizer table, more than 16 channels, and a scaled shift that takes the QP outside 32 bits throw. Closes when: the console's functions are disassembled or measured on a PS5

## change [freeQuantizer]

- [freeQuantizer](../../../core/libs/prx/libSceJxr/src/Quantizer.cpp) not measured on a PS5: the prototype is inferred from the export name. It follows pinned jxrlib [strcodec.c](https://github.com/4creators/jxrlib/blob/f7521879862b9085318e814c6157490dd9dbbdb4/image/sys/strcodec.c#L855-L859): only a non-null `pQuantizer[0]`, the one block `allocateQuantizer` shares across channels, is released with the guest `free`; the table entries are left unchanged. A null table, or one that cannot be read through `GuestCopyIn_nid_no_patch`, throws where jxrlib dereferences it. Closes when: the console's function is disassembled or measured on a PS5

## change [WriteWS_List, ReadWS_List, SetPosWS_List, GetPosWS_List, CloseWS_List and CreateWS_List]

- [WriteWS_List, ReadWS_List, SetPosWS_List, GetPosWS_List, CloseWS_List and CreateWS_List](../../../core/libs/prx/libSceJxr/src/ListStream.cpp) (libSceJxr) follow the linked-list `WMPStream` in [jxrlib strcodec.c](https://github.com/4creators/jxrlib/blob/f7521879862b9085318e814c6157490dd9dbbdb4/image/sys/strcodec.c#L455-L602) on the LP64 layout in `Stream.hpp`: 4 KiB packets from the guest heap, each after its next-packet pointer, with the first one right after the 88-byte stream. jxrlib's checks are kept as written, including the write limit against the total capacity, the read clamp and the null-pointer buffer left after reading the last packet. Null streams, outputs and buffers, which jxrlib dereferences, throw. `CreateWS_List` and `CloseWS_List` reach the guest stream pointer through `GuestCopyIn_nid_no_patch` and `GuestCopyOut_nid_no_patch`; one they cannot read or write throws, after `CreateWS_List` frees its new block and before `CloseWS_List` frees anything. Nothing is checked on the console. Closes when: compared with the console's libSceJxr.
