# libkernel_sys

## change [aio_read, aio_write, aio_fsync, aio_error, aio_return, aio_suspend, aio_waitcomplete, aio_cancel]

- [aio_read, aio_write, aio_fsync, aio_error, aio_return, aio_suspend, aio_waitcomplete, aio_cancel](../../../core/libs/prx/libkernel_sys/Aio.cpp) (libkernel_sys) - a `SIGEV_SIGNAL` or `SIGEV_THREAD_ID` completion, or a socket write's `EPIPE` `SIGPIPE`, throws unless its thread (the `SIGEV_THREAD_ID` one, else the submitter, where FreeBSD posts to the process) blocks the signal. File requests run one at a time, cancellable until started. Socket requests poll every 10 ms; a macOS or Windows host can block in a send on a blocking socket, so a cancelled write there sends all. A request keeps the descriptor number. Pipes fail with `EOPNOTSUPP` (`enable_unsafe` 0, unverified). Waits ignore signals, timeouts under 1 ms round up, and a bad `aio_suspend` pointer crashes the host. Else FreeBSD 11.4 [`vfs_aio.c`](https://github.com/freebsd/freebsd-src/blob/release/11.4.0/sys/kern/vfs_aio.c) and [`sys_socket.c`](https://github.com/freebsd/freebsd-src/blob/release/11.4.0/sys/kern/sys_socket.c)
