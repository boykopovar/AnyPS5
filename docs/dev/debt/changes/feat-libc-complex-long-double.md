# libc

## add Functional

- [ccosl, ccoshl, cexpl, clogl, csinl, csinhl, csqrtl and cpowl](../../../core/libs/prx/libc/src/FloatBuiltins.cpp) (libc) - the `long double` forms compute through `std::complex<long double>` as C99 Annex G defines them, including the branch cuts. `ctanhl` and `ctanl` are in [ComplexTanh.cpp](../../../core/libs/prx/libc/src/ComplexTanh.cpp), FreeBSD 11.4's [`s_ctanh.c`](https://github.com/freebsd/freebsd-src/blob/8c639945a44588f6cfdddfb057bb5aad88735da0/lib/msun/src/s_ctanh.c) in `long double` over this library's msun `tanl`, `sinl`, `cosl`, `sinhl` and `expl`, switching to `±1` from a real part of magnitude 26 instead of FreeBSD's 22 for `double`: `tanhl` rounds to 1 from about 22.9, and 26 keeps FreeBSD's margin of about 3. The console's results at the branch cuts and for special values are unverified.
- [cacosl, cacoshl, casinl, casinhl, catanhl and catanl](../../../core/libs/prx/libc/src/ComplexInverseTrig.cpp) (libc) - adapted from FreeBSD's [`catrigl.c`](https://github.com/freebsd/freebsd-src/blob/0dd5a5603e7a33d976f8e6015620bbc79839c609/lib/msun/src/catrigl.c), which FreeBSD 11.4 does not have, reading exponents through `ilogb` instead of the 80-bit layout so a 64-bit `long double` host works too. The console's results are unverified.
