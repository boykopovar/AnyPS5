# libSceLibreSsl3

## add Functional

- [d2i_PKCS7 and PKCS7_free](../../../core/libs/prx/libSceLibreSsl3/src/Pkcs7.cpp) (libSceLibreSsl3) - not checked on the console. High tag numbers, a null `in`, and BER inside an AlgorithmIdentifier, Name, certificate or CRL throw: those use the DER decoders of `X509_STORE_load_locations` and `d2i_X509_CRL`. UTCTime and GeneralizedTime values are not validated. Strings collected past `INT_MAX` bytes queue `ASN1_R_TOO_LONG` (untested; 4.0.0 fails in `CBB`). The rest follows the 4.0.0 [pk7_asn1.c templates](https://github.com/libressl/openbsd/blob/ce488b78e0bd994780569df718596b9776ff681a/src/lib/libcrypto/pkcs7/pk7_asn1.c#L77-L489), [`asn1_collect`](https://github.com/libressl/openbsd/blob/ce488b78e0bd994780569df718596b9776ff681a/src/lib/libcrypto/asn1/tasn_dec.c#L178-L227) and [pkcs7.h layouts](https://github.com/libressl/openbsd/blob/ce488b78e0bd994780569df718596b9776ff681a/src/lib/libcrypto/pkcs7/pkcs7.h#L84-L198).
