# libSceCesCs
## change [sceCesRefersUcsProfileCp864]
- [sceCesRefersUcsProfileCp864](../../../core/libs/prx/libSceCesCs/SingleByte.hpp) (libSceCesCs) - the table follows Microsoft's [CP864.TXT](https://unicode.org/Public/MAPPINGS/VENDORS/MICSFT/PC/CP864.TXT): 0x25 is U+066A and U+0025 has no byte. The PS5 firmware 11.60 sweep returned 0 for 250 of 256 bytes through `sceCesSbcToUtf32`, with CRC32 0xca172948 over the (return value, scalar) pairs. The six undefined bytes return `UNASSIGNED_CODE` with scalar output 0 through native `sceCesSbcToUtf32`; native `sceCesUcs2ToSbc` clears the output byte on errors. `sceCesSbcToUtf8` deliberately keeps its output unchanged for 0x9B, as measured. Endian-qualified wide conversions and other unmeasured forms remain unverified. Measurements were from a payload process; a title process may differ.
