# libScePosixForWebKit

## add Functional

- [getpwuid](../../../core/libs/prx/libScePosixForWebKit/UserDatabase.cpp) (libScePosixForWebKit) - returns a thread-local FreeBSD 11.4 `passwd` layout for the guest's existing UID 0 identity, with a host-independent root name, UID/GID 0, and home directory `/`. Other UIDs have no guest database record and return null. The password and login fields are synthetic; account database contents and the console provider for the raw Azahar import are unverified.
