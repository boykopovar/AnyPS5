## add Unknown function info

- [The manual UDP contexts](../../../core/libs/prx/libSceNpSessionSignaling/Export.cpp) (libSceNpSessionSignaling) - past their checks, firmware 13.42's CreateJoin and Join take a slot from `sceNpSessionSignalingCreateContext`'s ten (`0x80553307` when none is free), then set up a context for the user id at `param+0` with `sceNpManagerIntGetNpId` and `sceNpManagerIntGetAccountId`, returning their error and giving the slot back ([follow-up](https://github.com/boykopovar/AnyPS5/issues/21755#issuecomment-6949399700), disassembly and an emulator run, not on a console). Here they return NpManager's answer the same way, signed out for every user, and the given-back slot's next id moves on by 10 as after `DestroyContext`; a set-up context would next register with the signaling core, which wasn't read, so that path throws. EstablishConnection and AbortConnection on a known context return GROUP_NOT_FOUND (`0x8055330a`), as the console does for a context with no group, and none has one here
