# libSceAgcDriver

## change [Native D32S8 guest publication]

- [Native D32S8 guest publication](../../../core/libs/prx/libSceAgcDriver/Graphics/src/DepthSurface.cpp) cannot distinguish unchanged bytes on a CPU-stored page when host bytes differ and no driver store covers them. Draw/storage/colour/depth reuse takes guest bytes (inferred); CPU/DMA/texture/buffer access and writable-buffer publication throw. Unchanged import-window touches take host bytes; same-value CPU stores inside that window are overwritten. During commit, only a late store of the snapshot into a host-changed byte is overwritten; others are kept and the read throws. HTILE is expanded; stencil uses depth XOR. Reuse taking guest bytes, a new depth target or a guest write retires the owner. Host-only planes rebase; guest bytes or unmapped holes make later use throw. D16/HTILE D32 owners, unproven clears, other resident colour aliases, colour acquisition mid-read, pending storage units over a plane and GPU-completion publication throw.
