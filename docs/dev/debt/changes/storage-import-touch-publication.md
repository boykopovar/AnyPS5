# libSceAgcDriver

## change [Native D32S8 guest publication]

- [Native D32S8 guest publication](../../../core/libs/prx/libSceAgcDriver/Graphics/src/DepthSurface.cpp) overwrites a guest byte only when a CPU store of the snapshot's own value lands in a byte the host changes while that part commits; other late stores are kept and the read throws. An import-window touch without changed bytes takes the host result; a same-value CPU store inside that window is overwritten. A CPU-stored page's byte equal to its snapshot, the host's differing, no driver store covering it, is undecided: a draw input, storage image, colour target or new depth target reusing the memory takes the guest's byte, inferred; CPU, DMA, texture and buffer reads throw. HTILE is published expanded; the stencil plane is retiled with the depth XOR. Only a reuse taking a guest byte or a new depth target over its planes retires the owner. A kept plane of host bytes is rebased; one with a guest byte or unmapped hole throws at next use. D16 and HTILE D32 owners, unproven clear transitions, other resident colour aliases, colour acquisition mid-read, pending storage-image units over a plane and in-completion publication throw.
