# libSceLibcInternal

## add Functional

- [Daylight saving time rules parser](../../../core/libs/prx/libSceLibcInternal/Export.cpp) (libSceLibcInternal) - `_Getdst` parses daylight saving time rule strings following Dinkumware libc specifications from firmware 13.42, decoding year, date, optional hour, and weekday search direction suffixes into 5-byte rule records and a 5-byte terminator.
