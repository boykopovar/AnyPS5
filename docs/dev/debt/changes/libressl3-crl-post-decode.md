# libSceLibreSsl3

## add Functional

- [d2i_X509_CRL](../../../core/libs/prx/libSceLibreSsl3/src/X509Crl.cpp) (libSceLibreSsl3) - not measured on a PS5. A CRL with exactly one issuing distribution point extension throws, because that extension is not decoded. A certificate issuer CRL entry extension is not decoded: the entry's issuer and the CRL's issuer list stay null, and a malformed one does not set `EXFLAG_INVALID`. The revoked stack gets no comparison function. `EXFLAG_CRITICAL` takes LibreSSL's later fix [bf24a103](https://github.com/libressl/openbsd/commit/bf24a103424334af46d2cf695b6e60f39ce9e3a8) and keeps scanning past a critical AKID, delta CRL indicator or issuing distribution point extension; LibreSSL 4.0.0 stops at the first critical extension, so a CRL that 4.0.0 leaves unflagged can get the flag here. The hash, cached extensions, reasons and flags otherwise follow LibreSSL 4.0.0 [`crl_set_issuers` and `crl_cb`](https://github.com/libressl/openbsd/blob/ce488b78e0bd994780569df718596b9776ff681a/src/lib/libcrypto/asn1/x_crl.c#L189-L340).
