# shader

## change [SDWA destination selectors on `v_sin_f32`, `v_cos_f32`]

- [SDWA destination selectors on `v_sin_f32`, `v_cos_f32`](../../../core/shader/recompiler/RdnaDecoder/src/RdnaVectorOpDecoder.cpp) - the PS5's gfx1013 is not measured. `v_sin_f32` and `v_cos_f32` accept byte and word destination selectors (`BYTE_0`..`BYTE_3`, `WORD_0`, `WORD_1`) with unused modes `UNUSED_PAD`, `UNUSED_SEXT` and `UNUSED_PRESERVE` when the source selector is `DWORD`. Sources: [RDNA2 ISA](https://gpuopen.com/download/rdna2-shader-instruction-set-architecture.pdf) §§6.8, 12.8, 13.3.7 Table 88; LLVM 19.1.0 [VOP1Instructions.td](https://github.com/llvm/llvm-project/blob/llvmorg-19.1.0/llvm/lib/Target/AMDGPU/VOP1Instructions.td) and [SIPeepholeSDWA.cpp](https://github.com/llvm/llvm-project/blob/llvmorg-19.1.0/llvm/lib/Target/AMDGPU/SIPeepholeSDWA.cpp). Execution verified in Wave32 and Wave64, and on RDNA2 (gfx1036, [hardware oracle](../HW_ORACLE.md)) every pinned result and placement matches; gfx1013 is unmeasured.
