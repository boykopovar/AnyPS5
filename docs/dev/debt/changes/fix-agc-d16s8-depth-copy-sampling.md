# libSceAgcDriver

## change [Depth plane copies]

- [Depth plane copies](../../../core/libs/prx/libSceAgcDriver/Graphics/src/DepthSurface.cpp) (libSceAgcDriver): a depth plane sampled as a 2D array, cube or cube array, or a D16 plane read as `R16_UINT`, is copied into a `DepthPlaneCopy` image from the live depth surface at each slice's address or from detiled guest memory. Each slice's address (`DepthSliceBytes`, one 64 KiB-block depth slice per layer), array-ordered cube faces, and 2D-array or 2D bindings with `BASE_ARRAY > 0` reading slices `BASE_ARRAY` to `LAST_ARRAY` or slice `BASE_ARRAY` (PPSA01556, PPSA03912) are inferred from title use and colour 2D-array semantics, not measured on hardware. Unchanged slices are reused across draws and dispatches except for the latest depth draw's target. Planes with mips, a cube or 2D T# with a non-zero base slice, `BASE_ARRAY` past `LAST_ARRAY`, a cube whose last array slice is neither 0 nor 6n - 1, and other views of the planes still throw.

## change [16-bit depth with stencil]

- [16-bit depth with stencil](../../../core/libs/prx/libSceAgcDriver/Graphics/src/DepthSurface.cpp) (libSceAgcDriver) is stored as `D24_UNORM_S8_UINT`, or `D32_SFLOAT_S8_UINT`, on a device without `D16_UNORM_S8_UINT` as an attachment. Storage import, export and store-back, integer and array/cube plane copies and layered storage copies convert between the guest 16-bit encoding and the host depth format at the transfer boundary. Depth comparisons, clears and the depth image still see the wider format's precision, so results at the 16-bit quantization boundary can differ from the console; the constant depth bias is scaled by 256 for D24, and a non-zero constant on the D32 float fallback throws. A nonfinite D32 depth value converted to D16 refuses at the owning batch's normal completion after its fence, skips that batch's successful write-backs, drains later in-flight batches and leaves a sticky failure for later waits; none of this is measured on the console.

## change [Depth surfaces created over storage writes]

- [Depth surfaces created over storage writes](../../../core/libs/prx/libSceAgcDriver/Graphics/src/DepthSurface.cpp) (libSceAgcDriver): a depth surface created without HTILE copies its depth plane from the storage image at the plane's address, a pending one first, when that image has the plane's extent, one level, a 2D view or a 2D array view (its layer 0 is copied) and a 16-bit format for a 16-bit plane or a 32-bit format for a 32-bit plane. A multisampled surface, a surface with HTILE and a surface without such an image start from `DB_DEPTH_CLEAR`, and the stencil plane from `DB_STENCIL_CLEAR`; CPU writes to the plane's memory are not read. Not measured on the console, where the plane is that memory.
