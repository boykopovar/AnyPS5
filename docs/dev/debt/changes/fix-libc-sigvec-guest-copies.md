# libc

## change [sigvec]

- [sigvec](../../../core/libs/prx/libc/src/LegacySignals.cpp) (libc and libSceLibcInternal) has not been measured on a physical PS5 or run on macOS. Its Windows module-lookup fixture pins modules until process exit; explicit DLL unloading remains unverified. The cause of the reported unload crash is unknown. A contributor executed the firmware 13.42 export `yhxKO9LYc8A` from libSceLibcInternal in an emulator with recording `_sigaction`/`sigemptyset` imports; layout, conversion, aliasing and forwarded results match this implementation. Its vector ABI, low-word mask conversion and restart/interrupt flag inversion follow FreeBSD 11.4 [`sigcompat.c`](https://github.com/freebsd/freebsd-src/blob/8c639945a44588f6cfdddfb057bb5aad88735da0/lib/libc/compat-43/sigcompat.c) and [`signal.h`](https://github.com/freebsd/freebsd-src/blob/8c639945a44588f6cfdddfb057bb5aad88735da0/sys/sys/signal.h). Calls use registered guest `sigaction`; absent registration throws before mutation. It inherits the [guest signal layer's gaps](libkernel.md): the restart flag, `SA_ONSTACK` and `SA_SIGINFO` delivery are not applied, while the action mask, `SA_NODEFER` and `SA_RESETHAND` are applied when a handler runs. New vectors clear the upper mask words; queries return only the low word. A non-null replacement vector is read through `GuestCopyIn_nid_no_patch`; an unreadable one returns `-1` with `EFAULT` without output or disposition mutation. The previous-vector output is guarded by a host-write scope before the action changes; a rejected scope returns `EFAULT` without output or disposition mutation. The previous vector is written through `GuestCopyOut_nid_no_patch`; if that copy fails after the scope opened, the call returns `EFAULT` and the new disposition stays installed, as FreeBSD `sys_sigaction` installs before copying out. Console behaviour for invalid vectors is not measured.
