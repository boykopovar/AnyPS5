- [sigvec](../../../../core/libs/prx/libc/src/LegacySignals.cpp) (libc and libSceLibcInternal) now reads a non-null replacement vector through `GuestCopyIn_nid_no_patch` before forwarding; an unreadable replacement returns `-1` with `EFAULT` before the host-write check, without output or disposition mutation. FreeBSD 11.4 [`sigcompat.c`](https://github.com/freebsd/freebsd-src/blob/8c639945a44588f6cfdddfb057bb5aad88735da0/lib/libc/compat-43/sigcompat.c) dereferences the vector directly, so this replaces the previously undefined case; console behaviour for invalid vectors is unmeasured.
- [sigvec](../../../../core/libs/prx/libc/src/LegacySignals.cpp) (libc and libSceLibcInternal) still opens the previous-vector `GuestArena::HostWrite` scope before forwarding, and a rejected scope still returns `EFAULT` without output or disposition mutation. The previous vector is then written through `GuestCopyOut_nid_no_patch`. If that copy fails after the scope opened (for example a concurrent unmap), the call returns `-1` with `EFAULT` and the replacement disposition stays installed; no rollback is attempted, matching FreeBSD `sys_sigaction`, which installs the new action before copying out the old one. Only the unreadable-replacement path is covered by tests; a copy-out failure after an opened scope is not reproduced deterministically.
