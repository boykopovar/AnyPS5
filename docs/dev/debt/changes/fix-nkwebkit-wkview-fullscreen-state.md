# libSceNKWebKit

## change [View scale factors, drawing and fullscreen state]

- [View scale factors, drawing and fullscreen state](../../../core/libs/prx/libSceNKWebKit/src/View.cpp) (libSceNKWebKit) - `WKViewGetPageScaleFactor`, `WKViewSetPageScaleFactor`, `WKViewGetViewScaleFactor`, `WKViewSetViewScaleFactor` and `WKViewSetDrawsBackground` keep scale factors and background drawing in host memory. Fullscreen flag `WKViewIsFullScreen` is set by `WKViewWillEnterFullScreen` and cleared by `WKViewDidExitFullScreen`, per [PlayStationWebView.cpp](https://github.com/neonmodder123/PS5-WebKit-11.x/blob/80f77e94c63ee7202eec3d4b5b1a021dd89011ba/Source/WebKit/UIProcess/playstation/PlayStationWebView.cpp#L112-L150); `WKViewDidEnterFullScreen`, `WKViewWillExitFullScreen` and `WKViewRequestExitFullScreen` leave it. `WKViewPaint` and `WKViewPaintToCurrentGLContext` track paint invocations, and `WKViewScrollBy` accumulates the view scroll offset in host memory. Fullscreen manager IPC, compositor integration and OpenGL draw calls are unmodeled.
