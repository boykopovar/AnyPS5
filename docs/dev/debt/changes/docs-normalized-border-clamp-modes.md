# libSceAgcDriver

## add Functional

- [Normalized S# clamp modes 4, 5 and 7](../../../core/libs/prx/libSceAgcDriver/Graphics/src/GuestSamplerResource.cpp) (libSceAgcDriver) map to `CLAMP_TO_BORDER` (4) and `MIRROR_CLAMP_TO_EDGE` (5, 7); an X or Y axis in mode 4 under point XY filters maps to `CLAMP_TO_EDGE`. On RDNA2 (gfx1036, AMD Windows driver 32.0.21045.16010, [hardware oracle](../HW_ORACLE.md), 8x1 32_FLOAT, `image_sample_lz`, x from -2.3 to 2.6, three border colour types) point mode 4 reads the edge texel, which that mapping matches, and point mode 7 mirrors once on [-1, 0) and reads the border from x >= 1 and x < -1. A bilinear filter clamps the coordinate to the image's edges, so modes 4 and 5 (after mirroring) return half the edge texel and half the border there, and mode 7 blends the border into the last texel. AnyPS5 returns the border for bilinear mode 4 and the edge texel for 5 and 7. Mode 4 on Z is unmeasured. Modes 0, 1, 2, 3 and 6 match. The PS5's gfx1013 is not measured.
