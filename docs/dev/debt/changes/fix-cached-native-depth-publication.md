# libSceAgcDriver

## change [Native D32S8 guest publication]

- [Native depth guest publication](../../../core/libs/prx/libSceAgcDriver/Graphics/src/DepthSurface.cpp) overwrites a guest byte only when a CPU store of the snapshot's own value lands in a byte the host changes while that part commits; any other late store is kept and the read throws, leaving committed planes published and later reads throwing. It throws when a written page holds a byte equal to its snapshot while the host result differs and no driver store covers it: a same-value CPU store cannot be told from none. HTILE is published expanded, not as the console's compressed stream; the stencil plane is retiled with the depth XOR. A bare D32 or D32S8 owner stays resident: a plane whose bytes are the host's is rebased, one that took a guest byte or has an unmapped hole throws at the next use. D16 owners, unproven clear transitions, other resident colour aliases, a colour target acquired during a read, pending storage-image units over a plane and publication inside GPU completions throw.

## change [Native multisampled D32S8 depth without HTILE]

- [Native multisampled D32S8 depth without HTILE](../../../core/libs/prx/libSceAgcDriver/Graphics/src/DepthSurface.cpp) is imported when its depth plane repeats one float in [0, 1], its separate stencil plane repeats one byte and no multisampled colour target covers either plane; the host image starts at those values and the sampled descriptor must name no metadata, whose pipe-aligned and ITERATE_256 bits are then not compared. The depth plane is sampled as a 32-bit float, the stencil plane through the R8_UINT descriptor of the stencil plane sampling entry below. That every sample then holds them is inferred from the uncompressed layout, not measured on the console. A written owner is published on a guest read as the native depth guest publication entry above describes, with no HTILE to expand. Other planes import once a stencil readback shows the first draw (depth ALWAYS with writes, stencil ALWAYS/REPLACE, mask 0xff) reached every sample; else they throw, as D16 without HTILE does.

## change [Shader buffer access to native multisample targets]

- [Shader buffer access to native multisample targets](../../../core/libs/prx/libSceAgcDriver/Graphics/src/ShaderResources.cpp) - Shader buffer descriptors retain the existing native color/depth guest-access refusal during preparation, completion and binding, including cached bindings and moved draw ranges. The check covers logical descriptor ranges, not larger import windows; dynamically addressed BDA heaps and vertex/index input snapshots remain outside this check. Native color buffer publication and console equivalence remain unimplemented or unmeasured; supported D32/D32S8 publication is described above.
