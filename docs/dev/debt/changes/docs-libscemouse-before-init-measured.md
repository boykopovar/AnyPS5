# libSceMouse

## change [sceMouseConnectPort, sceMouseDeviceOpen, sceMouseDisconnectDevice, sceMouseDisconnectPort, sceMouseMbusInit and sceMouseSetProcessPrivilege]
- [sceMouseConnectPort, sceMouseDeviceOpen, sceMouseDisconnectDevice, sceMouseDisconnectPort, sceMouseMbusInit and sceMouseSetProcessPrivilege](../../../core/libs/prx/libSceMouse/Export.cpp) (libSceMouse) - names and NIDs are present in the [PS5 3.20 export inventory](https://github.com/DNNDHH/PS5-3.20_Libs/blob/b2a77c09cd71c01f34c790cfbe98c751a13262ad/libSceMouse.c); the no-argument prototypes follow [shadPS4's PS4 stubs](https://github.com/shadps4-emu/shadPS4/blob/f68923fe807f657348e6719ce658bcbd0a2b1c72/src/core/libraries/mouse/mouse.cpp#L34-L146), not measured on a console. These declarations have no parameters solely to resolve known imports and make no ABI claim. Each returns `MOUSE_ERROR_NOT_INITIALIZED` (`0x80df0005`) before initialization and throws afterwards. A PS5 (firmware 11.60, payload process; a title process may differ) returned `0x80DF0005` from sceMouseConnectPort, sceMouseDeviceOpen, sceMouseDisconnectDevice and sceMouseDisconnectPort, each called once with all arguments 0 before any initialization (the prototype is assumed); sceMouseMbusInit and sceMouseSetProcessPrivilege were found by `dlsym` and not called, and nothing was measured after an initialization.
