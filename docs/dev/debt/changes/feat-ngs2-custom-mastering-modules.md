# libSceNgs2.native

## change [NGS2 custom ChannelMixer]

- [NGS2 custom ChannelMixer](../../../core/libs/prx/libSceNgs2.native/src/Custom.cpp) (module 0x17) - a 37x37 level matrix `level[out][in]` set per position by voice parameter `0x40001700 | index`; each output channel renders `sum(level[o][i] * in[i])` over the voice's channels, the table applying from the next render's first sample with no ramp, per [kali113's console runs](https://github.com/boykopovar/AnyPS5/issues/8039#issuecomment-6792157201). Levels store clamped to [-32, 32] with NaN kept. An unset module passes source to dest unchanged — the console's identity default. Creation takes a null option or one sized 4, 8 or 16 (other sizes `0x804A8013`) and no module state, as measured. A parameter size short of the table applies only the bytes present; the console reads the whole matrix anyway. Unknown or unimplemented: option contents, `extra_buffer_id`, unequal buffer sizes, mastering rack modules, and whether the custom sampler's position shift applies here (it follows Gain's).

## change [NGS2 custom mastering rack]

- [NGS2 custom mastering rack](../../../core/libs/prx/libSceNgs2.native/src/Rack.cpp) (libSceNgs2.native, rack 0x4003) - gaps: into a buffer of another count the PS5 library uses the plain mastering rows, while the PS5 4.03 module and PS4 11.00 copy the first channels unchanged for 1, 2, 6 and 8 channels (m20 runs on a PC; the PS4 library copies); param 0x40030004 (gain) returns an invalid-id code on both (PS4 `0x804A0308`, PS5 4.03 `0x804A8362`) where this library accepts it; non-default option fields throw (modules: next entry); channels 9 to 37 throw (voices hold 8; creation returns `0x804A8052` above 37). Option size 0x508 (PS4: 0x4d8) follows [fma-rc's reading of the 12.70 module](https://github.com/boykopovar/AnyPS5/issues/8039#issuecomment-6319332943), matching the custom submixer layout; params 0x40030000 (setup), 0x40030005 (output). `sceNgs2VoiceGetState` fills common flags. PPSA10278 and PPSA04540 create rack 0x4003 without modules (#8039)

## add Functional

- [NGS2 custom mastering modules](../../../core/libs/prx/libSceNgs2.native/src/Custom.cpp) (libSceNgs2.native, rack 0x4003, modules 0x17, 0x18, 0x1a) - follows [the 13.590.001 measurement](https://github.com/boykopovar/AnyPS5/issues/8039#issuecomment-6792157201) (section A, not a title).
