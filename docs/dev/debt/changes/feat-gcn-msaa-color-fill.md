# libSceAgcDriver

## change [Multisampled texture no draw rendered to]

- [Multisampled texture no draw rendered to](../../../core/libs/prx/libSceAgcDriver/Graphics/src/MultisampleTarget.cpp) (libSceAgcDriver) - sampling a multisampled texture whose surface no draw rendered to creates the host target from the T# and clears it to the color a single 32-bit value repeated over the whole footprint encodes, padding up to whole tile blocks included; other RenderTarget and Z64KBX contents are uploaded sample by sample through the native color initialization. A PS4 thin or display 2D texture takes its PS4 footprint (PS4 multisampled color memory). Inferred, not measured on the console: that the samples of such a surface are the guest color memory, as a title that clears its canvas on the CPU (ps5-opengl `ps5_clear_msaa4_color`) relies on. Non-uniform Standard4KB, Standard64KB, D64KBX and PS4 memory, other tile modes, unmapped memory and values with no exact clear color throw. CPU writes to the surface after its host target exists are not seen by the host.

## add Functional

- [PS4 multisampled color memory](../../../core/libs/prx/libSceAgcDriver/Graphics/src/MultisampleTarget.cpp) (libSceAgcDriver, PS4) - a PS4 thin or display 2D multisampled color target's color memory is its padded one-sample size times its stored fragments: CB_COLOR_SLICE's for a drawn target, the PS4 multisampled layout's ([TextureTiling.cpp](../../../core/libs/prx/libSceAgcDriver/Graphics/src/TextureTiling.cpp)) for a texture no draw rendered to. Fills, first-draw contents and such textures use that range, and an exact uniform fill over all of it is absorbed by the host target, not stored to guest memory. Inferred: that an undrawn PS4 surface holds its samples there. PS4 1D and linear targets have no footprint. T# word 6 (shadPS4's `alt_tile_mode` and `compression_en`) is not read, so an alternate-tiled or compressed PS4 Pro surface counts as a plain base-layout one. A PS4 target over a texture's host target it does not match throws. Closes when: measured on a PS4 Pro.
