# libSceIcu

## change [Default-converter string copy helpers]

- [Default-converter string copy helpers](../../../core/libs/prx/libSceIcu/Invariant.cpp) `u_austrcpy`, `u_austrncpy`, `u_uastrcpy` and `u_uastrncpy` are unverified on a console and throw `NotImplemented_nid_no_patch` on code units or bytes above `0x7f`. Their names and NIDs come from the PS5 3.20 inventory; signatures and ASCII (`0x01`–`0x7f`) behavior follow ICU 78.1's [ustr_cnv.cpp](https://github.com/unicode-org/icu/blob/release-78.1/icu4c/source/common/ustr_cnv.cpp), unchanged since 65.1, without assuming the console's default converter for non-ASCII units. `u_austrncpy` and `u_uastrncpy` write a single NUL when the source ends before the count without zero-padding the remainder. Null buffers with `u_austrcpy`, `u_uastrcpy` or a positive count throw an invalid-argument exception, whereas ICU dereferences in the unbounded copies and returns the destination unchanged in the bounded ones. Closes when: compared with the console, including the default converter for non-ASCII units.
