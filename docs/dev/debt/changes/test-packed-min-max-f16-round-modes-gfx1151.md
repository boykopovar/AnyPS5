# shader

## change and are not measured in those modes, and in `v_pk_add_f16`, `v_pk_mul_f16`

- [Packed f16 NaN results](../../../core/shader/recompiler/Translation/src/FloatInstructions.cpp) (`v_pk_add/mul/fma/min/max_f16`) follow the hardware measured on RDNA2 (gfx1035) at IEEE=0 and IEEE=1 with f16 round-to-nearest-even and f16 denormals kept: with IEEE=1 a signaling NaN input is quieted and min/max return the other operand only for a quiet NaN; with IEEE=0 NaN inputs pass through unquieted and min/max ignore signaling. In `v_pk_fma_f16` an invalid product (inf * 0) gives the default NaN even when src2 is a NaN. A shader without a known float mode is translated as IEEE=0, the mode titles use; a mode with another f16 rounding throws, except in `v_pk_min/max_f16`, which select one operand's bits without rounding (RDNA2 ISA §12.10, opcodes 17 and 18) and return in those modes the same bits as with round-to-nearest-even, as measured on RDNA2 (gfx1036, AMD Windows driver 31.0.22044.1) in wave32 at IEEE=0 and IEEE=1 with denorm16 0..3, and on RDNA3.5 (gfx1151, Radeon 8060S, AMD Windows driver 32.0.22032.6002, [hardware oracle](../HW_ORACLE.md)) at IEEE=0 and IEEE=1, DX10_CLAMP=0 and 1 and f16 denormals kept or flushed, which [PackedMinMaxF16RoundModes](../../../core/libs/prx/libSceAgcDriver/tests/execution/PackedMinMaxF16RoundModes.cpp) pins in wave32, wave64 and split wave64 (the PS5's gfx1013 is unmeasured), and in `v_pk_add_f16`, `v_pk_mul_f16`, `v_pk_fma_f16` and `v_pk_fmac_f16`, which round as the `v_fma_mixlo_f16` entry records, with the NaN results above, as measured on RDNA2 (gfx1036) in those modes (#16739, #16889; fma and fmac as their own entry records). In the f16 denormal modes that flush, each denormal input lane is flushed to a zero of its sign when bit 0 of the field is clear (0 and 2), so `inf * 0x0001` is an invalid product there, and when bit 1 is clear (0 and 1) a `v_pk_add_f16` result below 2^-14, or a `v_pk_mul_f16`, `v_pk_fma_f16` or `v_pk_fmac_f16` result whose exact value rounded to 11 significant bits with an unbounded exponent is below 2^-14, is flushed to a zero of its sign; `v_pk_min/max_f16` flush only their inputs. The native f16x2 add and multiply is not used while results are flushed. Measured on RDNA2 (gfx1031, Radeon RX 6700 XT, AMD Windows driver 32.0.21045.5002 through HIP) at IEEE=0 and IEEE=1 with denorm16 0..3, over 19,192 to 162,204 lanes per instruction with op_sel, op_sel_hi, neg_lo, neg_hi and clamp variants and products and sums at the 2^-14 boundary.
