# libSceIme

## change [sceImeFilterText]

- [sceImeFilterText, sceImeCheckFilterText](../../../core/libs/prx/libSceIme/Export.cpp) (libSceIme) - `sceImeFilterText` follows the disassembly of `libSceIme.sprx` from firmware 13.60 and is differential-tested against that function in an emulator, not measured on a console. [ImeFilterCodepages.hpp](../../../core/libs/prx/libSceIme/include/ImeFilterCodepages.hpp) holds the two codepage checks (helpers at 0x4850 and 0x48f0), rebuilt from Unicode's public [CP932](https://unicode.org/Public/MAPPINGS/VENDORS/MICSFT/WINDOWS/CP932.TXT) and [CP936](https://unicode.org/Public/MAPPINGS/VENDORS/MICSFT/WINDOWS/CP936.TXT) tables plus the Latin-1, CJK Extension A and a few other units the firmware also accepts (listed in the PR). The parameter layout beyond `type` is inferred: `mask` is the allowed-class bitmask, and `version` and `variant` derive it when it is 0. `sceImeCheckFilterText` takes a UTF-16 string and a byte-sized repair flag: it returns -3 for a null string, 0 when a terminator occurs within the first 0x98 code units, -2 when that range has no terminator and repair is false, and otherwise writes a terminator at code unit 0x98 and returns 0. This follows the supplied firmware module's disassembly; it is not measured on a console. Unmapped guest memory throws as a host-safety fallback.
