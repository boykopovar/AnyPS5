# libSceAgcDriver

## remove [sceAgcDriverInitResourceRegistration, sceAgcDriverQueryResourceRegistrationUserMemoryRequirements]

## add Functional

- [sceAgcDriverInitResourceRegistration, sceAgcDriverQueryResourceRegistrationUserMemoryRequirements](../../../core/libs/prx/libSceAgcDriver/Resource/src/Lifecycle.cpp) have unmeasured console initialization and null-query results. Both return `0x8A6C9018`, following [OpenAGC's constant-return implementation](https://github.com/OpenAGC/OpenAGC/blob/3c7e8072f0d7684e930454794fd5c02056946d73/src/game_compat.c#L300-L314); that reference is not a console measurement and leaves query output untouched. [obSCEne's probe](https://github.com/project-oops/obSCEne/blob/de5efc406319ade18df00654025494804405a7fb/src/probe/sections/agc.c#L22240-L22259) instead initializes a `uint64_t` output to `0xbeefcafebeefcafe`, and its [PS5 12.40 report](https://github.com/project-oops/obSCEne/blob/de5efc406319ade18df00654025494804405a7fb/reports/hardware/report-20261013-172400.log#L23428-L23439) records query result `0x8A6C9018` and output zero. This supports clearing the eight-byte value, but does not measure surrounding bytes, null or invalid pointers, unaligned output, errno, or initialization. Unwritable non-null output returns `0x80020065` through safe copy-out with errno preserved as host policy. Local regressions check AnyPS5 behaviour, not console equivalence.
