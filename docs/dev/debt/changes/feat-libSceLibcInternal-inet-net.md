# libSceLibcInternal

## add Unknown function info

- [inet_net_ntop and inet_net_pton](../../../core/libs/prx/libSceLibcInternal/InetNet.cpp) (libSceLibcInternal) - follow FreeBSD 11.4's [`inet_net_ntop.c`](https://github.com/freebsd/freebsd-src/blob/8c639945a44588f6cfdddfb057bb5aad88735da0/lib/libc/inet/inet_net_ntop.c) and [`inet_net_pton.c`](https://github.com/freebsd/freebsd-src/blob/8c639945a44588f6cfdddfb057bb5aad88735da0/lib/libc/inet/inet_net_pton.c) at the pinned commit. The port reads guest memory with checked copies. Where FreeBSD writes partial output before failing (IPv4 `inet_net_pton`), this port writes nothing on failure. For an IPv6 address with more groups than its prefix can hold, FreeBSD's zero-compression writes below its buffer; this port returns `ENOENT` for those inputs. A null source or destination throws, and an unreadable source sets `EFAULT`. The console's output for the same input is not measured.
- [inet_nsap_addr and inet_nsap_ntoa](../../../core/libs/prx/libSceLibcInternal/InetNsap.cpp) (libSceLibcInternal) - follow FreeBSD 11.4's [`nsap_addr.c`](https://github.com/freebsd/freebsd-src/blob/8c639945a44588f6cfdddfb057bb5aad88735da0/lib/libc/inet/nsap_addr.c) at the pinned commit, with `inet_nsap_ntoa` keeping its static buffer when no destination is given. A null text or binary pointer throws. The console's output for the same input is not measured.
