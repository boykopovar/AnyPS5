# libSceUserService

## change [sceUserServiceGetAgeLevel, sceUserServiceGetInitialUser,

- [sceUserServiceGetAgeLevel, sceUserServiceGetInitialUser, sceUserServiceGetUserNumber, sceUserServiceGetPlatformPrivacyWs1, sceUserServiceGetForegroundUser, sceUserServiceGetRegisteredUserIdList, sceUserServiceGetUserColor, sceUserServiceGetAccessibility*, sceUserServiceGetKeyboardType](../../../core/libs/prx/libSceUserService/Export.cpp) (libSceUserService) - returning `USER_SERVICE_ERROR_INVALID_ARGUMENT` for unwritable destination pointers is a host-safety fallback; measured with `sceUserServiceGetInitialUser` on a PS5 Pro payload process (13.60): an unwritable destination faults the calling process and a null destination answers `0x80960005`, both only after the initialization check - before `sceUserServiceInitialize` even a null destination answers `0x80960002` - so the console reads through the pointer and the error codes here are deviations on purpose, while this implementation does not gate `sceUserServiceGetInitialUser` on initialization state at all; in this payload, with Initialize done at priority 700, a valid destination answered `0x80940004` and was not written (no user session to query), which is an environment answer a title process may not reproduce. The other getters were not measured.
