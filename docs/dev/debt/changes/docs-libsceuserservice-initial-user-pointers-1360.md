# libSceUserService

## change [sceUserServiceGetAgeLevel, sceUserServiceGetInitialUser,

- [sceUserServiceGetAgeLevel, sceUserServiceGetInitialUser, sceUserServiceGetUserNumber, sceUserServiceGetPlatformPrivacyWs1, sceUserServiceGetForegroundUser, sceUserServiceGetRegisteredUserIdList, sceUserServiceGetUserColor, sceUserServiceGetAccessibility*, sceUserServiceGetKeyboardType](../../../core/libs/prx/libSceUserService/Export.cpp) (libSceUserService) - returning `USER_SERVICE_ERROR_INVALID_ARGUMENT` for unwritable destination pointers is a host-safety fallback; measured with `sceUserServiceGetInitialUser` on a PS5 Pro payload process (13.60): the initialization check comes first (a null destination before `sceUserServiceInitialize` answers `0x80960002`), then a null destination answers `0x80960005` and an unwritable one faults the calling process, so the console writes through the pointer and these error codes are deviations on purpose; this implementation does not gate `sceUserServiceGetInitialUser` on initialization state at all. With Initialize done, a valid destination answered `0x80940004` and was not written (no user session in that payload). The other getters were not measured.
