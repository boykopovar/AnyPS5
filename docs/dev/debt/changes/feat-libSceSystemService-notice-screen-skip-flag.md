# libSceSystemService

## change [sceSystemServiceSetNoticeScreenSkipFlag, sceSystemServiceDisableNoticeScreenSkipFlagAutoSet]

- [sceSystemServiceGetNoticeScreenSkipFlag, sceSystemServiceSetNoticeScreenSkipFlag, sceSystemServiceDisableNoticeScreenSkipFlagAutoSet](../../../core/libs/prx/libSceSystemService/Export.cpp) (libSceSystemService) - the flag is stored and read back for the running title, and starts false, but AnyPS5 has no system notice screen to skip, so it changes nothing else. `sceSystemServiceSetNoticeScreenSkipFlag` takes no argument and sets the flag, and `sceSystemServiceGetNoticeScreenSkipFlag` writes one byte holding it, as [SharpProspero](https://github.com/SvenGDK/SharpProspero/blob/60977b29103452b9681ae10c7a9011d44965bf16/src/SharpProspero/Interop/SystemService/SystemService.cs#L397-L417) documents the pair. A null output returns `0x80A10003` and an unwritable one returns the same; that result is a host-safety choice and is unmeasured. Nothing sets the flag automatically, so `sceSystemServiceDisableNoticeScreenSkipFlagAutoSet` only returns success. Metal Gear Solid 4 (PPSA18194) imports both and calls `sceSystemServiceDisableNoticeScreenSkipFlagAutoSet` once.
