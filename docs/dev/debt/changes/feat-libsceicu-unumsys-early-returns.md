# libSceIcu

## change [ICU numbering system exports]

- [ICU numbering systems](../../../core/libs/prx/libSceIcu/NumberingSystem.cpp) have unmeasured console ABI and ICU data-version equivalence. The six `unumsys_*` calls use pinned ICU 78.1 [unumsys.cpp](https://github.com/unicode-org/icu/blob/049e0d6a420629ac7db77256987d083a563287b5/icu4c/source/i18n/unumsys.cpp) and packaged locale/numbering-system resources; names/NIDs alone do not establish console signatures. A null handle closes without action. Failed status returns before argument access, and warnings continue into ICU. Null locale selects the configured guest default. A null system name and unusable guest memory throw. Foreign/stale handles throw. Native objects free on close; distinct token identities, including guest enumeration callback tables, remain until process teardown. Returned strings follow native lifetime and must not race close or cursor movement. Cleanup/reconfiguration require no live handles or concurrent ICU use. Closes when: console signatures, data and behavior are compared.
