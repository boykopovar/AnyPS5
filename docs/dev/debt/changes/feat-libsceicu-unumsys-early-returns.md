# libSceIcu

## change [ICU numbering system exports]

- [ICU numbering systems](../../../core/libs/prx/libSceIcu/NumberingSystem.cpp) have unmeasured console ABI and ICU data-version equivalence. The six `unumsys_*` calls use pinned ICU 78.1 [unumsys.cpp](https://github.com/unicode-org/icu/blob/049e0d6a420629ac7db77256987d083a563287b5/icu4c/source/i18n/unumsys.cpp) and packaged locale/numbering-system resources; names/NIDs alone do not establish console signatures. Null close is a no-op. Failures return before argument access. Warnings reach ICU. Null locale selects the configured guest default. A null system name and unusable guest memory throw. Foreign/stale handles throw. Close frees native objects. Tokens and their guest enumeration callback tables persist until exit. Returned strings follow native lifetime and must not race close or cursor movement. Cleanup/reconfiguration require no live handles or concurrent ICU use. Closes when: console signatures, data and behavior are compared.
