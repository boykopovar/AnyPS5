# libSceIcu

## add Resbund

- [ures_openNoDefault](../../../core/libs/prx/libSceIcu/LegacyExports.cpp) (libSceIcu) - not checked against `libSceIcu.sprx` or on a console. Guards a null `error` because bundled ICU dereferences it before any check of its own; a null `path` or `localeID` is passed through unchanged because bundled ICU resolves them itself to the default data package and the default locale.
- [ures_openFillIn](../../../core/libs/prx/libSceIcu/LegacyExports.cpp) (libSceIcu) - not checked against `libSceIcu.sprx` or on a console. Guards a null `error` (dereferenced before bundled ICU's own null-`r` check) and requires `bundle` writable when given; a null `bundle` keeps bundled ICU's own `U_ILLEGAL_ARGUMENT_ERROR`, and a null `path` keeps its default-package meaning.
- [ures_openDirectFillIn](../../../core/libs/prx/libSceIcu/LegacyExports.cpp) (libSceIcu) - not checked against `libSceIcu.sprx` or on a console. Same policy as `ures_openFillIn`: null `error` guarded, `bundle` validated writable when given, null `bundle` and null `path` passed through so bundled ICU's documented results stand.
- [ures_findResource](../../../core/libs/prx/libSceIcu/LegacyExports.cpp) (libSceIcu) - not checked against `libSceIcu.sprx` or on a console. Guards a null `path` (bundled ICU takes its length before parsing the package/locale/key separators) and requires `fillIn` writable when given; a null `status` is left alone because bundled ICU returns the caller's `fillIn` for it without dereferencing.
- [ures_findSubResource](../../../core/libs/prx/libSceIcu/LegacyExports.cpp) (libSceIcu) - not checked against `libSceIcu.sprx` or on a console. Guards a null `bundle` (dereferenced for the resource data) and requires `path` writable, because bundled ICU terminates path segments in place - which is why the parameter is `char*` upstream - so a guest's own buffer is modified by the call, as it is on a console.
- [ures_getKeywordValues](../../../core/libs/prx/libSceIcu/LegacyExports.cpp) (libSceIcu) - not checked against `libSceIcu.sprx` or on a console. Guards a null `keyword` and a null `error`; a null `path` is passed through for the default data package, matching bundled ICU.
- [ures_getStringByKeyWithFallback](../../../core/libs/prx/libSceIcu/LegacyExports.cpp) (libSceIcu) - not checked against `libSceIcu.sprx` or on a console. Guards a null `key` and requires `length` writable when given (bundled ICU writes it only when non-null); a null `bundle` is passed through so bundled ICU's own `U_ILLEGAL_ARGUMENT_ERROR` still reports.
- [ures_getVersionByKey](../../../core/libs/prx/libSceIcu/LegacyExports.cpp) (libSceIcu) - not checked against `libSceIcu.sprx` or on a console. Guards a null `key` and requires `version` writable: bundled ICU writes the four-byte version only when the status allows, so an unwritable destination has to report rather than fault. A null `bundle` is passed through so bundled ICU's own `U_ILLEGAL_ARGUMENT_ERROR` still reports.
