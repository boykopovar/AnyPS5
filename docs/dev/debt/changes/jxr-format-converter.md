The guest layout follows nine callbacks before the decoder pointer; callback offset 16 follows the decoder's first two callbacks. Unreadable pointer fields and null converter/decoder/callback pointers throw; width and height pass through, including null. The console ABI remains unverified.

- [PKFormatConverter_Release](../../../core/libs/prx/libSceJxr/Export.cpp#L347) is not measured on a PS5: pinned jxrlib [JXRGluePFC.c](https://github.com/4creators/jxrlib/blob/f7521879862b9085318e814c6157490dd9dbbdb4/jxrgluelib/JXRGluePFC.c#L2329-L2336) delegates to `PKFree((void**) ppFC)`. ## change [freeTileInfo]

- [freeTileInfo](../../../core/libs/prx/libSceJxr/src/GlueHelpers.cpp#L224): PS5 execution, prototype and codec/tile layouts are unverified; they are inferred from the named export and pinned LP64 jxrlib [strcodec.c](https://github.com/4creators/jxrlib/blob/f7521879862b9085318e814c6157490dd9dbbdb4/image/sys/strcodec.c#L811-L859).
