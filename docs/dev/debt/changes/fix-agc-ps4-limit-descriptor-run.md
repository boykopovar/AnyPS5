# libSceAgcDriver

## add Unknown function info

- [Buffer descriptors of the range limit in PS4 titles](../../../core/libs/prx/libSceAgcDriver/Graphics/src/ShaderResources.cpp) (libSceAgcDriver, PS4) - in a PS4 title (GCN guest shaders) a buffer V# whose size is `maxStorageBufferRange` or more is bound only up to the end of the run of readable registered allocations that holds its base and continue one another with the same access flags, and as the empty placeholder buffer when no registered allocation holds its base; PS5 titles keep the rules above. A PS4 shader can build a V# with num_records 0xFFFFFFFF from a raw pointer and index it with values read on the GPU, so no bound is known before the draw, and where the limit is 4294967295 such a V# is exactly the limit. On the console a read of unmapped memory faults, so a working title reads past that run only by jumping over a gap, which is not followed. CUSA24767 01.71 binds such V#s into a run of 33 allocations (110 MiB) in every draw of one screen. Not measured on hardware.
