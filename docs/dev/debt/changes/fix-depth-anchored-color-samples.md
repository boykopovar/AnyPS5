# libSceAgcDriver

## add Functional

- [Color-writing draws over a depth target with fewer samples](../../../core/libs/prx/libSceAgcDriver/Graphics/src/State.cpp) (AGC driver) - a draw that writes color under an N-sample rasterizer over a depth target of 1 < Z < N samples is drawn at N samples against a copy of the depth target expanded to N: coverage sample i < Z reads stored sample i, and each later sample the stored sample nearest to it on the 1/16-pixel grid, the lower index on a tie. `DB_EQAA.STATIC_ANCHOR_ASSOCIATIONS` 0 is treated as static and `MAX_ANCHOR_SAMPLES` above Z is ignored; none of the three is measured. Depth and stencil are read-only: depth or depth-bounds tests, depth or stencil writes, occlusion queries, alpha-to-coverage, `PS_ITER_SAMPLE`, centroid, sample, ancillary or coverage inputs, depth or sample-mask exports, overrasterization, fewer anchor samples than Z, devices that put the guest's samples in order, and a depth target no draw has rendered since its last other write throw. The copy of the stored samples names the sample locations of the last draw that rendered the depth target, not the color-writing draw's leading locations. Closes when: measured on a PS5.
