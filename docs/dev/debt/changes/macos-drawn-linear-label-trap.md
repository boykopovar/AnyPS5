# libSceAgcDriver

## change [Label read traps]

- [Label read traps](../../../core/libs/prx/libSceAgcDriver/Graphics/src/Texture.cpp) (libSceAgcDriver, macOS): at a label, a pending linear or small storage image that shares no page with another image a label stores or one being stored, and is not direct memory mapped twice, gets a [read trap](../../../core/libs/prx/libc/src/GuestWriteWatch.cpp) instead of its store. A drawn resident linear target with a host import gets one too, at a label or interrupt-only `RELEASE_MEM` of the graphics queue, instead of its completion-point store (next entry). The first access to its pages stores it whole through the host-read hook; a store of another image over it stores it too, and an eviction or explicit write-back stores it first. Other stores release the trap once their GPU copy is recorded, so a read before that copy lands sees the old bytes; a CPU store releases the traps on its pages first, leaving those images untrapped until the next label. A `GpuMutex` holder that touches a trapped page takes the trap off that page without storing the image, so the holder and every other thread read that page unstored until the next label or a store of the image; a system call that reads one without the hook fails with `EFAULT`, and other double mappings go undetected. `APS5_NO_LABEL_READ_TRAP=1` stores at the label.
