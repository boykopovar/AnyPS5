# libSceAgcDriver

## change [Layered color targets]

- [Layered color targets](../../../core/libs/prx/libSceAgcDriver/Graphics/src/State.cpp) (libSceAgcDriver) - 3D color targets with 64 KiB render-target or 4 KiB standard tiling render several slices, and so does a `CB_COLOR_VIEW` slice range on a 2D array target through the array's resident image, or on a surface of one slice as an array of the view's last slice + 1 slices, one slice pitch apart: a layered draw into an array without its resident image, a layered draw with a depth view of another slice count than its color views, and color targets of different slice counts throw. The vertex layer export (`PA_CL_VS_OUT_CNTL` USE_VTX_RENDER_TARGET_INDX) reaches the shader only for a layered draw and is otherwise ignored, as before; a layer beyond the view's last slice is undefined in Vulkan, while the console's handling (clamping to `SLICE_MAX`) is not modeled, and a view whose last slice lies past the surface is clamped to its last slice. DCC keys of a 3D color target are taken as one key per 256 bytes over the whole surface, every slice included, and only uniform keys (all uncompressed, or one fast-clear code) are interpreted, as for 2D targets; mixed keys leave the stored texels as they are. The console's DCC key layout for 3D surfaces is not checked (LEGO Horizon Adventures' (PPSA14632) lighting volumes are DCC)

## add Functional

- [Layered depth targets](../../../core/libs/prx/libSceAgcDriver/Graphics/src/DepthSurface.cpp) (libSceAgcDriver) - Layered draws use a DB_DEPTH_VIEW slice range matching the color layer count, or the view's slices without color, in a single-sample array image. Each layer retains depth, stencil and HTILE state; depth and stencil slice pitches span the mip chain, and HTILE slices span the sum of their mip metadata. Clears and plane copies are tracked per layer. Mismatched color/depth counts, multisampled layered depth and views without a depth plane throw. A later draw into one slice binds that layer. Out-of-range layer behavior is undefined in Vulkan; the DB SLICE_MAX clamp is not modeled.
