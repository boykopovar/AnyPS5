# libSceAudioOut
## change [sceAudioOut2PortCreateEx]
- [sceAudioOut2PortCreateEx](../../../core/libs/prx/libSceAudioOut/src/AudioOut2Port.cpp) (libSceAudioOut) - the PS5 4.03 module takes the same three arguments as `sceAudioOut2PortCreate` and passes an internal extension flag into the shared create core, which accepts a wider parameter interpretation. The host forwards to `sceAudioOut2PortCreate`; how the extended interpretation differs is unverified. Called once on a PS5 (firmware 11.60, payload process; a title process may differ) without `sceAudioOut2Initialize` and with all three arguments 0 (the prototype is assumed), it answered `0x80268001` without a fault; this forwards to `sceAudioOut2PortCreate` and answers `0x80260503` for the zero context, so the extended interpretation stays unmeasured.
## change [sceAudioOut2LoContextCreateEx and sceAudioOut2LoContextQueryMemoryEx]
- [sceAudioOut2LoContextCreateEx and sceAudioOut2LoContextQueryMemoryEx](../../../core/libs/prx/libSceAudioOut/src/AudioOut2Low.cpp) (libSceAudioOut) - the PS5 4.03 module inserts an optional extension pointer as the second argument: `LoContextQueryMemoryEx(params, exParams, size*)` and `LoContextCreateEx(params, exParams, buffer, bufferSize, ctx*)`. The query core validates params null, `max_object_ports` <= `0x80`, `max_ports` <= `0x20`, `guarantee_object_ports` <= `max_object_ports`, `num_grains` in `0x100..0x800` step `0x100` (`0x8026800d`), extension count <= `0x15`, and `queue_depth` <= `0x40` with an extension or `0x10` without (`0x80268001`); the host returns the same firmware memory size. Create also requires a non-null buffer and output, writes -1 to the output first, requires `exParams[1]` <= `max_object_ports` and `bufferSize` >= the computed size, then forwards to `sceAudioOut2ContextCreate`. The extension's service-side meaning is unverified. On a PS5 (firmware 11.60, payload process; a title process may differ) both answered `0x80268001` before initialization with all arguments 0 (prototypes assumed), as this does.
## change [sceAudioOut2LoPortCreateEx]
- [sceAudioOut2LoPortCreateEx](../../../core/libs/prx/libSceAudioOut/src/AudioOut2Low.cpp) (libSceAudioOut) - the PS5 4.03 module takes the same three arguments as `sceAudioOut2LoPortCreate` and passes an internal flag into the shared core, which widens the accepted port-type set (the `0x80`-family and `0x3f`).
