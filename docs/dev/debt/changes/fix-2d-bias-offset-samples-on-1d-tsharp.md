# shader

## add Functional

- [2D bias and offset samples through a 1D T#](../../../core/shader/recompiler/Optimization/src/ResourceTracker.cpp) (shader recompiler) - DIM 2D `image_sample_b`, `image_sample_lz_o`, `image_sample_l_o` and `image_sample_b_o` through a 1D T# take the 1D mode of the other 2D accesses through a 1D T#; through a 2D-array view of a 1D T# they still throw. Measured on RDNA2 (gfx1036, [hardware oracle](../HW_ORACLE.md)), not the PS5's gfx1013: on a 64-texel, five-level 32_FLOAT 1D T# with clamp and wrap addressing, each equals the DIM 1D form with the same first coordinate, bias, x offset and LOD on 32 of 32 rows, whatever the second coordinate and the y offset hold. The translated offset forms match the hardware on every row on NVIDIA and AMD; the translated bias forms equal the translated DIM 1D ones on every row, and both differ from the hardware in compute shaders, whose implicit LOD is taken as 0; in a pixel shader the LOD comes from the first coordinate's derivatives plus the bias.
