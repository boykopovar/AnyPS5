# libSceIcu

## change [Converter STOP/SKIP callbacks]

- [Converter callbacks](../../../core/libs/prx/libSceIcu/ConverterCallbacks.cpp) - console ABI and behavior are unverified. STOP, SKIP, SUBSTITUTE, ESCAPE and `ucnv_cbFromUWriteUChars` follow ICU 78.1, not the console. Their default-ignorable range includes U+180F unlike ICU 65.1; firmware selection is absent. The writer treats guest arguments as ICU's host layout and requires a host-ICU converter, which no guest export creates. Out-of-range reasons throw `invalid_argument`. SUBSTITUTE and ESCAPE throw on null converter arguments or status, including reset calls; ESCAPE also throws on null code units with a nonzero length. The writer throws on null status, or null arguments while status permits work; a failing status returns without reading the other pointers. STOP and SKIP preserve untouched pointers. Replacement output is tested only with a host-created converter. Closes when: compared with the console, including output and a title-provided converter.
