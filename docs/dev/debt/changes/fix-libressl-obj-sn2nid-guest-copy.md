# libSceLibreSsl

## add Functional

- [OBJ_sn2nid name](../../../core/libs/prx/libSceLibreSsl/src/ObjectText.cpp) (libSceLibreSsl) - the short name is read once through checked copies, in chunks that never cross a 4 KiB boundary, and both the added-object lookup and the built-in table search compare the host copy. An unreadable name throws, as a null one does; LibreSSL faults there. A host-safety fallback, not measured on the console.
