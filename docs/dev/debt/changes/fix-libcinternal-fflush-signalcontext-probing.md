# libSceLibcInternal

## change [signalcontext]

- [signalcontext](../../../core/libs/prx/libSceLibcInternal/UserContext.cpp) (libSceLibcInternal, NID `SQGxZCv3aYk`) follows FreeBSD 11.4's [`lib/libc/amd64/gen/signalcontext.c`](https://github.com/freebsd/freebsd-src/blob/release/11.4.0/lib/libc/amd64/gen/signalcontext.c#L44-L106): it copies the context below its stack pointer, builds an 80-byte `siginfo_t` holding only `si_signo`, removes the signal from the context's mask, points `uc_link` at the copy and runs the handler through the `makecontext` entry, which calls `exit(0)` or `setcontext` on `uc_link` when the handler returns. A null context returns -1 with `EINVAL` (22), and an unmapped context or stack pointer returns -1 with `EFAULT` (14) via `GuestCopyIn` / `GuestCopyOut` as a host-safety fallback instead of aborting or faulting; `errno` is preserved on success. It is not measured on a console, which lists only the name in the [PS5 3.20 export inventory](https://github.com/DNNDHH/PS5-3.20_Libs/blob/b2a77c09cd71c01f34c790cfbe98c751a13262ad/libSceLibcInternal.c). The handler also receives the three extra argument registers of the `makecontext` entry

## change [__fflush]

- [__fflush](../../../core/libs/prx/libSceLibcInternal/Stream.cpp) (libSceLibcInternal, NID `E1iwBYkG3CM`) reuses the public `fflush` implementation (`fflush_nid_postfix`) rather than FreeBSD 11.4 libc's unlocked helper ([fflush.c](https://github.com/freebsd/freebsd-src/blob/8c639945a44588f6cfdddfb057bb5aad88735da0/lib/libc/stdio/fflush.c)): it acquires stream locks. It probes non-null `stream` pointers with `GuestCopyIn`, returning -1 with `EFAULT` (14) on an unmapped pointer as a host-safety fallback instead of faulting. A closed stream returns 0 without modifying `errno`, as FreeBSD does for a stream with 0 flags, instead of the public `fflush` result of -1 with `EBADF`. Passing null flushes all open streams and returns 0 when all writes succeed (preserving `errno`) or EOF on write error. Console behavior is unverified.
