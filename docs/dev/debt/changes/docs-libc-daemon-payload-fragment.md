# libc

## change [daemon]

- [daemon](../../../core/libs/prx/libc/src/Process.cpp) (libc) changes the working directory and redirects descriptors without forking, because single-process emulation does not fork. A [PS5 payload process](https://github.com/boykopovar/AnyPS5/issues/13271#issuecomment-6792156826) (firmware 13.590.001) forks, and all four `nochdir`/`noclose` combinations return 0: working directory is `/` unless `nochdir` is set, and descriptors 0 to 2 point at `/dev/null` unless `noclose` is set. When `noChdir` is 0, `chdir_nid_postfix("/")` runs. When `noClose` is 0, descriptors 0, 1, and 2 are redirected to `/dev/null` (`NUL` on Windows). PPSA85300 imports it and fails to load without it. VLC 3.0 calls it only with `--daemon` ([libvlc.c](https://github.com/videolan/vlc/blob/6de05adcbaf2e8b85fe86aad4169393098628119/src/libvlc.c#L190-L197)), which the title avoids with `--ignore-config` ([player.cc](https://github.com/ZiZc3/VLC/blob/f3253020a64368153233ede29183014c0b6c8979/src/player.cc#L960-L981))
