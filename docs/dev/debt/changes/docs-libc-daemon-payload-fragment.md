# libc

## change [daemon]

- [daemon](../../../core/libs/prx/libc/src/Process.cpp) (libc) - does not fork, start a new session or point descriptors 0 to 2 at `/dev/null`: they are the emulator's own standard descriptors, which carry its logging, and there is no separate guest table for them. It returns 0 and changes the guest working directory to `/` unless `nochdir` is set. A [PS5 payload process](https://github.com/boykopovar/AnyPS5/issues/13271#issuecomment-6792156826) (firmware 13.590.001) forked, returned 0 for all four `nochdir`/`noclose` combinations, and moved to `/` and pointed descriptors 0 to 2 at `/dev/null` unless told not to. PPSA85300 imports it and fails to load without it; VLC 3.0 calls it only with its `daemon` option ([libvlc.c](https://github.com/videolan/vlc/blob/6de05adcbaf2e8b85fe86aad4169393098628119/src/libvlc.c#L190-L197)), which the title does not set ([player.cc](https://github.com/ZiZc3/VLC/blob/f3253020a64368153233ede29183014c0b6c8979/src/player.cc#L960-L981))
