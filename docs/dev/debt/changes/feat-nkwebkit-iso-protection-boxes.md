- [ISO frma, schm and tenc boxes](../../../core/libs/prx/libSceNKWebKit/src/IsoProtectionBoxes.cpp) (libSceNKWebKit) - not compared with a console module. A key ID vector resized before a failed length check holds zeros where WTF leaves the bytes uninitialized. The 3.20 `ISOTrackEncryptionBox::operator=`, deleted in 11.x, copies member by member. The rest follows the pinned 11.x box sources such as [ISOTrackEncryptionBox.cpp](https://github.com/neonmodder123/PS5-WebKit-11.x/blob/80f77e94c63ee7202eec3d4b5b1a021dd89011ba/Source/WebCore/platform/graphics/iso/ISOTrackEncryptionBox.cpp), including the key ID slice taken from the whole buffer at the view-relative offset. A null argument throws. Closes when: compared with a console module.
