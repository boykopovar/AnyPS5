# libSceIcu

## add Functional

- [Converter accessors and lifecycle](../../../core/libs/prx/libSceIcu/ConverterAccessors.cpp) (libSceIcu) - thirty one `ucnv_*` exports: the lifecycle (`ucnv_open`, `ucnv_close`, `ucnv_getName`, `ucnv_reset`, `ucnv_setFallback`), eighteen accessors for character size, type, CCSID, platform, ambiguity, fixed width, fallback, pending counts, the cache flush and the name, standard, standard name, alias count and alias lookups, plus the buffer conversion wrappers (`ucnv_fromUChars`, `ucnv_getNextUChar`, the from/to UCallBack getters, `ucnv_getInvalidChars`, `ucnv_getInvalidUChars`, `ucnv_setSubstString`, `ucnv_getStarters`). They forward to the host ICU entry points the rest of this library already calls, copying the guest status word in and out and the converter name in through `CopyGuestString`. `ucnv_fromUChars` stages through buffers sized from the caller's source length and capacity and writes back the partial prefix ICU produced on `U_BUFFER_OVERFLOW_ERROR`, clamped to the capacity; `ucnv_setSubstString` forwards the caller's length unchanged. `ucnv_getNextUChar` stages one character through a 64-byte window clamped to the caller's `sourceLimit`, which is a superset of any single character rather than a limit on the input. `ucnv_enableCleanup` and `ucnv_unload` stay stubs because ICU 68 hides them behind `U_HIDE_INTERNAL_API`; the callback setters and the entries built on them (`ucnv_setFromUCallBack`, `ucnv_setToUCallBack`, `ucnv_setSubstChars`, `ucnv_convertEx`, `ucnv_cbFromUWriteBytes`) stay stubs until the callback-driven conversion path is ported.
