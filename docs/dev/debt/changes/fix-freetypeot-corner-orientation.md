# libSceFreeTypeOt

## change [ft_corner_is_flat, ft_corner_orientation]

- [ft_corner_is_flat, ft_corner_orientation](../../../core/libs/prx/libSceFreeTypeOt/Export.cpp) (libSceFreeTypeOt) - console prototypes are unverified. Both follow FreeType 2.4.11 [ftcalc.c](https://github.com/freetype/freetype/blob/c6a66b49e64e9a21c013f23c867d238cf1aa98cb/src/base/ftcalc.c#L841-L955) built with `FT_LONG64`, which gives all 79 vectors measured on a PS5 (FW 11.60, payload process). `ft_corner_orientation` returns `out_y`, `-out_x`, `in_y` or `-in_x` when `in_y`, `in_x`, `out_y` or `out_x` is 0, checked in that order and negated for a negative partner, else the sign of the 64-bit cross product. Its `FT_Long` result is returned as `int`, so the console's register keeps the high half (`2^40` gave `0x10000000000`); this library returns the low 32 bits. `ft_corner_is_flat` compares L1 norms, flat up to 90 degrees and not from 100, as measured; sums that overflow `FT_Pos`, undefined there, throw. Closes when: compared with a console module.
