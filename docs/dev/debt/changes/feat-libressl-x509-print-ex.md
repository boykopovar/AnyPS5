# libSceLibreSsl

## add Functional

- [X509_print_ex](../../../core/libs/prx/libSceLibreSsl/src/X509PrintEx.cpp) - follows [LibreSSL 2.5.4](https://github.com/libressl/openbsd/tree/2e2c612066aa993717528a0249c15c51128d61cb/src/lib/libcrypto) `asn1/t_x509.c`, `asn1/t_pkey.c`, `x509v3/v3_prn.c`, `rsa/rsa_ameth.c`, `ec/ec_ameth.c`, `ec/eck_prn.c` and `dsa/dsa_ameth.c`; nothing is verified on a console. Prints header, version, serial number (including the `-1` negative hex fallback), signature algorithm, issuer and subject via `X509_NAME_print_ex` with `mlch`/`nmindent` rules, validity, SubjectPublicKeyInfo (RSA from DER or attached `EVP_PKEY` using the 2.5.4 `Public-Key: (<bits> bit)` heading, and the 11 standard named EC curves; missing/corrupt/unknown-OID keys print `Unable to load Public Key`), X509v3 extensions via `X509V3_EXT_print` and `ASN1_STRING_print`, and signature dump (DSA DER `r`/`s` or 18-byte colon hex dump); `libSceLibreSsl3` also forwards `X509_print_ex` here via [ParentExports.cpp](../../../core/libs/prx/libSceLibreSsl3/ParentExports.cpp). Unported extensions in `X509V3_EXT_print`, unsupported public key algorithms or EC curves, RSA-PSS signature parameters, and null pointers that LibreSSL dereferences throw `NotImplemented_nid_no_patch` or `std::invalid_argument`. `X509_CERT_AUX_print` is omitted because `LibreSslX509` only models the 32-byte header shared with `libSceLibreSsl3` and no export attaches auxiliary certificate data. Closes when: compared with the console and remaining public-key/extension/aux printers are implemented.
