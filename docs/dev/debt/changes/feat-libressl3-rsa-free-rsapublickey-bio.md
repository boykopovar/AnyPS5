# libSceLibreSsl3

## add Functional

- [RSA_free](../../../core/libs/prx/libSceLibreSsl3/src/RsaCrypto.cpp) (libSceLibreSsl3) - not measured on a PS5. A key whose method pointer is set goes to libSceLibreSsl's `RSA_free`, because only that library's `RSA_new` sets one; keys from this module's `RSA_new`, which leaves it null, are freed here. Native keys holding PSS parameters, blinding state, extra data or method data still throw. Otherwise follows LibreSSL 4.0.0 [`RSA_free`](https://github.com/libressl/openbsd/blob/ce488b78e0bd994780569df718596b9776ff681a/src/lib/libcrypto/rsa/rsa_lib.c#L160-L189). Closes when: the RSA layout is measured on the firmware module and native keys carry a method.
- [d2i_RSAPublicKey_bio](../../../core/libs/prx/libSceLibreSsl3/src/RsaPublicKeyBio.cpp) (libSceLibreSsl3) - not measured on a PS5. Follows LibreSSL 4.0.0 [`d2i_RSAPublicKey_bio`](https://github.com/libressl/openbsd/blob/ce488b78e0bd994780569df718596b9776ff681a/src/lib/libcrypto/x509/x_all.c#L191-L195), the [SEQUENCE decoder](https://github.com/libressl/openbsd/blob/ce488b78e0bd994780569df718596b9776ff681a/src/lib/libcrypto/asn1/tasn_dec.c#L735-L909) and [`c2i_ASN1_INTEGER_cbs`](https://github.com/libressl/openbsd/blob/ce488b78e0bd994780569df718596b9776ff681a/src/lib/libcrypto/asn1/a_int.c#L660-L739), including BER headers inside the SEQUENCE and negative integers. The `d2i_PrivateKey_bio` reader fetches the object and rejects the indefinite outer lengths that `asn1_d2i_read_bio` accepts. `Field=` and `Type=` error data is not queued. Closes when: the module is measured and the reader accepts indefinite outer lengths.
- [Encrypted PEM keys](../../../core/libs/prx/libSceLibreSsl3/src/PemEncryption.cpp) (libSceLibreSsl3) - not measured on a PS5. Follows LibreSSL 4.0.0 [`PEM_do_header`](https://github.com/libressl/openbsd/blob/ce488b78e0bd994780569df718596b9776ff681a/src/lib/libcrypto/pem/pem_lib.c#L442-L485), [`EVP_PBE_CipherInit`](https://github.com/libressl/openbsd/blob/ce488b78e0bd994780569df718596b9776ff681a/src/lib/libcrypto/evp/evp_pbe.c#L180-L231) and the `tasn_dec.c` template decoder. Indefinite lengths, constructed strings and UTCTime or GeneralizedTime values inside an `ENCRYPTED PRIVATE KEY` throw through `NotImplemented_nid_no_patch`. OIDs are matched against the built-in table, so objects registered with `OBJ_create` are ignored. The writer knows the three `EVP_aes_*_cbc` objects by address and throws for any other cipher object. `Field=`, `Type=` and `NID=` error data is not queued. Closes when: the BER forms are decoded and the module is measured.

## change [`PEM_read_bio_PrivateKey`, `PEM_read_bio_PUBKEY` and `PEM_write_bio_PrivateKey`]

- [`PEM_read_bio_PrivateKey`, `PEM_read_bio_PUBKEY` and `PEM_write_bio_PrivateKey`](../../../core/libs/prx/libSceLibreSsl3/src/PemKeys.cpp) (libSceLibreSsl3) - encrypted keys: only AES-128/192/256-CBC, as `DEK-Info` records and as PBES2 with PBKDF2 (HMAC MD5, SHA-1, SHA-224, SHA-256, SHA-384, SHA-512, SHA-512/256). Every other 4.0.0 cipher, PBES1 and PKCS#12 schemes, the SHA-512/224 and SHA-3 PRFs and the terminal pass phrase prompt (null callback and null `u`) throw through `NotImplemented_nid_no_patch`, as does a `DSA PRIVATE KEY` record. Bare `RSA*` labels stay stubs. The `EVP_PKEY_ASN1_METHOD` table is a static list of the 4.0.0 `pem_str` entries, and writes are always PKCS#8. `PEM_read_bio_PrivateKey` keeps its NID behind a `nid_disambig1` name because the parent declares the plain one. The `Expecting: %s` error data is not queued; no console measurement. Closes when: the missing ciphers and digests, DSA and bare `RSA*` labels land.
