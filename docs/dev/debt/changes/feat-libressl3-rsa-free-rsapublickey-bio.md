# libSceLibreSsl3

## add Functional

- [RSA_free](../../../core/libs/prx/libSceLibreSsl3/src/RsaCrypto.cpp) (libSceLibreSsl3) - not measured on a PS5. A key whose method pointer is set goes to libSceLibreSsl's `RSA_free`, because only that library's `RSA_new` sets one; keys from this module's `RSA_new`, which leaves it null, are freed here. Native keys holding PSS parameters, blinding state, extra data or method data still throw. Otherwise follows LibreSSL 4.0.0 [`RSA_free`](https://github.com/libressl/openbsd/blob/ce488b78e0bd994780569df718596b9776ff681a/src/lib/libcrypto/rsa/rsa_lib.c#L160-L189). Closes when: the RSA layout is measured on the firmware module and native keys carry a method.
- [d2i_RSAPublicKey_bio](../../../core/libs/prx/libSceLibreSsl3/src/RsaPublicKeyBio.cpp) (libSceLibreSsl3) - not measured on a PS5. Follows LibreSSL 4.0.0 [`d2i_RSAPublicKey_bio`](https://github.com/libressl/openbsd/blob/ce488b78e0bd994780569df718596b9776ff681a/src/lib/libcrypto/x509/x_all.c#L191-L195), the [SEQUENCE decoder](https://github.com/libressl/openbsd/blob/ce488b78e0bd994780569df718596b9776ff681a/src/lib/libcrypto/asn1/tasn_dec.c#L735-L909) and [`c2i_ASN1_INTEGER_cbs`](https://github.com/libressl/openbsd/blob/ce488b78e0bd994780569df718596b9776ff681a/src/lib/libcrypto/asn1/a_int.c#L660-L739), including BER headers inside the SEQUENCE and negative integers. The `d2i_PrivateKey_bio` reader fetches the object and rejects the indefinite outer lengths that `asn1_d2i_read_bio` accepts. `Field=` and `Type=` error data is not queued. Closes when: the module is measured and the reader accepts indefinite outer lengths.
- [Encrypted PEM keys](../../../core/libs/prx/libSceLibreSsl3/src/PemEncryption.cpp) (libSceLibreSsl3) - not measured on a PS5. Follows LibreSSL 4.0.0 [`PEM_do_header`](https://github.com/libressl/openbsd/blob/ce488b78e0bd994780569df718596b9776ff681a/src/lib/libcrypto/pem/pem_lib.c#L442-L485), `EVP_PBE_CipherInit` and the `tasn_dec.c` template decoder. DES blocks come from mbedtls, with the `EVP_DecryptFinal_ex` checks redone here, to decrypt only. The two MD2 schemes queue `EVP_R_UNKNOWN_DIGEST`: 4.0.0 has no MD2. Indefinite lengths, constructed strings and UTCTime or GeneralizedTime values inside an `ENCRYPTED PRIVATE KEY` throw through `NotImplemented_nid_no_patch`. OIDs are matched against the built-in table, so objects registered with `OBJ_create` are ignored. The writer knows the three `EVP_aes_*_cbc` objects by address and throws for any other cipher object. `Field=`, `Type=` and `NID=` error data is not queued. Closes when: the BER forms are decoded and the module is measured.
- [DSA private keys](../../../core/libs/prx/libSceLibreSsl3/src/DsaKeys.cpp) (libSceLibreSsl3) - not measured on a PS5. `DSA PRIVATE KEY` and PKCS#8 DSA keys follow LibreSSL 4.0.0 [`dsa_ameth.c`](https://github.com/libressl/openbsd/blob/ce488b78e0bd994780569df718596b9776ff681a/src/lib/libcrypto/dsa/dsa_ameth.c) and `dsa_check_key`. The 112-byte `DSA` follows `dsa_local.h`, with `flags` 1 and `references` 1 as `DSA_new` leaves them; `meth` stays null, the module's method address being unknown, and freeing a key with `meth`, `method_mont_p` or `ex_data` set throws. `BN_is_prime_ex` is 64 Miller-Rabin rounds of mbedtls on host entropy, not Baillie-PSW: verdicts can differ only on a composite that passes one of the two. Indefinite lengths throw. A DSA `PUBLIC KEY` fails as an unsupported algorithm and `d2i_PrivateKey_bio` reads six fields as RSA. `Field=` and `Type=` error data is not queued. Closes when: the module is measured, `DSA_new` exists and DSA public keys are decoded.

## change [`PEM_read_bio_PrivateKey`, `PEM_read_bio_PUBKEY` and `PEM_write_bio_PrivateKey`]

- [`PEM_read_bio_PrivateKey`, `PEM_read_bio_PUBKEY` and `PEM_write_bio_PrivateKey`](../../../core/libs/prx/libSceLibreSsl3/src/PemKeys.cpp) (libSceLibreSsl3) - encrypted keys: readers take AES-128/192/256-CBC, DES-CBC, DES-EDE-CBC and DES-EDE3-CBC as `DEK-Info` records, those with an OID as PBES2 with PBKDF2, and PBE-MD5-DES, PBE-SHA1-DES, PBE-SHA1-3DES and PBE-SHA1-2DES; the writer takes AES only. Other 4.0.0 ciphers, the RC2 and RC4 schemes, the SHA-512/224 and SHA-3 PRFs and the terminal pass phrase prompt throw through `NotImplemented_nid_no_patch`. Bare `RSA*` labels stay stubs. The `EVP_PKEY_ASN1_METHOD` table is a static list of the 4.0.0 `pem_str` entries; writes are always PKCS#8. `PEM_read_bio_PrivateKey` has a `nid_disambig1` name because the parent declares the plain one. `Expecting: %s` error data is not queued; no console measurement. Closes when: the missing ciphers and digests, DSA public keys and bare `RSA*` labels land.

## change [`d2i_PUBKEY`, `d2i_PrivateKey_bio`, `d2i_PKCS8_PRIV_KEY_INFO`, `d2i_PKCS8_PRIV_KEY_INFO_bio`, `i2d_PKCS8_PRIV_KEY_INFO`, `PKCS8_PRIV_KEY_INFO_free`, `EVP_PKCS82PKEY` and `EVP_PKEY2PKCS8`]

- [`d2i_PUBKEY`, `d2i_PrivateKey_bio`, `d2i_PKCS8_PRIV_KEY_INFO`, `d2i_PKCS8_PRIV_KEY_INFO_bio`, `i2d_PKCS8_PRIV_KEY_INFO`, `PKCS8_PRIV_KEY_INFO_free`, `EVP_PKCS82PKEY` and `EVP_PKEY2PKCS8`](../../../core/libs/prx/libSceLibreSsl3/src/KeyDer.cpp) - console ABI and error-queue parity are unverified. Follows LibreSSL 4.0.0 `x_pubkey.c`, `p8_pkey.c`, `evp_pkey.c` and `a_pkey.c` for RSA, EC P-256/P-384 and DSA private keys only (other curves and types, and DSA public keys, fail). `PKCS8_PRIV_KEY_INFO` uses the 32-byte LP64 layout, storing optional `[0]` attributes as raw `Asn1String*` bytes rather than `STACK_OF(X509_ATTRIBUTE)`. `*_bio` reads one definite-length TLV object without over-reading; indefinite-length BER is rejected. RSA keys in `EVP_PKEY` use `RSA_new` and `RsaAsn1Method`. Closes when: compared with the console.
