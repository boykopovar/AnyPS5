# relinker

## change [1/sqrt(x) computed as SQRT then DIV]

- `--to-intel` [reciprocal stubs](../../../core/relinker/codegen/src/x86/ReciprocalLowering.cpp) for (V)RCPPS, (V)RSQRTPS, (V)RCPSS and (V)RSQRTSS read [tables](../../../core/relinker/codegen/src/x86/SharedStubData.cpp) from [measure.cpp](../../../tools/reciprocal-tables/measure.cpp) on a desktop Zen 2 (Ryzen 7 3700X), not a PS5; whether the PS5's CPU uses the same tables is unmeasured, and PPSA21564 has not been rerun. On that Zen 2 the legacy, VEX.128 and VEX.256 register-form stubs match the native instructions for all 2^32 inputs. A stub is about 400 bytes (500 for VEX.128, 950 for VEX.256) plus 24.8 KB of tables per image and takes about 16 ns per call on that Zen 2 (old legacy stub 7 ns, native 1.5 ns). A misaligned legacy `m128` is read where native raises #GP outside AMD's misaligned SSE mode. FS and GS memory forms, and a site shorter than 5 bytes with no movable instruction after it (5 in PPSA21564, not recounted), keep the native instruction. Closes when: measured on a PS5.
