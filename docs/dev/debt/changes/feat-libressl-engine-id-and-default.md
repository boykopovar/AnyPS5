Follows [LibreSSL 2.5.4](https://github.com/libressl/openbsd/tree/2e2c612066aa993717528a0249c15c51128d61cb/src/lib/libcrypto/engine) with an empty engine list: unknown ids push `ENGINE_R_NO_SUCH_ENGINE` without `id=` data, null engines or commands push `ERR_R_PASSED_NULL_PARAMETER` (function `0xfff`). `ENGINE_get_id` copies `id` at offset 0 and throws on null or unreadable `engine` where LibreSSL faults. `ENGINE_set_default` checks 2.5.4's `0x06FF` mask (ignoring `0x0100` and bits above `0x0400`, including 3.x `0x0800`), returning 1 if clear and throwing on any `engine` otherwise; other calls throw on non-null `engine`.
