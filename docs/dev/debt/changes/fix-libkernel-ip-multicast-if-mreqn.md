# libkernel

## change [IP_ADD_MEMBERSHIP, IP_DROP_MEMBERSHIP, IP_MULTICAST_IF]

- [IP_ADD_MEMBERSHIP, IP_DROP_MEMBERSHIP, IP_MULTICAST_IF](../../../core/libs/prx/libkernel/Socket/src/SocketOptions.cpp) (libkernel) - set on the host socket after the checks a PS5 (firmware 13.60, payload process) showed: `EOPNOTSUPP` on a stream socket, `EINVAL` for a short value or a group outside 224.0.0.0/4, `EADDRINUSE` for a group joined twice and `EADDRNOTAVAIL` for one not joined, tracked per socket. An interface the host lacks fails with the host's error (`EADDRNOTAVAIL` on the console); on Windows, interface addresses in 0.0.0.0/8 other than `0.0.0.0` fail with `EADDRNOTAVAIL` before reaching Winsock, which reads them as interface indices. A group joined through `INADDR_ANY` and through that interface's address counts as two here. Not measured, after FreeBSD 11.4: a drop through `INADDR_ANY` leaves the first such group on any interface (`inp_leave_group`), and the other multicast options fail with `EOPNOTSUPP` on a stream socket (`inp_setmoptions`).

## add Functional

- [IP_MULTICAST_IF with an ip_mreqn](../../../core/libs/prx/libkernel/Socket/src/SocketOptions.cpp) (libkernel) - a positive `imr_ifindex` throws, as no guest interface index is modelled, and so does a 12-byte read while an interface is selected, where FreeBSD returns its index and address. Taken from FreeBSD 11.4's source and not measured on a console: [`inp_set_multicast_if`](https://github.com/freebsd/freebsd-src/blob/8c639945a44588f6cfdddfb057bb5aad88735da0/sys/netinet/in_mcast.c#L2456-L2517) selects by index alone, so index 0 clears the interface whatever the addresses and a negative index fails with `EINVAL`, and [`inp_getmoptions`](https://github.com/freebsd/freebsd-src/blob/8c639945a44588f6cfdddfb057bb5aad88735da0/sys/netinet/in_mcast.c#L1788-L1812) returns a zeroed `ip_mreqn` for a 12-byte read with none selected
