# libSceGnmDriver

## add Functional

- [Workload stream and queue exports](../../../core/libs/prx/libSceGnmDriver/Export.cpp) (libSceGnmDriver, PS4) - four `_nid_disambig1` exports answer as the Neo provider's copies do, following the PS4 13.52 `libSceGnmDriver.sprx` and `libSceGnmDriverForNeoMode.sprx`, which hold these bodies byte for byte (read from disassembly, not measured on a console). `sceGnmDestroyWorkloadStream` answers 1 for a stream of 0 or 16 and above and 0 for 1 to 15. `sceGnmGetNumTcaUnits` answers 2. `sceGnmMapComputeQueueWithPriority` refuses a pipe above 6, a queue above 7, a ring size with more than one bit set, a ring base with a non-zero low byte, an unaligned read pointer or a priority above 1, and answers the unavailable status otherwise; a ring size of 0 is not refused there, as the Neo provider answers on Linux. `sceGnmRequestFlipAndSubmitDoneForWorkload` answers the too-small status below 0x100 words and the unavailable status above. No GPU state is modelled, so every answer is a constant.

- [Constant GPU query exports](../../../core/libs/prx/libSceGnmDriver/Export.cpp) (libSceGnmDriver, PS4) - seven `_nid_disambig1` exports answer as the Neo provider's copies do, from the same 13.52 disassembly, which holds these bodies byte for byte (read from disassembly, not measured on a console). `sceGnmGetGpuBlockStatus`, `sceGnmGetGpuInfoStatus`, `sceGnmGetLastWaitedAddress`, `sceGnmGetProtectionFaultTimeStamp`, `sceGnmGetShaderProgramBaseAddress`, `sceGnmGetShaderStatus` and `sceGnmInsertThreadTraceMarker` answer 0, and `sceGnmSetWaveLimitMultipliers` answers 1. No GPU state is modelled, so every answer is a constant.

- [Draw writers still absent from the normal provider](../../../core/libs/prx/libSceGnmDriver/Export.cpp) (libSceGnmDriver, PS4) - `sceGnmDrawIndexMultiInstanced` and `sceGnmDrawOpaqueAuto` still throw. The normal provider has no draw writer, and the Neo packet encodings use Neo-only flag constants, so their PS5 encoding is unestablished here. Closes when: the normal provider's packet encoding is measured against a console.
