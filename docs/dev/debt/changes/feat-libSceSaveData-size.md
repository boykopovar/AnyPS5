# libSceSaveData.native

## add Unknown function info

- [sceSaveDataGetSaveDataCount, sceSaveDataGetAllSize](../../../core/libs/prx/libSceSaveData.native/Export.cpp) (libSceSaveData.native) - the first counts the directories directly under the host save root and the second sums the files inside them, reporting KiB rounded up. Both write through the second argument and ignore the first, as [SharpEmu](https://github.com/sharpemu/sharpemu/blob/4d5697892e70f1d508ae6dbddf1e4b518c97fd84/src/SharpEmu.Libs/SaveData/SaveDataExports.cs#L509) and [RPS5E](https://github.com/keklick1337/rps5e/blob/d540c46f5d83efac3a0df9b2edc14cf12fe9f2be/crates/ps5hle/src/savedata.rs#L1473-L1497) do; the first argument's meaning is unverified. A null or unwritable output returns `0x809F0000` (`SAVE_DATA_ERROR_PARAMETER`), a call before `sceSaveDataInitialize` returns `0x809F0001` (`SAVE_DATA_ERROR_NOT_INITIALIZED`), and a host read failure returns `0x809F000B` (`SAVE_DATA_ERROR_INTERNAL`). The last two results and the KiB rounding are this implementation's choices; the console's count and size for a real title are unmeasured. Host `.param` and `.blocks` sidecars sit beside a save directory and are not counted.
