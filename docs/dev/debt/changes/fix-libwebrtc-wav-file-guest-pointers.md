# libwebrtc

## change FileWrapper::Close, Flush, Write and its move constructor

- [FileWrapper::Close, Flush, Write and its move constructor](../../../core/libs/prx/libwebrtc/src/FileWrapper.cpp) have no PS5 ABI or behavior measurements. Signatures and layout follow WebRTC [M127](https://webrtc.googlesource.com/src/+/e0b28a6a81a989c1f5c89e30fcd247870047390d/rtc_base/system/file_wrapper.cc) and [M134](https://webrtc.googlesource.com/src/+/8d78f5de6c27b2c793039989ea381f1428fb0100/rtc_base/system/file_wrapper.cc), where the four methods are identical. The module's exact revision is unknown; its `rtc::` names and `InterleavedView` resampler exports bracket it between those versions (PR #13687). Wrappers are copied through `GuestPtr`, payloads in `Write` are staged through bounded 4096-byte host buffers, and `GuestWritable_nid_no_patch` is checked before closing streams or clearing moved-from handles, preserving caller `errno` around guest memory checks. Null or inaccessible wrappers, invalid move objects, non-writable wrappers, and `Flush` or `Write` without an open stream throw; a nonempty write from null or inaccessible data throws instead of dereferencing guest memory on the host. File errors follow guest libc and lack console comparison.

## change webrtc::WavReader::Reset, ReadSamples for int16_t and Close

- [webrtc::WavReader::Reset, ReadSamples for int16_t and Close](../../../core/libs/prx/libwebrtc/src/WavReader.cpp) (libwebrtc) - the 64-byte `WavReader` layout (vtable, `sample_rate_` at 8, `num_channels_` 16, `format_` 24, `num_samples_in_file_` 32, `num_unread_samples_` 40, `file_` 48, `data_start_pos_` 56) is assumed, not measured. A failed `RTC_CHECK` throws `std::runtime_error`; a reader without an open file throws. Readers are copied through `GuestPtr` (`CopyIn`/`CopyOut`), `ReadSamples` stages output through bounded 4096-sample host buffers, and `GuestWritable_nid_no_patch` probes validate non-writable guest `WavReader` and sample pointers before advancing streams or closing handles. Adapted from [wav_file.cc](https://webrtc.googlesource.com/src/+/8d78f5de6c27b2c793039989ea381f1428fb0100/common_audio/wav_file.cc), [audio_util.h](https://webrtc.googlesource.com/src/+/8d78f5de6c27b2c793039989ea381f1428fb0100/common_audio/include/audio_util.h) and [file_wrapper.cc](https://webrtc.googlesource.com/src/+/8d78f5de6c27b2c793039989ea381f1428fb0100/rtc_base/system/file_wrapper.cc), the same at M127 for the code used; file reads go through the guest libc. Closes when: compared with the console.
