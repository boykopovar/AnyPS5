# libSceUserService

## change [sceUserServiceInitialize](../../../core/libs/prx/libSceUserService/Export.cpp) - returning `0x80960005`

- [sceUserServiceInitialize](../../../core/libs/prx/libSceUserService/Export.cpp) - returning `0x80960005` (`USER_SERVICE_ERROR_INVALID_ARGUMENT`) for an unmapped or unreadable parameter pointer is a defensive host-safety fallback; measured on a PS5 Pro payload process (13.60): an unwritable non-null parameter faults the calling process while a null parameter is accepted with return 0, so the console stores through the pointer and this implementation's error code is the deviation; priorities are validated against [256..767] before initialization state - 0, 1, 255, 768 and -1 answer `0x80960005`, first calls with 256, 700 and 767 answer 0, and a repeated valid call answers `0x80960003` - matching the host range constants and check order.

## change [sceUserServiceGetEvent](../../../core/libs/prx/libSceUserService/Export.cpp) (libSceUserService) - login and logout events

- [sceUserServiceGetEvent](../../../core/libs/prx/libSceUserService/Export.cpp) (libSceUserService) - login and logout events queued dynamically on controller hotplug have no source and are assumed, not measured. On a PS5 (firmware 11.60, payload process) one event with `event_type` 0 follows `sceUserServiceInitialize`, then `NO_EVENT`; re-measured on a PS5 Pro payload process (13.60): before Initialize the call answers `0x80960002` writing nothing, after the first successful Initialize (priority 700) one event with `event_type` 0 and a non-zero `user_id` at offset 4 is returned, then `0x80960007` (`NO_EVENT`) writes nothing again - the 11.60 sequence reproduces exactly; here one login event per connected user, so this matches with one user. Six titles disassembled for this entry drain the queue until the call returns nonzero. PPSA01494 01.100.002 (at 0x374C0C6), PPSA30839 01.003.000 (0x4DF3F0), PPSA31162 02.000.001 (0x550ED0) and PPSA34502 01.010.000 (0x30035C, 0x300433) act only on `event_type` 0 and 1, reading `user_id` at offset 4 for both, and skip other types. PPSA18194 01.004.003 (0x16D44A3) tells `NOT_INITIALIZED` (0x80960002) and `NO_EVENT` (0x80960007) apart and logs any other error. PPSA21564 01.007.000 copies each 8-byte event into a list at one site (0x2AFCA8) and discards them at the other (0x2B6CF3)
