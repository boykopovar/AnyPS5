# shader

## change [Unsigned packed32 images]

- [Unsigned packed32 images](../../../core/shader/recompiler/SpirvBackend/src/SpirvImageEmitter.cpp) - Measured on gfx1036 (driver 31.0.22044.1) with the hardware oracle at wave32, through a 2D T# carrying the guest code and an identity dst_sel rather than the recompiler's R32_UINT view: although RDNA2 Table 47 omits 37/41, `image_load` returns every code of every field by the layout (10/11/11 bits at 0/10/21 for 37/41, 2/10/10/10 at 0/2/12/22 for 44/48), UNORM as the correctly rounded f32 of n/max, not n times f32(1/max), and UINT as n, and the missing W of 37/41 returns the X field. A 32-bit `image_store` stores the correctly rounded code of the exact product x*max into 37/44, with half-even and half-up not separable from f32 inputs, giving 0 for negatives, -0 and every NaN tried and the maximum from 1.0 up to +inf, and saturates unsigned to the field maximum into 41/48. Wave64 at denormal modes 0 and 3, and wave32 at denormal modes 1-3, return the same words for every load and store above; f32 denormal store inputs at wave32 store 0 into 37/44 and their bit pattern, saturated, into 41/48 in modes 0-3 alike, so flush and keep are not separable. D16 of codes 41, 44 and 48 at wave32 and denormal mode 0 (the D16 entry records 37) loads UNORM 44 as the correctly rounded f16 of n/max and UINT as n, the missing W of 41 returning X, and a D16 store writes the same word as the 32-bit store. The PS5's gfx1013, wave64 at denormal modes 1 and 2, D16 at wave64 or other denormal modes, and samples are not measured. They reuse the typed-buffer bitfields through R32_UINT views, preserving UINT integers and dividing UNORM fields by their maxima in the shader. UNORM 37/44 inherit converted-unorm sampling limits: direct 2D/2D-array views, LOD 0, equal point or bilinear min/mag filters, wrap or clamp-to-edge; other samples, gathers, LOD queries, reductions and unnormalized coordinates throw. A format 37 image that no sample, gather or LOD query reads accepts an identity dst_sel whose W selects the missing channel: `image_load` returns the X field for it, as measured above, and `image_store` is measured with a DMASK of X, Y and Z only, so a DMASK that stores the missing W is not measured. An image that any sample reads, any other dst_sel selecting the missing W of 37 and the 11_11_10_UNORM sibling throw, because they are not measured; D16 UNORM loads and stores take the converted-image D16 path, not exercised for these codes, and D16 samples throw. UINT 41/48 inherit converted-integer point sampling. Host execution tests cover bit walks, boundaries, DMASK, swizzles, samples and guarded guest-byte store readback.
