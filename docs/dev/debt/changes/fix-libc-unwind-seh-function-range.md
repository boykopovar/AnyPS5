# libc

## change [slots]

- The [slots](../../../core/libs/prx/libc/src/exception/Unwind.cpp) of the libunwind `AbstractUnwindCursor` table at the start of the [`_Unwind_Context`](../../../core/libs/prx/libc/include/exceptions/Unwind.hpp) that `_Unwind_Backtrace` passes to its callback follow `UnwindCursor<LocalAddressSpace, Registers_x86_64>` of [LLVM 18.1.8](https://github.com/llvm/llvm-project/blob/llvmorg-18.1.8/libunwind/src/UnwindCursor.hpp); the console's own `libSceLibcInternal` is not checked. Differences from LLVM 18.1.8: `step` walks Windows frames without a DWARF record (host frames of SEH builds, system DLLs on every build) with `RtlVirtualUnwind`, and `getInfo` gives them the range and image base of their `RUNTIME_FUNCTION` but no unwind info; `step` looks a signal frame up at its IP instead of the IP minus one and ends at a frame whose rules leave `rsp` and `rip` unchanged; `getFunctionName` on Windows takes the nearest export at or below the IP; `jumpto` does not restore `r10` and `r11`

## change [_Unwind_FindEnclosingFunction]

- [_Unwind_FindEnclosingFunction](../../../core/libs/prx/libc/src/exception/Unwind.cpp) (libc, NID `go1LaO7f15k`) reports the first byte of the function owning an address, or 0 when no frame record covers it. The lookup subtracts one first, as libgcc does, so a return address belongs to the function it was called from and a first-byte argument names the function before it. The `libc.prx` of PPSA01341 v01.007.000 exports it at RVA `0x830d0`, where the module builds a context, sets the address, finds the frame and returns its function start or 0; that disassembly does not settle the subtraction, so a first-byte argument there is unverified. Windows answers from the `.ehmeta` index or the `.ehfram` copy of `.eh_frame`, and for a Windows frame without them from the start of the [`RUNTIME_FUNCTION`](https://learn.microsoft.com/en-us/cpp/build/exception-handling-x64) holding it, even a chained one; macOS uses compact unwind. Console execution and other firmware versions are unmeasured.
