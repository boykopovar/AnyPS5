# libScePlayReady4

## add Functional

- [scePlayReadyProfileStart, Enter, Leave, Pause, Resume, Stop and Clear](../../../core/libs/prx/libScePlayReady4/Export.cpp) (libScePlayReady4) - recovered from 13.40 bodies. `Start(buffer, entries)` stores a guest buffer of `entries` 24-byte records, clearing used and paused; a null buffer is ignored. `Enter(a, b, c)` records depth+1 and the three argument bytes at +0..3, a microsecond timestamp at +8 and pushes the record index; `Leave` writes `now - entry timestamp` at +16. `Pause`/`Resume` toggle recording; `Stop` clears the buffer and pauses; `Clear` zeroes the used records and resets the count. Depth caps at 64 records; deeper `Enter` calls only bump it. Timestamps use the host steady clock in microseconds; the module reads the console clock and the unit is otherwise unverified, so only differences matter. Guest writes use checked copies; an unwritable buffer throws where the console faults. The record layout and signatures are from disassembly, not measured on a console.
