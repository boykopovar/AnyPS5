- [WTF::URL::URL(const URL&, const String&, const URLTextEncoding*) and WTF::URL::setPassword](../../../core/libs/prx/libSceJsc/src/ApiBridge.cpp) (libSceJsc) - not compared with a console module; the console WTF version is unverified. The URL parser exists only in libSceNKWebKit, which registers both; unregistered, a call throws. The complete-object constructor runs the base-object one libSceNKWebKit already exports. `setPassword` follows pinned [URL.cpp](https://github.com/WebKit/WebKit/blob/c55364d53f97/Source/WTF/wtf/URL.cpp#L560-L578), the same in the PS5 11.x source but for `toStringWithoutCopying`: the UTF-8 bytes of the password are percent-encoded with the user-info set, a URL without an authority gets `//:`, an empty password removes the stored one, and the result is parsed again. Null objects and a view with a length but no characters throw `std::invalid_argument`. Closes when: compared with a console module.
