# libSceLibreSsl
## change [X509_verify_cert_error_string]
- [X509_verify_cert_error_string](../../../core/libs/prx/libSceLibreSsl/Export.cpp) - A PS5 (firmware 11.60, payload process; a title process may differ) answered with this library's text for codes 0, 2, 3, 7, 10, 18, 20, 21, 24, 40 (its first 48 characters only) and 50, and with the numeric fallback for 1, 62, 70, 80, 9999 and -1; 4294967298 gave the text of code 2, as the low-32-bit lookup does, and no call raised a signal. Other codes are not measured. The 64-bit argument, low-32-bit lookup, messages and shared numeric fallback follow [LibreSSL 2.5.4](https://github.com/libressl/openbsd/blob/2e2c612066aa993717528a0249c15c51128d61cb/src/lib/libcrypto/x509/x509_txt.c), the version identified in [published firmware 13.40 measurements](https://github.com/boykopovar/AnyPS5/discussions/8981#discussioncomment-19111214). Console modifications and other firmware versions remain unverified. Unknown-code results share an overwritten static buffer and are not safe for concurrent use, as in that release; code 1 and codes above 54 use the numeric fallback.
## change [OCSP_response_status_str, OCSP_cert_status_str and OCSP_crl_reason_str]
- [OCSP_response_status_str, OCSP_cert_status_str and OCSP_crl_reason_str](../../../core/libs/prx/libSceLibreSsl/src/Ocsp.cpp) (libSceLibreSsl) - A PS5 (firmware 11.60, payload process; a title process may differ) returned this library's strings for statuses 0 to 3, 5 and 6, certificate statuses 0 to 2 and CRL reasons 0 to 6 and 8, and `(UNKNOWN)` for status 4, -1, 99 and 4294967297, certificate status 3 and reasons 7, 9, 10 and 99 (26 calls, no signal); `(UNKNOWN)` for 4294967297 shows the argument is not cut to 32 bits. The tables follow LibreSSL [ocsp_prn.c](https://github.com/libressl/openbsd/blob/2e2c612066aa993717528a0249c15c51128d61cb/src/lib/libcrypto/ocsp/ocsp_prn.c), unchanged from revision 1.8 (2015) to 1.12 (2025), with codes from `ocsp.h`; the argument is a 64-bit `long` and every value not in a table returns `(UNKNOWN)`
