# shader

## add Functional

- [gfx1013-only memory forms](../../../core/shader/recompiler/RdnaDecoder/src/RdnaMemoryOpDecoder.cpp) (shader recompiler) - the SMEM scratch forms translate as wave-uniform accesses: byte address = SOFFSET + immediate minus the scratch stride, so every lane names the wave's first slot (uniform scratch aliases lane 0), loads broadcast lane 0 with `ReadFirstLane`, stores use a uniform predicate. The stride is the request's per-thread size, passed for compute only, so graphics still throws at tracking, and a spanned wave addresses its half's first lane (both inferred). The 64-bit SRC2 source pair is read at the address rounded down to 8 bytes. The other 21 forms and the 52 SMEM atomics translate into shared atomics and stores; an SMEM atomic reads SDST when GLC is 0 and returns the old value when GLC is 1 (LLVM `Constraints = "$sdst = $sdata"`), and compare-swap reads the pair after the data. Closes when: the graphics scratch size, SRC2 alignment and scratch addressing are confirmed.
