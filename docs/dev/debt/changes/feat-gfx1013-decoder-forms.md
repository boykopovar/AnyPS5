# shader

## add Functional

- [gfx1013-only memory forms](../../../core/shader/recompiler/RdnaDecoder/src/RdnaMemoryOpDecoder.cpp) (shader recompiler) - the SMEM scratch forms translate as a wave-uniform access: the byte address is SOFFSET plus the 21-bit signed immediate minus the lane's own scratch stride, so every lane names the wave's first slot (the console's uniform scratch aliases it), loads broadcast that lane with `ReadFirstLane`, and stores take a wave-uniform predicate. The lane stride is the request's per-thread size, zero for graphics stages, and a spanned 64-lane wave on a 32-lane host addresses its half's first lane; both are inferred, not measured. The 21 DS SRC2, global and buffer store forms and the 52 SMEM atomics translate into the shared atomics and stores; an SMEM atomic reads SDST when GLC is 0 and writes the old value back when GLC is 1 (LLVM `Constraints = "$sdst = $sdata"`), and compare-swap reads the pair after the data. Closes when: the scratch addressing is confirmed on hardware.
