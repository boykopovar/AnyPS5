# shader

## add Functional

- [gfx1013-only memory forms](../../../core/shader/recompiler/RdnaDecoder/src/RdnaMemoryOpDecoder.cpp) (shader recompiler) - the 15 DS 64-bit SRC2 forms and the 61 SMEM store and atomic forms have decoder tables for the gfx1013 reference. The 15 DS SRC2 forms and the six global and buffer stores translate into the shared 64-bit atomics and address/buffer stores; the three scratch stores translate to a throw because the scratch layout is not implemented, and the 52 SMEM atomic forms (`S_ATOMIC_*`, `S_BUFFER_ATOMIC_*`) still have no translation case, so a shader using one fails with the translator's unsupported-instruction error. The `_X2`/`_X4` suffix gives the SMEM dword count; the 64-bit SRC2 forms use the same DS `Offset` operand as the 32-bit forms (LLVM `DSInstructions.td` `DS_1A`, llvmorg-19.1.0), so they keep the 32-bit offset scale, which is not measured on hardware; the SMEM stores and atomics write the same wave-uniform address from every active lane. Closes when: the atomics and scratch stores are translated and tested.
