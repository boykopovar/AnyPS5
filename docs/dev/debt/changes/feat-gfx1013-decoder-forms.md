# shader

## add Functional

- [gfx1013-only memory forms](../../../core/shader/recompiler/RdnaDecoder/src/RdnaMemoryOpDecoder.cpp) (shader recompiler) - the SMEM scratch forms translate as a wave-uniform access: byte address = SOFFSET + immediate minus the lane's own scratch stride, so every lane names the wave's first slot (the console's uniform scratch aliases it), loads broadcast that lane with `ReadFirstLane`, and stores take a wave-uniform predicate. The stride is the request's per-thread size, which is passed for compute only, a graphics shader using them still throws at tracking, and a spanned wave addresses its half's first lane; both inferred. The 21 DS SRC2, global and buffer store forms and the 52 SMEM atomics translate into the shared atomics and stores; an SMEM atomic reads SDST when GLC is 0 and writes the old value back when GLC is 1 (LLVM `Constraints = "$sdst = $sdata"`), and compare-swap reads the pair after the data. Closes when: the graphics scratch size and addressing are confirmed.
