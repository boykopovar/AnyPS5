# libSceNetCtl

## change RFC 5389 STUN binding probes

- [sceNetCtlGetNatInfo](../../../core/libs/prx/libSceNetCtl/Export.cpp) (libSceNetCtl) - performs RFC 5389 STUN binding probes from the active host IPv4 interface against `stun.playstation.net` and fallback third-party STUN servers instead of reading cached state from the console's background `netctl` service; uncached calls disclose the host's IPv4 address to them. Each call budgets 1000 ms; successes cache 60 s per local IPv4 address, failures re-probe. Classification follows [RFC 3489 section 10.2](https://www.rfc-editor.org/rfc/rfc3489#section-10.2) figure 2, the pinned source: mapped endpoint equal to the local socket is type 1, secondary responses matching or differing the first are type 2 or type 3. When test I answers and every secondary probe times out, the result keeps stun_status FAILED and nat_type NONE, because no console evidence exists for that case: figure 2's follow-up, sending test I to the other IP once test II gets no answer and comparing the mapped addresses, is not modelled, so the symmetric answer figure 2 suggests for all-timeouts is a guess. Console captures confirm types 2, 3 and STUN failure; the console's answer on that branch is unmeasured, as is type 1 with a direct public IP.
