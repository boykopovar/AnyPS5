# libSceJpegDec

## change decode mode 1 and pixel formats 9 and 10 throw (incomplete in shadPS4)

- [sceJpegDecDecode](../../../core/libs/prx/libSceJpegDec/Export.cpp): decode mode 1 and pixel format 9 throw (incomplete in shadPS4). Y8 follows [shadPS4](https://github.com/shadps4-emu/shadPS4/blob/33e73127119f672f9f08b8a5a7f71600263f61d9/src/core/libraries/jpeg/jpegdec.cpp#L267-L317): rows are one byte per pixel, each `(77R + 150G + 29B) >> 8` of the decoded, clamped RGB. For a colour source this is luma re-derived from RGB, not the decoded Y component; the two differ by rounding and wherever the YCbCr to RGB step clips. One title (PPSA29866) disassembled for this entry has one call site (0x2c111d); it passes a null `imageInfo` and a parameter structure with decode mode 0, down-scale 1 and pixel format 0, and hands the result to another function whose handling of a negative result was not read. In the parameter structure built around this call site, mode 1 and formats 9, 10 and 11 do not show up; whether a down-scale of 1 means no scaling was not compared.

## add Functional

- [sceJpegDecDecode Y8U8Y8V8 output](../../../core/libs/prx/libSceJpegDec/Export.cpp) (format 10) - unmeasured: whether the console interpolates chroma, rounds otherwise or goes through RGB is unknown. Corrupt data that unscaled formats 0, 1 and 11 decode through stb returns 0x80650012 here. Order `Y0 Cb Y1 Cr` and `(width + 1) / 2 * 4`-byte rows follow [KytyPS5](https://github.com/KytyPS5/KytyPS5/blob/3b549a9d8487a3e488760bffe3287b70d43f46be/src/libs/libJpegDec.cpp) and libSceJpegEnc. Samples come from [TurboJPEG's planar decoder](https://github.com/libjpeg-turbo/libjpeg-turbo/blob/c85e6b905bf237038faa936dab160ebfc5da0344/src/turbojpeg.h#L2150-L2191): 4:2:2 chroma is kept, coarser chroma repeated, 4:4:x chroma pairs averaged with [libjpeg-turbo's bias](https://github.com/libjpeg-turbo/libjpeg-turbo/blob/c85e6b905bf237038faa936dab160ebfc5da0344/src/jcsample.c#L220-L253). Odd widths repeat the last sample; gray gets 0x80 chroma. Sources TurboJPEG cannot split into YCbCr planes throw.
