Closes when: compared with the console.

## change [webrtc::VideoFrame::Builder constructor and destructor]

- [webrtc::VideoFrame::Builder constructor and destructor](../../../core/libs/prx/libwebrtc/src/VideoFrameBuilder.cpp) (libwebrtc) - destroying a builder that holds a frame buffer or packet infos throws through `NotImplemented_nid_no_patch`: it releases those guest references, through the buffer's virtual `Release`. Both are defaulted in [video_frame.cc](https://webrtc.googlesource.com/src/+/8d78f5de6c27b2c793039989ea381f1428fb0100/api/video/video_frame.cc); every default member value of the 192-byte `Builder` (`kNotSetId`, null references, zero times, `kVideoRotation_0`, unset optionals and `use_low_latency_rendering` false) is zero, so the constructor clears it, and without references the destructor does nothing. The builder is written and read through `GuestPtr`; a null builder, an unwritable one in the constructor or an unreadable one in the destructor throws. Closes when: the references are released through the guest objects.
