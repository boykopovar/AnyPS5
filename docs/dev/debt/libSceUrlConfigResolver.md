- [Configuration loading](../../../core/libs/prx/libSceUrlConfigResolver/Export.cpp) (libSceUrlConfigResolver) - not modelled: the configuration the module loads through its imports. Read from disassembly of firmware 13.42, not measured on a console, only the checks before that load are answered: `sceUrlConfigResolverUpdate` and `sceUrlConfigResolverGetJscHeapSizeSoftLimit` return `0x80BA8080` for a null argument; `sceUrlConfigResolverGetAppConfig` clears its buffer and stores 0 to its length output, then returns `0x80BA8080` for a null key; `sceUrlConfigResolverIsUpdated` returns false, as the flag it reads is set only by the load. Past those checks the four throw. Firmware writes the buffer and length directly; an unwritable one throws here. `sceUrlConfigResolverGetDefaultQueryParameter` is not exported by 13.42.
