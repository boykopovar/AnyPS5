# libSceVoiceQoS technical debt

### Silent stubs

- [sceVoiceQoSReadPacket](../../../core/libs/prx/libSceVoiceQoS/Export.cpp) (libSceVoiceQoS) - network voice packet streaming is not implemented: it returns `SCE_VOICE_ERROR_LIBVOICEQOS_ARGUMENT_INVALID` for a null buffer or size or an unknown connection id, and otherwise returns 0 and writes size 0 (indicating no packet is available). Aliens: Fireteam Elite (PPSA03393) calls it on its startup path (`0x76D14C`-`0x76D16E`) and stops with `not implemented` if it throws
- [sceVoiceQoSWritePacket](../../../core/libs/prx/libSceVoiceQoS/Export.cpp) (libSceVoiceQoS) - network voice packet streaming is not implemented: it returns `SCE_VOICE_ERROR_LIBVOICEQOS_ARGUMENT_INVALID` for a null buffer or size or an unknown connection id, and otherwise returns 0 leaving `*size` untouched (treating all input bytes as accepted). Aliens: Fireteam Elite (PPSA03393) sets `*size` to the packet size before `WritePacket` (`0x76CEB9`-`0x76CEC4`), compares `*size` against that input size upon return (`0x76CF07`-`0x76CF10`) to verify all bytes were accepted, and stops with `not implemented` if it throws

### Unknown function info

- [sceVoiceQoSSetMode and sceVoiceQoSTerminate](../../../core/libs/prx/libSceVoiceQoS/Export.cpp): these exports are absent from the supplied module. Their argument declarations still require another firmware version or callers; sceVoiceQoSTerminate forwards to sceVoiceQoSEnd as an inferred alias.

### Functional

- [libSceVoiceQoS](../../../core/libs/prx/libSceVoiceQoS/Export.cpp): initialization arguments, initialization errors, endpoint and connection argument lists, and the no-argument End path are confirmed by the supplied module. The 11.00 module's Initialize builds a 40-byte libSceVoice init parameter with the QoS app type and calls `sceVoiceInit(..., 100)` at `0x6e8`, returning its error, then calls `sceVoiceStart` with the caller's memory block and the 0x40000 size at `0x70b`, calling `sceVoiceEnd` if it fails; End calls `sceVoiceStop` and then `sceVoiceEnd` at `0xb34`/`0xb39` and returns the latter's result. The host mirrors that lifecycle, so the title must not initialize libSceVoice itself and gets the already-initialized error if it does. The QoS pool allocation, the signaling sockets and the remaining internal object state are not modelled. End deletes the local endpoint ports and clears host state. Connecting an uncreated port throws.
- [sceVoiceQoSCreateLocalEndpoint](../../../core/libs/prx/libSceVoiceQoS/Export.cpp): creates the input and output device ports through sceVoiceCreatePort with the confirmed parameter template (port types 0 and 5, device types 0 and 2, the given user and device IDs, volume 1.0) and returns the libSceVoice error unchanged; when the output port fails it deletes the input port first. Local ID zero, the single-slot limit, the -1 output on exhaustion and the 0x804E0907 limit error for a repeated or -1 user are confirmed.
- [sceVoiceQoSCreateRemoteEndpoint and sceVoiceQoSConnect](../../../core/libs/prx/libSceVoiceQoS/Export.cpp): remote/connection slot allocation from zero, seven/fifteen slot capacities, exhaustion outputs, and reuse of released slots are recovered; the endpoints allocate slots without creating ports. Remote endpoint deletion clears the first matching connection. Shared encoder ownership, codec parameters and packet accounting are still missing.
- [sceVoiceQoSSetLocalEndpointAttribute](../../../core/libs/prx/libSceVoiceQoS/Export.cpp): local selectors 0/2 forward a four-byte float to sceVoiceSetVolume on the input/output port and 1/3 a one-byte flag to sceVoiceSetMuteFlag; unsupported selectors and sizes return the confirmed invalid-argument error. Without a created local endpoint the call returns the invalid-argument error instead of addressing libSceVoice port 0, which is a real handle a title can own. Remote selector 7 still throws until remote endpoint ports exist.
- [sceVoiceQoSGetLocalEndpointAttribute](../../../core/libs/prx/libSceVoiceQoS/Export.cpp): the 4.03 module (`libSceVoiceQoS.sprx`, SHA-256 `5427cd36c68bcab64e5ccecdca92f8e54a7a11d80191a21e9a02f29eca73858d`, export `eZu2RP0Ma3w#D#A` at VA 0x1530) accepts only local endpoint 0 and non-null output, then a selector table of 0/2/6 (four bytes), 1/3/5 (one byte) and 8 (two bytes); selectors 4 and 7 and any other id or size return the confirmed invalid-argument error, and valid reads reach the voice-port parameter getters keyed by the two port handles. Local selectors 0..3 read volume and mute from the two local ports. Selectors 5, 6 and 8 call sceVoiceGetPortAttr with 1001, 1002 and 1003, which still throws for device attributes in libSceVoice. Other selectors return the invalid-argument error; the local ID must be zero and the value non-null. Without a created local endpoint it returns the invalid-argument error and does not read a title-owned libSceVoice port 0.
- [sceVoiceQoSGetLocalEndpoint and sceVoiceQoSGetRemoteEndpoint](../../../core/libs/prx/libSceVoiceQoS/Export.cpp): all in-range connection slots are queryable, including unused slots returning endpoint ID -1. Disconnecting an unused in-range slot succeeds. These state rules are confirmed; the packet and status getters containing `NotImplemented_nid_no_patch` remain unchanged.
- [VoiceQoS endpoint ID guest outputs](../../../core/libs/prx/libSceVoiceQoS/Export.cpp): the console result for an unwritable non-null output in `sceVoiceQoSGetLocalEndpoint` or `sceVoiceQoSGetRemoteEndpoint` is unmeasured. AnyPS5 returns `SCE_VOICE_ERROR_LIBVOICEQOS_ARGUMENT_INVALID` as a host-safety fallback, preserving the existing null-output error and leaving stored connection state unchanged.
- [sceVoiceQoSEnableChat, sceVoiceQoSDisableChat and sceVoiceQoSInitHQ](../../../core/libs/prx/libSceVoiceQoS/Export.cpp): zero-argument chat wrappers validate initialization and throw because the chat backend is unimplemented; sceVoiceQoSInitHQ forwards directly to sceVoiceQoSInit. The sceVoiceQoSInitHQ forwarding and the chat wrappers' not-initialized result are not measured on a console and mirror the libSceVoice behaviour.
