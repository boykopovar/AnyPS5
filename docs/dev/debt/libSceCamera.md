### Functional

- [sceCameraIsAttached](../../../core/libs/prx/libSceCamera/Export.cpp) (libSceCamera) - no camera is ever attached: index 0 returns 0 (not attached) and any other index returns `SCE_CAMERA_ERROR_PARAM` (0x802E0000), as [shadPS4](https://github.com/shadps4-emu/shadPS4/blob/9a8ae4417bbfc79b1a43eb8a2eb0bb602148261e/src/core/libraries/camera/camera.cpp#L187-L200) does without a configured camera, with the error value from its [camera_error.h](https://github.com/shadps4-emu/shadPS4/blob/9a8ae4417bbfc79b1a43eb8a2eb0bb602148261e/src/core/libraries/camera/camera_error.h). Not measured on a console. Closes when: a host camera is exposed to guests.
- [sceCameraOpen, sceCameraClose, sceCameraCloseByHandle, sceCameraStart, sceCameraStartByHandle, sceCameraStop, sceCameraStopByHandle, sceCameraGetFrameData and sceCameraIsValidFrameData](../../../core/libs/prx/libSceCamera/src/Handles.cpp) (libSceCamera) - follow [shadPS4's camera.cpp](https://github.com/shadps4-emu/shadPS4/blob/396c2a09a38d22eaa02aab32c1967263dceab95f/src/core/libraries/camera/camera.cpp) with no host camera configured: its check order and 584-byte frame data limit. Handle calls require a live ID; IDs are not reused, unlike shadPS4's counter. The console's ID reuse and exhaustion policy is unknown; exhaustion throws. `sceCameraStartByHandle` succeeds where `sceCameraStart` reports `NOT_CONNECTED`, as in shadPS4; which of the two the console does is not known. The open parameter is not read and no camera memory is mapped. Not measured on a console. Closes when: a host camera is exposed to guests.
- [sceCameraGetAttribute, sceCameraGetAutoExposureGain, sceCameraGetAutoWhiteBalance, sceCameraGetDefectivePixelCancellation, sceCameraGetLensCorrection, sceCameraGetContrast, sceCameraGetSaturation, sceCameraGetSharpness, sceCameraGetHue, sceCameraGetExposureGain, sceCameraGetWhiteBalance and sceCameraGetGamma](../../../core/libs/prx/libSceCamera/src/Attributes.cpp) (libSceCamera) - return the defaults in [shadPS4's camera_config.cpp](https://github.com/shadps4-emu/shadPS4/blob/396c2a09a38d22eaa02aab32c1967263dceab95f/src/core/libraries/camera/camera_config.cpp), not values read from a device. The exposure target check from firmware 3.00 always applies. Not measured on a console. Closes when: a host camera is exposed to guests.
- [sceCameraSetAttribute, sceCameraSetAutoExposureGain, sceCameraSetAutoWhiteBalance, sceCameraSetDefectivePixelCancellation, sceCameraSetDefectivePixelCancellationInternal, sceCameraSetLensCorrection, sceCameraSetLensCorrectionInternal, sceCameraSetContrast, sceCameraSetSaturation, sceCameraSetSharpness, sceCameraSetHue, sceCameraSetExposureGain, sceCameraSetWhiteBalance and sceCameraSetGamma](../../../core/libs/prx/libSceCamera/src/Attributes.cpp) (libSceCamera) - report `NOT_CONNECTED` after shadPS4's checks. shadPS4 refuses a non-null exposure gain or gamma in `sceCameraSetExposureGain` and `sceCameraSetGamma`; here a null one is refused, like `sceCameraSetWhiteBalance`. The sharpness limit from firmware 3.50 always applies. Not measured on a console. Closes when: a host camera is exposed to guests.
- [sceCameraGetConfig, sceCameraSetConfig, sceCameraSetConfigInternal, sceCameraGetDeviceConfig and sceCameraGetDeviceConfigWithoutHandle](../../../core/libs/prx/libSceCamera/src/Config.cpp) (libSceCamera) - the type 1 default configuration and the cleared device configurations follow shadPS4's camera_config.cpp and [camera_device.cpp](https://github.com/shadps4-emu/shadPS4/blob/396c2a09a38d22eaa02aab32c1967263dceab95f/src/core/libraries/camera/camera_device.cpp); a new configuration is refused with `NOT_CONNECTED` before its type is read, as shadPS4 does without a camera.
