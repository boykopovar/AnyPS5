# libSceVcodec technical debt

### Functional

- [libSceVcodecUnknown_Ipf4PM5PIHE_nid_no_patch](../../../core/libs/prx/libSceVcodec/Export.cpp) (libSceVcodec) - returning ErrorInvalidArgument (0x80bf0001) for unmapped result or config pointers via GuestCopyIn/Out_nid_no_patch is a host-safety fallback preserving host errno; console behavior on unmapped memory is unmeasured.
- [libSceVcodec](../../../core/libs/prx/libSceVcodec/Export.cpp) has no `/dev/uvd_bgt` device behind it: AnyPS5's kernel models no video-codec hardware-budget device, so the library's descriptor stays -1 and every request fails with `EBADF`, which the library reports as `0x80BF0000`. What the requests do on the device and what its replies hold is not known. The library side follows firmware 13.42 `libSceVcodec.sprx` (sha256 `3a808faf1aba9728036f74c82a2a0c8082602172bed67524a23f3f0f777b9c5a`), read from disassembly to every return, not measured on a console. Closes when: a `/dev/uvd_bgt` model exists and is measured against a console.
- [Ac6aYjr1pY8](../../../core/libs/prx/libSceVcodec/Export.cpp) (NID only) throws when its request succeeds and it is given an output: the 13.42 library then clears 0x1308 bytes of the output and converts the device's per-budget counters into floating-point rates there, which is not implemented. A failed request, or a null output, returns as the library does.
- [Device descriptor](../../../core/libs/prx/libSceVcodec/Export.cpp) - the 13.42 library opens `/dev/uvd_bgt` from a module initializer and closes it from a finalizer; here it is opened on the first export call and never closed. The diagnostic `printf` lines the library writes when the open or a request fails are not written. Request bytes the library leaves unset are zero here.
- [Argument meanings](../../../core/libs/prx/libSceVcodec/include/InventoryExports.hpp) - argument registers and widths come from the 13.42 disassembly; what the budget, size and type values mean is not established. `sceVcodecOpenHwBudget` and `X0qscgxx1MI` pass their pid to `sceKernelGetAppInfo`, which in AnyPS5 throws for a pid other than the caller's and 0.
