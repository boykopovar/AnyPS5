# libSceSystemLogger technical debt

### Functional

- [sceSystemLoggerInitialize, sceSystemLoggerSetLogData and sceSystemLoggerTerminate](../../../core/libs/prx/libSceSystemLogger/Export.cpp) (libSceSystemLogger) - the state and argument checks follow firmware 11.00's `libSceSystemLogger.sprx` disassembly, not measurements on a console: `Initialize` returns `0x81080005` when the library is already initialized, `Terminate` returns `0x81080004` when it is not, and `SetLogData` rejects a tag longer than 15 bytes or containing a character outside `[0-9A-Za-z]`, a count above 32, a non-zero count with a null data pointer, an entry size above 64 and any non-zero byte in the entry's 32-byte tail. The entries are written to the host's standard error with the tag. The system logger service, its ring buffer and transport, the objects created by the firmware's internal initialize/terminate/submit helpers and the `0x81080001` failure paths are not implemented, so initialization always succeeds and submission always reports success. The tag is copied up to 15 bytes; the wrapper does not read its fourth argument register.
