AnyPS5 input mapping

Change the keyboard and mouse bindings and save them as anyps5-input.ini. Game controllers are mapped automatically and do not use this file.

anyps5-input.ini


                

                    
                    
                

                

                    
                    
                    
                

                

                

            

            

                
Save the file beside the converted game executable, or set ANYPS5_INPUT_CONFIG to its path.

                
Actions left out of the file keep their built-in bindings. Keys are matched by their position and named as on a US keyboard.

                
File format: INPUT_MAPPING.md.
