LOCAL & IN YOUR CONTROL

Settings

Desktop connection

Start-AnyPS5.cmd updates the per-user helper and starts Docker. If the helper disconnects, it retries automatically. Close the native launcher before editing the shared library here.

Preparation storage

New prepared copies use this folder. Existing games and saves stay where they are. Create a folder on a drive with enough space, then paste its Windows path.

Prepared for Windows

The library links prepared Windows games with their matching app0 and runtime libraries. Original ELF, SELF and package inputs need preparation. Renaming a file does not convert it.

Available to launch means files are present. Gameplay, audio, input and save compatibility require testing each game.

Engine updates

Linux containers build the Windows engine and versioned runtime bundles from this source. Download the current bundle above to install or update the helper. Choose Prepare & add in scan results to create a separate Windows copy with the matching converter and libraries. Existing games keep their runtimes.

Activity & diagnostics


AnyPS5 relinks executables into native programs. Game compatibility is unverified until tested.
