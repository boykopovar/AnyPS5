CAPABILITIES & COMPATIBILITY
What AnyPS5 can do
AnyPS5 relinks supported PS5 executables into native programs using reimplemented system libraries. Compatibility varies by game and engine build.
From this web app
  • Pair securely with your signed-in Windows desktop using a short-lived, one-use code.
  • Paste an Explorer path or browse on Windows, scan folders, review results and link existing prepared games.
  • Prepare extracted x86-64 ELF or decrypted SELF inputs in a separate folder with matching runtime libraries, declared module dependencies and supported companion executables.
  • Choose the preparation drive, follow progress, cancel a job, launch registered games and inspect process results and logs.
Preparation preserves original inputs. Existing game folders, settings and saves are retained.
Current limits
  • Linux containers build and serve the app. Games run on the Windows desktop through the installed helper; Docker alone cannot launch them.
  • No games, firmware or keys are supplied. Encrypted SELF files and package extraction/decryption are unsupported.
  • Missing libraries or exports, unsupported console syscalls, and incompatible executable/module layouts stop preparation. The app cannot implement missing engine behavior.
  • Automatic preparation supports up to 250,000 resource files and main executables up to 2 GiB. It needs space for a full copy, runtime and conversion workspace. Linked resources and UNC paths are unsupported.
  • Dynamic modules without declared dependencies may need manual preparation. Executables sharing module directories or requiring different shared-module outputs are unsupported by automatic preparation.
  • Per-game launch-argument/environment editing and removing individual library entries use the native launcher; the web app currently provides launch and inspection. Session monitoring after a helper restart requires confirming that old games have closed.
  • The desktop folder picker can temporarily pause helper heartbeats while its dialog remains open.
  • Existing prepared copies retain their original runtimes when the engine updates. This app does not automatically upgrade their runtime or migrate saves into a new copy.
Ready to launch is not a compatibility verdict
StateMeaning
Needs preparationAn input was found; it is not yet a Windows launch folder.
PreparedThe app converted the selected inputs and checked their loader dependencies. The game was not executed automatically.
Available / UnverifiedLaunch files are present. Rendering, controllers, audio, saves and gameplay still require testing.
Exited with code 0The launch process ended successfully. This does not establish that the game rendered or was playable.
Unsupported / failedNo new game is registered. Read the specific error and log; an engine change or additional game data may be needed.
CPU, GPU, drivers and title-specific settings affect results. See the upstream compatibility discussions for title reports; they do not guarantee results for another build.
Engine source and updates
Checking the installed engine source...
Every docker compose up --build resolves the configured upstream ref (main by default) and merges in this fork's launcher features. Conflicts or build failures stop the update. Latest code can also introduce regressions; support is not guaranteed.
After a successful engine update, install the generated desktop helper from Settings or run Start-AnyPS5.cmd. Existing games keep their own runtime copies.
For a reproducible source selection, set ANYPS5_UPSTREAM_REF to the full upstream commit SHA before building.
Start and stop
Start from the source folder with docker compose up --build, then open 127.0.0.1:8766. Install and pair the Windows helper on first use.
Stop and remove this stack's containers and network with docker compose down. There is no -d flag for down. Docker images, build caches, app data and game folders remain available.
The Windows helper reconnects when the app returns. Windows games and preparation jobs have their own lifecycle. Cancel preparation in the app and close games normally if you want those Windows processes to stop before shutdown. To remove the helper's sign-in startup and executable, use Start-AnyPS5.cmd -Uninstall; configuration, tokens, logs, games and saves are retained.
AnyPS5 relinks executables into native programs. Game compatibility is unverified until tested.
